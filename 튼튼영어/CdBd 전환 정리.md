## 4. CdBd로 그대로 못 옮기는 것 — 대체안 / 확인 필요

| 원본 기능 | CdBd | 처리 |
|---|---|---|

| 메뉴 → 특정 페이지 점프 | ⚠️ **미검증** | 내부 페이지 이동 링크 매핑 키가 이 볼트에 없음 → **메뉴 페이지 제외**하고 선형 진행 제안. 필요하면 UI diff로 키 검증 후 사용 |
| 하단 sticky 버튼 | ⚠️ **미검증** | 「하단 고정」 UI 매핑 키 미검증 → **shotgun 금지**. 각 페이지 하단 버튼 카드로 배치 |
| 유튜브 인라인 재생 | 🔶 유튜브 카드 존재하나 **이 볼트에 명세 없음** | 카드 12종 명세는 `cdbd-templates` 볼트 `1-6-2`가 정본. 이 볼트 범위로 하려면 **이미지 카드 + `linkButton`(url)** 로 처리 |

## 6. 확정이 필요한 질문

1. **페이지 수** — 20P 안 / 19P 안 / 13P 압축안 중 무엇으로 갈지 (과금 단위)

4. **유튜브** — 유튜브 카드를 쓸지, 썸네일 이미지 + 링크로 갈지
5. **「상상해 보세요」 섹션** — 우수 회원 하위인지 별도 화면인지 (녹화본만으로는 불명)
6. **"파랑색"** — 튜터링(보라)·주니어·베이비리그와 별개인 **메인 브랜드 버전**이 맞는지
