# 소식지 제작 프로세스

> 소식지는 CdBd 멀티페이지의 **소식·매거진형** 콘텐츠입니다. **대아청과**를 첫 사례로 기준을 세우며, 룩북만큼 반복 패턴이 강하지 않아 **브랜드별 템플릿** 성격을 가집니다.
> CdBd 이용 방식·제작 흐름은 룩북과 동일하지만 **페이지 유형**이 다릅니다(아래 [[소식지/2. 디자인 가이드/2-1. 공통]]).
> 본 문서의 **스켈레톤 규칙**은 cdbd-templates 저장소 「1. 작업 가이드/1-1. 워크플로우.md」를 소식지에 맞춰 옮긴 것입니다 — 원본이 갱신되면 함께 점검하세요.

---

## 용어

- **시안**: 같은 내용·구성요소로 **서로 다른 디자인 2타입**(예: 딥그린 / 연베이지그린)을 제시 → 디자인 톤 기준 확정
- **초안**: 채택된 타입으로 **전체 페이지** 완성

---

## 단계 개요

스켈레톤(구조) → 색·폰트 배리에이션(시안) → CdBd 구현 순으로, **각 단계마다 사용자 피드백 게이트**를 둡니다.

| # | 단계 | 출력물 | 게이트 |
|---|------|--------|--------|
| 1 | **콘텐츠 기획** | 페이지 구성·카드 단위 초안 + 무드(색·폰트) 결정 | 기획 피드백 |
| 2 | **피그마 스켈레톤** | 디폴트 테마(fafafa/292929/Pretendard) 카드 구성 + 이미지·표 자리(주석) | 스켈레톤 피드백 |
| 3 | **색·폰트 배리에이션 (시안 2타입)** | 스켈레톤에 색·폰트·이미지 입힌 **A·B 2타입** | 시안 피드백 |
| 4 | **CdBd 에디터 구현** | 라이브 페이지 + OG + 제목 | CdBd 페이지 피드백 |

> cdbd-templates 워크플로우의 5단계(상세 페이지)·6단계(어드민 등록)는 **템플릿 마켓 등록용**이라 일반 소식지 제작에는 생략합니다. 소식지를 정식 템플릿으로 등록할 때만 추가 적용.

## 2단계 — 스켈레톤 규칙 (핵심)

실제 CdBd 카드 속성만 사용해 **이미지 없이 구조·카드 구성**만 빠르게 시각화. 색·폰트는 3단계에서.

### 디폴트 테마 고정
| 역할 | 값 |
|------|----|
| 배경색 | `#fafafa` |
| 텍스트·버튼색 | `#292929` |
| 버튼 텍스트색 | `#fafafa` (= 배경색) |
| 서체 | **Pretendard** 단일 |
| 버튼 모양 | 원형 99px (pill) |

### Auto Layout = CdBd 여백 1:1 매핑
| 레이어 | Auto Layout | CdBd 매핑 |
|--------|-------------|-----------|
| 페이지 프레임 | vertical · gap 0 · padding 0 | 페이지엔 gap·padding 옵션 없음 |
| 카드(페이지 직접 자식) | vertical로 쌓임 · gap 0 | 카드 보드 배치 |
| 카드 내부여백 | 카드 프레임 자체 `padding` | 「카드 내부여백」 (0~40, 2단위) |
| 카드 외부여백 | 카드를 wrapper 프레임으로 감싸 wrapper에 `padding` | 「카드 외부여백」 (0~40, 2단위) |

- **단일 depth 예외**: 배경(fill)·테두리(stroke) **없는** 카드는 wrapper 없이 카드 자체 `padding`만(외부여백 0). 배경·테두리 **있는** 카드만 wrapper(외부)+카드(내부) 2 depth.
- **여백 우선순위**: ① 4면 비슷한 padding(간격은 인접 카드 padding 합으로) → ② 상·하 대칭 → ③ 여백 카드(구분선 두께 0, intra-section 미세 간격 4~8px만). 페이지 **첫·마지막 카드**는 asymmetric 허용(첫 카드 top 24~40 / 마지막 카드 bottom 24~40).

### 텍스트 속성 분리
- **1 카드 = 1 텍스트 속성**. 제목/본문/보조설명/정렬이 다르면 카드를 나눈다 (CdBd 텍스트 카드는 카드 단위로 속성을 가짐 → 인라인 혼합 불가).

### 카드 옵션은 CdBd 제공값 범위 내에서만
- 내부/외부여백 0~40(2단위) · 모서리 각진(0)/둥근 · 테두리 0~4(0.5단위) · 텍스트 사이즈 16단계(12·14·16·…·60) · 줄간격 100%~(10단위, default 160) · 정렬 좌/중/우 · 갤러리 유형·간격·단 수 등. **CdBd 슬라이더·세그먼트에 없는 임의값 금지.**

### 이미지·표 처리
- **이미지·표 영역은 자리(프레임)만** 잡고, **프레임 안에 주석으로 무엇을 넣을지 명시**(예: `[서명 이미지 자리] 이상용 대표 친필 서명 (투명 PNG)`).

### 5대 원칙
1. 범용성(카드 단위 복제·삭제 가능성) 2. 텍스트 카드 분리 3. 보조 텍스트는 투명도로 4. 테마 default 색상 최대 활용 5. 편집 불가 장식 그래픽 배제

### 카드 네이밍·주석 라벨
- 카드 프레임 이름 = `N. 카드유형 — 역할` (예: `2. 텍스트 — 클래스 개요`)
- 각 카드 첫 자식 = 동일 문구의 **주석 라벨** — Pretendard SemiBold **10px** · `#292929 @45%` · letter-spacing 0.6
