# 소식지 디자인 가이드

> CdBd 멀티페이지 규격 = **가로 380 고정 × 세로 자유**(580 초과 시 자동 스크롤). 메이크뷰(통이미지 스크롤)와 달리 **실제 카드 조합**으로 쌓는다.

---

## ⚠️ 표지 규칙 (예외)

- **표지는 스크롤 없이 380×580에 딱 맞는 「통 이미지」 한 장**으로 만든다. **포스터형 단일 페이지**이며 **별도 인터랙션이 없다.**
- 표지에 들어가는 모든 요소 — **발행 호수 · 제호 · 태그라인 · 일러스트 · 로고 · 색감** — 은 **이미지 안에 렌더**된다 (카드로 쪼개지 않음).
- CdBd 등록 = **이미지 카드 1장**(내부·외부여백 0 · 크기 100%) → 1 페이지.
- 룩북의 「01 표지 = 통 이미지 허용」 예외와 동일한 개념. **표지를 제외한 모든 페이지는 카드 조합 + 세로 자유 스크롤.**

---

## 페이지 구성 (대아청과 기준)

| 순서 | 페이지 | 비고 |
|------|--------|------|
| ⓪ | **표지** | 380×580 통이미지 (위 예외) |
| ① | **대표이사 인사말** | 인사말만. 편지형(제목·본문·서명·서명 이미지) |
| ② | **출하자 지원 현황** | 지원금 4종 카드 |
| ③ | **상반기 리뷰·전망 + 저장물량** | 데이터 성격이라 한 스크롤 페이지로 묶음 |
| … | (이후 주요 소식·알림·찾아오는 길 등) | 초안에서 전체 확장 |

- **인사말 페이지 = 인사말만** 포함(지원현황은 별도 페이지) — 최근 작업 방식 계승.

## 카드 컨벤션

- **텍스트 카드 분리**: 제목 / 본문 / 보조를 각각 카드로. (보조 텍스트는 별도 색이 아니라 **투명도**로.)
- **항목 카드(지원금·품목 등) = inset 둥근 배경 카드**
  - 구조: wrapper(외부여백 좌우 20 · 하단 간격) + 카드(내부여백 · 배경색 · 모서리 둥근)
  - 메이크뷰의 번호·카드 톤 계승하되 **번호는 텍스트(①②③④)**, 원형 뱃지 등 **편집 불가 장식 그래픽은 배제**.
- **표 = Figma 디자인 이미지**: CdBd엔 표 카드가 없으므로 **수치 표**(예: 저장물량 전수조사)는 Figma에서 디자인해 **이미지 카드**로 넣는다. 서술형 비교(품목별 리뷰·전망 등)는 **카드로 분리**.
- **서명 · 로고 · 일러스트 = 이미지 카드**.

## 색·무드

- **스켈레톤(2단계)** = 디폴트 테마(`#fafafa` / `#292929` / Pretendard) — 구조만 평가.
- **시안(3단계)** = **2타입 색·무드 배리에이션**.
  - 대아청과 원고 지정 색감 = **딥그린 + 아주 연한 베이지빛 그린** → **Type A 딥그린 무드 / Type B 연베이지그린 무드**(레이아웃 동일, 색·무드만 차별화).
  - 딥그린은 **대아청과 CI 그린**에 맞춰 미세조정.
- **로고와 텍스트는 항상 동일 컬러**.

## 메이크뷰 톤 계승

- 둥근 카드 · 친근/따뜻 · 캐릭터·채소 모티프 · 명확한 타이포 위계. (보라 팔레트 → 그린 팔레트로만 교체.)
