# 소식지 디자인 가이드

> CdBd 멀티페이지 규격 = **가로 380 고정 × 세로 자유**(580 초과 시 자동 스크롤). 메이크뷰(통이미지 스크롤)와 달리 **실제 카드 조합**으로 쌓는다.

---

## ⚠️ 표지 규칙 (예외)

- **표지는 스크롤 없이 380×580에 딱 맞는 「통 이미지」 한 장**으로 만든다. **포스터형 단일 페이지**이며 **별도 인터랙션이 없다.**
- 표지에 들어가는 모든 요소 — **발행 호수 · 제호 · 태그라인 · 일러스트 · 로고 · 색감** — 은 **이미지 안에 렌더**된다 (카드로 쪼개지 않음).
- CdBd 등록 = **이미지 카드 1장**(내부·외부여백 0 · 크기 100%) → 1 페이지.
- 룩북의 「01 표지 = 통 이미지 허용」 예외와 동일한 개념. **표지를 제외한 모든 페이지는 카드 조합 + 세로 자유 스크롤.**

---

## 페이지 구성 (대아청과 기준)

| 순서 | 페이지 | 비고 |
|------|--------|------|
| ⓪ | **표지** | 380×580 통이미지 (위 예외) |
| ① | **대표이사 인사말** | 인사말만. 편지형(제목·본문·서명·서명 이미지) |
| ② | **출하자 지원 현황** | 지원금 4종 카드 |
| ③ | **상반기 리뷰·전망 + 저장물량** | 데이터 성격이라 한 스크롤 페이지로 묶음 |
| … | (이후 주요 소식·알림·찾아오는 길 등) | 초안에서 전체 확장 |

- **인사말 페이지 = 인사말만** 포함(지원현황은 별도 페이지) — 최근 작업 방식 계승.

## 헤더·푸터 (고정 섹션)

> **표지·목차를 제외한 모든 페이지**에 헤더·푸터를 둔다. CdBd **카드 「상단 고정」/「하단 고정」**으로 구현(스크롤 중 화면에 고정). 참고: 메이크뷰 `fix`(node 12:2229).

- **헤더(상단 고정)** = **2단 카드** [ **페이지 제목**(왼쪽 정렬) ㅣ **메뉴(☰) 아이콘 이미지**(오른쪽 정렬) ] · 풀폭 컬러 밴드(타입 포인트색 — A 딥그린 / B 틸, 글씨는 배경색).
  - ⚠️ **CdBd는 「좌측 아이콘 + 중앙 텍스트」 불가** → 반드시 **2단 카드(텍스트 좌 / 아이콘 우)**.
  - 헤더가 페이지 제목을 담으므로 **본문 내 메인 제목 중복 배치 ❌** — 본문엔 **서브섹션 제목만**.
- **푸터(하단 고정)** = **◀ 이전** + 가운데 **로고** + **이후 ▶** · 풀폭 컬러 밴드.
- 헤더·푸터는 **풀폭(full-bleed)**, 본문 패널의 인셋과 무관하게 좌우 꽉 차게.

## 섹션 타이틀 분리 + 품목 일러스트

> 참고: node `12:2940`.

- **각 섹션·항목 제목은 별도 「타이틀 섹션」으로 분리**한다(내용 패널과 분리 — 타이틀 밴드/행 + 내용 패널).
- **일러스트(품목 등)는 텍스트 카드에 동봉 불가** → 둘 중 택1:
  - **2단 카드** [ 일러스트 ㅣ 제목 ] — 좌우 비율로 (어두운 밴드 위 등).
  - **원형 배지 이미지 + 제목(상하)** — 밝은 배경에서 일러스트 **흰 영역이 묻힐 때**, 일러스트를 **녹색 원형 배지** 위에 올려 대비 확보(예: A 리뷰).
- **이미지 출처 = src 보드(`2012:45`)**: 표지 **배경 지도** + **표지 레이어**(A 캐릭터 / B 채소), **리뷰 품목별 일러스트**(배추·무·양배추·대파), CI 로고, 대표이사 서명.
- **간격(가독성)**: 소식지는 텍스트가 많아 **섹션 내·섹션 간 간격을 넉넉히** 준다(좁으면 가독성 저하). 항목 padding ~20+ · 섹션 간 ~16+.

## ⚠️ CdBd 구현 제약 (필수)

> 시안은 **CdBd 카드로 1:1 매핑 가능**해야 한다. CdBd 카드 모델상 아래는 **불가능** — 시안에 넣지 말 것. (원본: cdbd-templates 「1. 작업 가이드/1-5-2. CdBd 카드 기능」)

### 카드 = 1 콘텐츠 = 1 배경 (중첩 금지)
- **둥근(또는 배경 있는) 카드 = 그 자체로 의미가 완결되는 단일 콘텐츠.** 그 안에 **또 다른 배경 요소(뱃지·pill·칩·서브바)를 중첩 ❌.**
- 한 배경 카드 안에 **제목+금액+설명+기준을 묶기 ❌** → 텍스트 카드 N장으로 분리하고, 그룹은 **배경 비움(투명) + 간격**으로 표현. 섹션 분리가 필요하면 한쪽에만 배경/테두리 또는 **구분선·여백 카드** 삽입.

### 텍스트 카드 = 1 속성 · 1 색
- 한 텍스트 카드 안에서 **사이즈·정렬·색 혼합 ❌** (인라인 다색 불가).
- **컬러 화살표(증감) 인라인 ❌** → **증가(녹색) / 감소(빨강)를 각각 별도 단일색 텍스트 카드**로 분리. (한 줄에 같은 방향만 있으면 한 카드, 방향이 섞이면 카드 2장.)
- 보조·캡션 텍스트 = **별도 회색 ❌**, **테마 텍스트색 + 투명도(alpha)**.

### 가로 배치 = 2단 카드
- 「제목 ㅣ 금액」처럼 한 줄에 좌우 배치는 **2단 카드(텍스트+텍스트, 2~4단)** — 셀별 단일 색. (카드는 기본 세로로만 쌓임.)

### 표 = 이미지 카드
- CdBd엔 **표 카드 없음** → 수치 표(저장물량 등)는 Figma 디자인 후 **이미지 카드 1장**. 표 안의 **증감 화살표·감소 빨강 등 색은 이미지 내부**에서 처리.

### 폰트·사이즈·여백 단위 (CdBd 슬라이더)
- **폰트 두께 = Bold(700) / Regular(400) 2단계만** — ExtraBold·SemiBold·Medium은 Bold/Regular로 수렴.
- **텍스트 사이즈 = 정수 ≥ 12** (1=1px).
- **줄간격 = 1.2 / 1.4 / 1.6 / 1.8 / 2.0** 스냅(0.2 step) — 한 페이지 2값 권장(헤더 1.2·본문 1.6).
- **여백** = 카드 내부/외부여백(1=1px) · **구분선 카드**(실선/대시/점선/물결, 두께 1=1px · 상하여백 1=10px) · **여백 = 구분선 두께 0**. 배경·테두리 없는 카드는 **내부여백 0**, 외부여백만 사용.

### 표지만 예외
- 표지는 **통이미지(이미지 카드 1장)** 라 위 제약과 무관 — 자유 디자인.

## 카드 컨벤션 (위 제약 안에서)

- **텍스트 카드 분리**: 제목 / 본문 / 보조를 각각 카드로 (보조는 투명도).
- **항목(지원금·품목 등)** = 단일 속성 텍스트 카드 스택 + **구분선/여백**으로 그룹. **배경으로 묶은 카드 ❌.** 번호는 텍스트(「지원 01」 등), 원형 뱃지 등 **편집 불가 장식 ❌.**
- **제목 ㅣ 금액** = 2단 카드.
- **표** = 이미지 카드 · **서명 · 로고 · 일러스트** = 이미지 카드.
- 강조는 **포인트 컬러(테마 버튼색) · 텍스트 위계 · 구분선**으로.

## 색·무드 · 2타입 차별화

> 확정 HEX · WCAG 대비 · 역할 매핑({배경}/{텍스트}/{버튼}+포인트2)·의미색은 → [[2-2. 색상 팔레트]]

- **스켈레톤(2단계)** = 디폴트 테마(`#fafafa` / `#292929` / Pretendard) — 구조만 평가.
- **시안(3단계) = 2타입. 내용만 동일, 디자인은 명확히 다르게** — 색뿐 아니라 **정렬 · 헤더 방식 · 구분선 · 타이포**까지 분리. 단, 차별화는 **위 「CdBd 구현 제약」 안의 합법 레버**로만: 페이지 배경색 · 정렬(좌/중) · 헤더(라벨+구분선 vs 색면 밴드) · 구분선(유/무) · 이미지 모양 · 타이포 스케일.
- **대아청과 기준 2안 예시**:
  - **A · 에디토리얼** — 라이트 크림 · 좌측 정렬 · 구분선 · 2단[제목ㅣ금액] · 딥그린 통이미지 표지
  - **B · 모던** — 연그린 · 중앙 정렬 · **그린 헤딩 밴드**(배경 1카드 = 제목 1개) · 연그린 통이미지 표지
- 색감 = **딥그린 + 아주 연한 베이지빛 그린**(원고 지정), 딥그린은 **대아청과 CI 그린**에 맞춰 미세조정.
- **로고와 텍스트는 동일 컬러 계열**, 보조 텍스트는 투명도.
