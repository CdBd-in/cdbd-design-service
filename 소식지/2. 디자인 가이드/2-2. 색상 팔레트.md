# 소식지 색상 팔레트

> CdBd 페이지 테마 색을 정하는 규칙. **전체 70종 팔레트 라이브러리**(9개 무드 · 대비 검증)는 cdbd-templates 「1. 작업 가이드/1-2. 색상 팔레트」 참조. 본 문서는 그 규칙을 소식지에 맞춰 옮기고, **대아청과 2안(A/B) 팔레트를 확정**한 것.

---

## 역할 매핑 (CdBd 페이지 테마)

| 팔레트 | 색1 | 색2 | 색3 |
|---|---|---|---|
| **2색** | `{배경색}` | `{텍스트색}` + `{버튼색}` (동일) | — |
| **3색** | `{배경색}` | `{텍스트색}` | `{버튼색}` |

- **보조 텍스트(캡션·유의사항)** = `{텍스트색}` × **60% / 40% 투명도** — 별도 회색 지정 ❌.
- **대비 기준**: 배경 ↔ 텍스트 **≥ 3.6**. 본문 14px 이하는 **AA ≥ 4.5 권장**. **AA-Large(3.6–4.5)는 헤드라인·강조 전용**(작은 본문 ❌).

---

## 소식지 확장 — 포인트 2색 + 의미색

소식지는 정보량이 많아 기본 3색에 **포인트색 2개**와 **데이터 의미색**을 더한다. (모두 대비 통과 필수.)

| 역할 | 설명 |
|---|---|
| `{배경색}` / `{텍스트색}` | 기본 톤 (대비 AAA 지향) |
| **포인트1 = `{버튼색}`** | 섹션 라벨·헤더·금액 등 **주 강조** |
| **포인트2** | 번호·소제목 라벨 등 **부 강조** — 포인트1과 **명확히 구분되는 색상** |
| **의미색 — 증가 `#2156C0`(블루) / 감소 `#C0392B`(레드)** | 전망 수치 증감 신호 **전용 · 양 시안 공통·고정** |

- 의미색은 **인라인 불가**(텍스트 카드 = 1색) → 증가/감소를 **각각 단일색 텍스트 카드**로 분리한다 ([[2-1. 공통]] 「CdBd 구현 제약」).
- **표지는 통이미지**라 테마·대비 규칙 밖 — 색 자유(가독성만 유지).

## 대아청과 확정 팔레트 (2안) — **라이브러리에서 선택**

> 커스텀 hex가 아니라 cdbd-templates 「1-2. 색상 팔레트」 **70종에서 선택**. 두 안 모두 **내추럴/오가닉** 무드(청과 브랜드 적합)지만 텍스트색·포인트·배경이 달라 구분된다.

### A · 에디토리얼 = **HappyHues 5** (내추럴/오가닉)

| 역할 | HEX | 배경 대비 |
|---|---|---|
| 배경색 | `#F2F7F5` 그린-화이트 | — |
| 텍스트색 | `#00473E` 딥그린 | 9.84 **AAA** |
| 포인트1(버튼) | `#FAAE2B` 앰버 | 텍스트 ❌(1.7) → **채움색 전용**(앰버 면 위 딥그린 5.7 AA) |
| **포인트2** | `#1B6E37` 리프그린 | 5.8 AA — **섹션·항목 라벨**(딥그린과 다른 그린 범위) |
| 증가 / 감소 | `#2156C0` / `#C0392B` | 6.1 / 5.0 AA |

- 본문·헤더·금액 = 딥그린, **라벨·번호 = 리프그린**(2그린 위계). 앰버는 **표지 틱·강조 면/버튼** 채움색으로만.
- 표지(통이미지): 딥그린 `#00473E` 배경 + 그린-화이트 텍스트(9.8 AAA) + 앰버 틱.

### B · 모던 = **HappyHues 8** (내추럴/오가닉)

| 역할 | HEX | 배경 대비 |
|---|---|---|
| 배경색 | `#F8F5F2` 웜-화이트 | — |
| 텍스트색 | `#232323` 잉크 | 14.5 **AAA** |
| 포인트1(버튼) | `#078080` 틸 | **헤딩 스트립**(틸 면+흰 글씨 4.8 AA)·라벨 |
| **포인트2** | `#0B5C3B` 파인그린 | 7.4 AAA — **금액·품목명**(틸과 다른 그린 범위) |
| 섹션 면처리 틴트 | `#D6E5E2` (틸 ×14%) | 패널 배경 — 잉크 12 AAA |
| 증가 / 감소 | `#2156C0` / `#C0392B` | 6.1 / 5.0 AA |

- 본문·헤더 = 잉크, **금액·품목명 = 파인그린**, 틸은 **헤딩 밴드·라벨**.
- **⚠️ 섹션 면처리 (텍스트 多 카테고리 필수) — 두 방식 중 택1**:
  1. **Full-bleed (좌우 여백 없음)**: 각진 0px · **테두리 없음** · **간격 없음** · 섹션마다 색 **적용/미적용 반복**(지브라).
  2. **인셋 (좌우 여백 있음 · 참고 12:2940)**: 둥근/각진 · **테두리는 필요할 때만**(아니면 ❌) · **섹션 간 간격 필수**.
  - **대아청과 B = ② 인셋 둥근 패널** (틴트 `#D6E5E2` · radius 14 · 무테두리 · 간격 10) + 섹션 헤더 **틸 밴드**(둥근).
  - ⚠️ 패널 안엔 **plain 텍스트만** — 뱃지·pill 등 **별도 배경 요소 중첩 ❌** ([[2-1. 공통]] CdBd 제약).
- 표지(통이미지): 웜-화이트 `#F8F5F2` 배경 + 잉크 텍스트 + 틸 pill.

> **A·B 구분**: 배경(그린-화이트 / 웜-화이트) · 텍스트(딥그린 / 잉크) · 포인트(앰버 / 틸). 의미색(증가 블루/감소 레드)만 공통.
> ⚠️ **라이브러리 포인트색 = 채움색(버튼·면) 기준**이라 작은 글씨로는 대비가 약할 수 있음 → 포인트색은 **밴드·태그·금액 등 면/큰 글씨**에 쓰고, 본문·라벨 위계는 **텍스트색의 웨이트·투명도**로 처리.

## 다른 브랜드·호수에서 색을 새로 잡을 때

1. cdbd-templates 「1-2. 색상 팔레트」 **9개 무드 70종**에서 **대비 ≥ 3.6** 팔레트를 고른다.
2. 위 **역할 매핑**({배경}/{텍스트}/{버튼})으로 배치하고, 필요 시 **포인트2**를 같은 무드 안에서 1색 추가(대비 재검증).
3. **의미색(증가 블루/감소 레드)** 고정 사용.
4. 본문 가독성 = **AA ≥ 4.5** 우선.
