# 소식지 색상 팔레트

> CdBd 페이지 테마 색을 정하는 규칙. **전체 70종 팔레트 라이브러리**(9개 무드 · 대비 검증)는 cdbd-templates 「1. 작업 가이드/1-2. 색상 팔레트」 참조. 본 문서는 그 규칙을 소식지에 맞춰 옮기고, **대아청과 2안(A/B) 팔레트를 확정**한 것.

---

## 역할 매핑 (CdBd 페이지 테마)

| 팔레트 | 색1 | 색2 | 색3 |
|---|---|---|---|
| **2색** | `{배경색}` | `{텍스트색}` + `{버튼색}` (동일) | — |
| **3색** | `{배경색}` | `{텍스트색}` | `{버튼색}` |

- **보조 텍스트(캡션·유의사항)** = `{텍스트색}` × **60% / 40% 투명도** — 별도 회색 지정 ❌.
- **대비 기준**: 배경 ↔ 텍스트 **≥ 3.6**. 본문 14px 이하는 **AA ≥ 4.5 권장**. **AA-Large(3.6–4.5)는 헤드라인·강조 전용**(작은 본문 ❌).

---

## 소식지 확장 — 포인트 2색 + 의미색

소식지는 정보량이 많아 기본 3색에 **포인트색 2개**와 **데이터 의미색**을 더한다. (모두 대비 통과 필수.)

| 역할 | 설명 |
|---|---|
| `{배경색}` / `{텍스트색}` | 기본 톤 (대비 AAA 지향) |
| **포인트1 = `{버튼색}`** | 섹션 라벨·헤더·금액 등 **주 강조** |
| **포인트2** | 번호·소제목 라벨 등 **부 강조** — 포인트1과 **명확히 구분되는 색상** |
| **의미색 — 증가 `#2156C0`(블루) / 감소 `#C0392B`(레드)** | 전망 수치 증감 신호 **전용 · 양 시안 공통·고정** |

- 의미색은 **인라인 불가**(텍스트 카드 = 1색) → 증가/감소를 **각각 단일색 텍스트 카드**로 분리한다 ([[2-1. 공통]] 「CdBd 구현 제약」).
- **표지는 통이미지**라 테마·대비 규칙 밖 — 색 자유(가독성만 유지).

## 대아청과 확정 팔레트 (2안)

### A · 에디토리얼 (내추럴/오가닉 · 따뜻)

| 역할 | HEX | 배경 대비 |
|---|---|---|
| 배경색 | `#F6F4EA` 크림 | — |
| 텍스트색 | `#232021` 잉크 | 14.6 **AAA** |
| 포인트1(버튼) | `#1F7A3D` 포레스트그린 | 4.9 AA |
| 포인트2 | `#856212` 다크오커 | 5.1 AA |
| 증가 / 감소 | `#2156C0` / `#C0392B` | 6.0 / 4.9 AA |

- 표지(통이미지): 딥그린 `#163C28` 배경 + 크림 텍스트(10.6 AAA) + 오커 틱 `#C9A23C`(5.1 AA).

### B · 모던 (모던/시크 · 시원)

| 역할 | HEX | 배경 대비 |
|---|---|---|
| 배경색 | `#E8EEEA` 민트그레이 | — |
| 텍스트색 | `#15302A` 다크틸 | 12.0 **AAA** |
| 포인트1(버튼) | `#0C6B57` 틸 | 5.5 AA (헤딩 밴드 흰 글씨 6.5 AA) |
| 포인트2 | `#83406B` 플럼 | 6.1 AA |
| 증가 / 감소 | `#2156C0` / `#C0392B` | 5.7 / 4.6 AA |

- 표지(통이미지): 민트 `#E8EEEA` 배경 + 다크틸 텍스트 + 틸 pill.

> **A·B는 배경(크림/민트) · 텍스트(잉크/다크틸) · 포인트(그린·오커 / 틸·플럼)가 모두 달라 한눈에 구분**된다. 의미색(증가 블루/감소 레드)만 공통.

## 다른 브랜드·호수에서 색을 새로 잡을 때

1. cdbd-templates 「1-2. 색상 팔레트」 **9개 무드 70종**에서 **대비 ≥ 3.6** 팔레트를 고른다.
2. 위 **역할 매핑**({배경}/{텍스트}/{버튼})으로 배치하고, 필요 시 **포인트2**를 같은 무드 안에서 1색 추가(대비 재검증).
3. **의미색(증가 블루/감소 레드)** 고정 사용.
4. 본문 가독성 = **AA ≥ 4.5** 우선.
