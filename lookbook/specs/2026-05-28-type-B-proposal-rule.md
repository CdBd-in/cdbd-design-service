## 1. 개요

**타입**: Type B 시안 (동일 리소스로 다른 레이아웃/스타일 적용)  
**페이지 구성**: 3페이지
- Page 1: 표지 (로고 + 타입 표시)
- Page 2: 브랜드 & 시즌 컬렉션 소개
- Page 3: 내지 (화보 및 상품 정보)

**제작 기준**: 동일한 텍스트, 이미지 리소스를 Type B 스타일로 배치  
**Type A와의 차이**: 레이아웃 구성, 비주얼 스타일 상이

---

## 2. 페이지 규격 & 로고 규칙

### 기본 규격
| 항목 | 값 |
|------|-----|
| 페이지 너비 | 380px (고정) |
| 페이지 높이 | 580px (기본값) |
| 스크롤 | 필요 시 height 증가 가능 |

### 로고 배치 (Page 1 - 표지)

```
┌─────────────────────────────────────┐
│                                     │
│  ← 83px →  [ 로고 214×26 ]  ← 83px │  
│                                     │
│  ↑ 209px                            │
│                                     │
│            TYPE - B                 │
│                                     │
└─────────────────────────────────────┘
  380px wide
```

| 항목 | 값 | 상세 |
|------|-----|------|
| **로고 최대 사이즈** | 214px × 26px | 실제 로고가 이보다 작은 경우 비율 유지하며 축소 |
| **로고 정렬** | 중앙 정렬 | 좌우 패딩 각 83px (대칭) |
| **로고 상단 여백** | 209px | 페이지 상단에서 209px 하강 배치 |
| **로고 하단 여백** | 255px | 로고 하단(235px)부터 페이지 하단(580px)까지 여유 |
| **로고 스타일** | [브랜드별 정의] | 흑백/컬러/배경 처리 등은 브랜드 가이드 따름 |

### Page 2, 3 규격
- 동일한 380px × 580px (필요시 확장)
- Page 2, 3은 로고 불필요
