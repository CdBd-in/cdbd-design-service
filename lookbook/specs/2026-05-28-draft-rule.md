**작성일**: 2026-05-28  
**상태**: Draft (페이지 레이아웃 정의 대기 중)

---

## 1. 개요

**타입**: 초안 제작 (전체 페이지 완성 버전)  
**페이지 구성**: 시안(3페이지)보다 많은 모든 페이지 포함
- 표지
- 브랜드 & 시즌 소개
- 상품 카테고리별 내지 페이지 (복수)
- 기타 추가 페이지

**제작 기준**: 완전한 룩북/카탈로그로 풀 스펙 제작  
**용도**: 클라이언트 최종 검수 및 배포용

---

## 2. 페이지 규격 & 로고 규칙

### 기본 규격
| 항목 | 값 |
|------|-----|
| 페이지 너비 | 380px (고정) |
| 페이지 높이 | 580px 이상 (필요에 따라 확장) |
| 스크롤 | 높이 증가로 스크롤 발생 |

### 표지 로고 배치 (Page 1)

```
┌─────────────────────────────────────┐
│                                     │
│  ← 83px →  [ 로고 214×26 ]  ← 83px │  
│                                     │
│  ↑ 209px                            │
│                                     │
│        (타입 또는 브랜드명)          │
│                                     │
└─────────────────────────────────────┘
  380px wide
```

| 항목 | 값 | 상세 |
|------|-----|------|
| **로고 최대 사이즈** | 214px × 26px | 실제 로고가 이보다 작은 경우 비율 유지하며 축소 |
| **로고 정렬** | 중앙 정렬 | 좌우 패딩 각 83px (대칭) |
| **로고 상단 여백** | 209px | 페이지 상단에서 209px 하강 배치 |
| **로고 하단 여백** | 255px 이상 | 로고 하단(235px)부터 페이지 하단까지 여유 |
| **로고 스타일** | [브랜드별 정의] | 흑백/컬러/배경 처리 등은 브랜드 가이드 따름 |

### 내지 페이지 규격
- 동일한 380px × 580px (필요시 확장)
- 로고는 불필요 (표지에만 포함)

## 3. 페이지 구성 (예상)

### Page 1: 표지
**핵심**: 룩북 타이틀 + 브랜드/시즌 정보

**구성 요소**:
- 로고 (214px × 26px, 상단 209px)
- 룩북 제목/타이틀
- 브랜드명 및 시즌명
- 배경 이미지/컬러

---

### Page 2: 컬렉션 소개
**핵심**: 시즌 콘셉트 및 영감 제시

**구성 요소**:
- 시즌 타이틀
- 콘셉트 스토리텔링 텍스트
- 분위기 이미지
- (선택) 테마 컬러 팔레트

---

### Page 3 이상: 상품 카테고리별 내지
**핵심**: 각 카테고리의 상품 화보 + 정보

**각 페이지 구성**:
- 카테고리명 (또는 상품 이름)
- 상품 이미지 (화보)
- 상품 설명 텍스트
- 상세 정보 (가격, 색상, 사이즈, SKU 등)

**페이지 수**: 상품 수량 및 정보량에 따라 결정 (3페이지 이상)

---

### 마지막 페이지: 뒷표지 또는 연락처
**핵심**: 브랜드 마감 정보

**구성 요소**:
- 로고 (선택)
- 브랜드 연락처/웹사이트
- 추가 정보 (배송, AS 등)
- (선택) 뒷표지 이미지
