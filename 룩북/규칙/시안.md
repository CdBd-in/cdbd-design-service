# 룩북 시안 규칙

**작성일**: 2026-05-28  
**상태**: Draft (피그마 상세 레이아웃 대기 중)

---

## 개요

**시안이란**: 동일한 콘텐츠·구성요소로 **서로 다른 디자인(레이아웃) 2가지 안(A·B)**을 제시하여 클라이언트가 방향성을 선택하도록 하는 작업물

- **A안·B안의 구성요소·내용은 완전히 동일** — 다른 점은 채택한 **디자인(레이아웃·스타일)**뿐
- 아래 제시된 여러 레이아웃 옵션 중 **항상 2가지를 선택·조합**해 A안·B안을 구성
- **각 안 4페이지** → A안 4p + B안 4p = **총 8페이지**
- **목적**: 디자인 방향성 선택 & 피드백 수집
- **완성 후**: 선택된 안을 기반으로 초안(전체 페이지) 제작

### 페이지 구성 (파일명 기준)
- **시안 표지** (`A` / `B`): 로고 + 타입(TYPE-A/B) 표시
- **01**: 각 시안의 표지 (실제 콘텐츠 시작)
- **02**: 브랜드 및 시즌 컬렉션 소개
- **03**: 내지 (화보 및 상품 정보)

## 시안 표지 (`A` / `B`)

A안·B안을 구분하는 맨 앞 표지. **피그마 제공 화면을 그대로 사용하고 로고만 교체**합니다.

| 안 | 노드 ID | 타입 텍스트 |
|----|---------|-------------|
| A | 16001:96 | TYPE - A |
| B | 16001:106 | TYPE - B |

**제작 방법**:
- 피그마 화면의 로고 영역만 브랜드 로고로 교체
- 배경, 타입 텍스트, 배치 등 나머지는 원본 그대로 유지
- 로고는 비율을 유지하며 적절한 크기로 배치

## 표지 레이아웃 타입 (frame / clean)

**01·02 페이지**(각 시안의 표지 + 브랜드·시즌 소개)는 화보를 배경으로 로고·텍스트를 얹는 표지 성격의 페이지입니다.

**공통**: 두 타입 모두 화보 위에 로고·서브텍스트를 **오버레이**합니다.  
**차이**: 페이지 **바깥쪽 외곽선(테두리)의 유무**입니다.

### frame type
화보 위에 로고·서브텍스트를 오버레이하고, 페이지 **바깥쪽에 외곽선(테두리)**을 둡니다.

![[ref-표지-frame-01.png]]

### clean type
화보 위에 로고·서브텍스트를 오버레이하며, **외곽선 없이** 마감합니다.

![[ref-표지-clean-01.png]]

### 공통 핵심 원칙 (가장 중요)

1. **로고가 화보의 중요 부분(모델 얼굴 등)을 가리지 않을 것** — 화보 크기 또는 로고 위치를 조정해 해결
2. **로고와 서브타이틀 텍스트는 동일한 컬러를 사용할 것**
3. **서브텍스트 양(행 수)에 따라 레이아웃을 결정할 것** — 텍스트가 길어지면 텍스트 블록 영역을 충분히 확보
4. **화보 스타일(여백이 많은 방향)에 따라 레이아웃을 결정할 것** — 로고·텍스트를 화보의 여백이 많은 쪽에 배치

> **원칙**: 01·02 페이지는 **같은 타입으로 통일**하는 것을 권장합니다. 요청이 있을 경우 혼합 사용도 가능합니다.

### 피그마 레퍼런스
- **frame type**: 노드 ID `16002:110`
- **clean type**: 노드 ID `16002:111`

## 페이지별 규칙

> A안·B안은 아래 구성요소를 **동일하게** 포함하며, 레이아웃 변형(타입·로고 위치·정렬 등) 중 **2가지를 선택**해 서로 다른 디자인으로 제작합니다.

> **용어**  
> · **시즌명**: 예) `26 SPRING COLLECTION`  
> · **시즌 타이틀**: 예) `Soft Structured Transition` (슬로건 성격, 생략 가능)  
> · **시즌 설명**: 콘셉트 본문 텍스트 (예: "견고한 구조와 유연함이 공존하는…")

### 공통 텍스트·로고 스펙

모든 수치는 페이지 규격 **380 × 580px** 기준이며, 화보 구도에 따라 미세 조정될 수 있습니다.

**텍스트** (폰트: Pretendard)
| 요소 | 두께 | 크기 | 행간 |
|------|------|------|------|
| 시즌명 | Medium | 15px | 1.3 |
| 시즌 타이틀 | Bold | 20px | 1.3 |
| 시즌 설명 | SemiBold | 14px | 1.5 |

- 컬러: 로고와 텍스트는 **항상 동일 컬러** (화보 명도에 따라 흑/백 선택)
- 02는 dim 오버레이 위에 **흰색** 사용이 일반적

**로고 크기**
| 사용처 | 크기 (px) |
|--------|-----------|
| 01 분리형 로고 | 약 215 × 27 |
| 01 묶음형 로고 | 약 180~200 × 22~25 |
| 02 로고 | 약 146 × 18 |

### 01 — 각 시안의 표지

**핵심**: 실제 콘텐츠의 시작을 알리는 표지 페이지

**필수 요소**: 배경 화보, 로고  
**선택 요소**: 시즌명, 시즌 타이틀  
**오버레이**: 없음 (화보 위에 로고·텍스트 직접 오버레이)

**레이아웃 유형** (frame / clean 공통 적용):

| 유형 | 로고 위치 | 시즌명·타이틀 | 결합 방식 |
|------|-----------|---------------|-----------|
| **01-A** 로고 상단 | 상단 (중앙 또는 좌측) | 하단에 별도 배치 | 로고·텍스트 분리 |
| **01-B** 로고 중앙 | 화면 중앙 | 하단에 별도 배치 | 로고·텍스트 분리 |
| **01-C** 묶음·중앙 | 중앙 | 로고 바로 아래 시즌명 | 로고+시즌명 한 그룹 |
| **01-D** 묶음·하단 | 하단 | 로고 바로 아래 시즌명 | 로고+시즌명 한 그룹 |

| 01-A 로고 상단 | 01-B 로고 중앙 | 01-C 묶음·중앙 | 01-D 묶음·하단 |
|---|---|---|---|
| ![[ref-표지-frame-01.png]] | ![[ref-01-logo-center.png]] | ![[ref-01-group-center.png]] | ![[ref-01-group-bottom.png]] |

**치수 가이드** (px)
- **좌우 여백**: 중앙 배치 기준 약 83 (좌측 정렬 시 약 36~40)
- **01-A**: 로고 상단 여백 약 60 / 하단 시즌명·타이틀 — 좌측 약 80, 하단 여백 약 33
- **01-B**: 로고 세로 중앙 / 하단 시즌명·타이틀 동일
- **01-C**: 로고+시즌명 그룹 좌우 약 90, 세로 중앙 / 그룹 내 로고–시즌명 간격 약 8
- **01-D**: 로고+시즌명 그룹 좌우 약 101, 하단 여백 약 40

> 분리형(01-A·B)은 시즌명 + 시즌 타이틀을 함께 노출, 묶음형(01-C·D)은 로고 + 시즌명만 노출하는 경향. 로고 위치·정렬은 화보의 여백·구도에 맞춰 선택합니다.

### 02 — 브랜드 및 시즌 컬렉션 소개

**핵심**: 브랜드 스토리 + 시즌 콘셉트 상세 설명

**필수 요소**: 배경 화보 + **`#000000` dim 오버레이**, 로고, 시즌 설명 텍스트  
**선택 요소**: 시즌명, 시즌 타이틀  
**오버레이**: 화보 전체에 검정 dim을 깔아 텍스트 가독성 확보
- 기본값 **40%**
- 배경 화보의 밝기에 따라 투명도 조정 가능 (밝은 화보일수록 진하게, 어두운 화보는 더 옅게)

**텍스트 블록 구성** (위→아래): 시즌명 → (시즌 타이틀) → 시즌 설명

**레이아웃 유형** (frame / clean 공통 적용):

| 유형 | 텍스트 정렬 | 로고 위치 |
|------|-------------|-----------|
| **02-A** | 중앙 정렬 | 하단 |
| **02-B** | 중앙 정렬 | 상단 |
| **02-C** | 좌측 정렬 | 하단 |
| **02-D** | 좌측 정렬 | 상단 |

| 02-A 중앙·로고 하단 | 02-B 중앙·로고 상단 | 02-C·D 좌측 정렬 |
|---|---|---|
| ![[ref-표지-02-center.png]] | ![[ref-02-center-logotop.png]] | ![[ref-표지-02-left.png]] |

**치수 가이드** (px)
- **텍스트 블록 폭**: 약 251 (중앙 정렬 좌우 여백 약 65 / 좌측 정렬 좌측 여백 약 40)
- **텍스트 블록 세로**: 상단에서 약 214부터 시작 (본문 분량에 따라 가변) / 시즌명그룹–시즌 설명 간격 약 18
- **로고**: 하단형 하단 여백 약 55 / 상단형 상단 여백 약 50 / 좌우 — 중앙 정렬 약 117, 좌측 정렬 약 40

> 시즌 설명 분량(행 수)에 맞춰 텍스트 블록 크기·위치를 조정합니다. 01과 동일한 표지 레이아웃 타입(frame / clean) 사용을 권장합니다.

## 작업 체크리스트

### 안 구성 확인
- [ ] A안·B안의 구성요소·내용이 동일한가
- [ ] A안·B안이 서로 다른 레이아웃/디자인 2가지를 채택했는가
- [ ] 01·02 페이지의 표지 레이아웃 타입(frame/clean)이 (안 내에서) 통일되었는가

### 표지 레이아웃 핵심 원칙 확인
- [ ] 로고가 화보의 중요 부분(모델 얼굴 등)을 가리지 않는가
- [ ] 로고와 서브타이틀 텍스트가 동일 컬러인가
- [ ] 서브텍스트 행 수에 맞춰 레이아웃을 결정했는가
- [ ] 화보 여백이 많은 쪽에 로고·텍스트를 배치했는가

### 시안 표지 확인
- [ ] 피그마 기준 화면 사용, 로고만 교체
- [ ] 배경/타입 텍스트/배치는 원본과 동일

### 페이지별 확인
- [ ] 각 페이지 필수 요소 포함
- [ ] 이미지 비율 및 해상도 확인
- [ ] 텍스트 오타 검수 / 가독성 확인

### 전체 스타일 확인
- [ ] 각 안 내 색상 팔레트 일관성 유지
- [ ] 폰트 사이즈/두께 규칙 준수
- [ ] 간격(padding/margin) 일관성 확인
