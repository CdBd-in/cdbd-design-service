**작성일**: 2026-05-28  
**상태**: Draft (피그마 상세 레이아웃 대기 중)

## 개요

**시안이란**: 동일한 콘텐츠·구성요소로 **서로 다른 디자인(레이아웃) 2가지 안(A·B)**을 제시하여 클라이언트가 방향성을 선택하도록 하는 작업물

- **A안·B안의 구성요소·내용은 완전히 동일** — 다른 점은 채택한 **디자인(레이아웃·스타일)**뿐
- 아래 제시된 여러 레이아웃 옵션 중 **항상 2가지를 선택·조합**해 A안·B안을 구성
- **각 안 4페이지** → A안 4p + B안 4p = **총 8페이지**
- **목적**: 디자인 방향성 선택 & 피드백 수집
- **완성 후**: 선택된 안을 기반으로 초안(전체 페이지) 제작

### 페이지 구성 (파일명 기준)
- **시안 표지** (`A` / `B`): 로고 + 타입(TYPE-A/B) 표시
- **01**: 각 시안의 표지 (실제 콘텐츠 시작)
- **02**: 브랜드 및 시즌 컬렉션 소개
- **03**: 내지 (화보 및 상품 정보)

## 시안 표지 (`A` / `B`)

A안·B안을 구분하는 맨 앞 표지. **피그마 제공 화면을 그대로 사용하고 로고만 교체**합니다.

| 안 | 노드 ID | 타입 텍스트 |
|----|---------|-------------|
| A | 16001:96 | TYPE - A |
| B | 16001:106 | TYPE - B |

**제작 방법**:
- 피그마 화면의 로고 영역만 브랜드 로고로 교체
- 배경, 타입 텍스트, 배치 등 나머지는 원본 그대로 유지
- 로고는 비율을 유지하며 적절한 크기로 배치

## 표지 레이아웃 타입

**01·02 페이지**(각 시안의 표지 + 브랜드·시즌 소개)는 화보를 배경으로 로고·텍스트를 얹는 표지 성격의 페이지입니다. 화보 처리 방식에 따라 네 가지 타입으로 구분합니다.

- **thin frame / clean**: 화보를 풀블리드(꽉 채움)로 깔고 로고·서브텍스트를 화보 위에 **오버레이**. 둘의 차이는 페이지 **바깥쪽 외곽선(테두리) 유무** (thin frame=있음 / clean=없음).
- **thick frame**: 화보를 페이지 안쪽에 **두꺼운 여백(프레임)**을 두고 배치하고, 로고를 화보 **바깥 흰 여백**에 배치 (오버레이 아님). → 내지는 **03-basic-frame과 기본 세트**.
- **blur BG**: **블러+확대**된 화보를 배경으로, 선명한 화보(**내부 이미지 프레임**)와 로고·서브타이틀을 올림 (주로 01 표지 / 03-swp-blur BG와 유사).

### thin frame type
화보 위에 로고·서브텍스트를 오버레이하고, 페이지 **바깥쪽에 얇은 외곽선(테두리)**을 둡니다.

![[ref-표지-frame-01.png]]

### clean type
화보 위에 로고·서브텍스트를 오버레이하며, **외곽선 없이** 마감합니다.

![[ref-표지-clean-01.png]]

### thick frame type
화보를 페이지 안쪽에 **두꺼운 여백(프레임)**을 두고 배치하고, 로고는 화보 **바깥 흰 여백**에 놓습니다. (thin frame/clean과 달리 오버레이가 아님) — 주로 **01 표지**에 사용하며, **내지는 03-basic-frame과 기본 세트**(화보 여백 프레임 구조를 공유, 강제는 아님).

**치수** (페이지 380 × 580 기준, 괄호는 가로폭 대비 비율)
- **화보 영역**: 폭 약 332 (**87%**) · 좌우 여백 각 약 24 (**6%**) · 높이 약 486
- **로고**: 폭 약 142 (**37%**) · 높이 약 26 · **중앙 정렬**
- **로고 위치는 모델 얼굴의 상단 여백에 따라 결정하며, 기본은 하단**:
  - **하단 (기본)**: 화보 상단 여백 약 24 / 화보 하단↔로고 간격 약 22 / 로고 하단 여백 약 22 → *모델 얼굴이 화보 상단에 가까울 때*
  - **상단**: 화보 상단 여백 약 70(로고 공간 확보) / 로고 상단 여백 약 24 / 로고↔화보 간격 약 20 → *화보 상단에 여백이 있을 때*

![[ref-표지-thick-frame.png]]
*왼쪽: 로고 하단(기본) / 오른쪽: 로고 상단*

- **내부 이미지 프레임(화보) border radius** 적용 가능 — 기본 0, 적용 시 12 / 강조 20~40 ([[공통.md]] 참고)

### blur BG type
**블러 + 확대**된 화보를 배경으로 깔고, 그 위에 **선명한 화보(내부 이미지 프레임)** + 로고 + 서브타이틀을 올립니다. (주로 **01 표지** / 03-swp-blur BG와 유사한 구조)

**변형 3종** (이미지 좌→우):
1. **로고 볼드** — 큰 로고(약 169 × 71) 상단 + 서브타이틀 하단
2. **로고 미니멀** — 작은 로고(약 93 × 39) 상단 + 서브타이틀 하단
3. **서브타이틀 없음** — 로고 하단(약 104 × 44), 내부 화보 영역을 더 크게

**치수** (380 × 580): 내부 이미지 프레임 폭 약 340 · 좌우 여백 약 20

- **내부 이미지 프레임(화보) border radius** 적용 가능 — 기본 0, 적용 시 12 / 강조 20~40 ([[공통.md]] 참고)

![[ref-01-blur-bg.png]]
*좌→우: 로고 볼드 / 로고 미니멀 / 서브타이틀 없음*

### 공통 핵심 원칙 (가장 중요)

> **레이아웃 유형 결정의 1순위 = 배경 화보의 여백** (01·02 공통)  
> 모델의 **얼굴이 상단·양옆에서 얼마나 떨어져 있는지**에 따라 로고·텍스트의 위치(상단 / 하단 / 상단 좌측 등)를 결정합니다.

1. **화보의 여백(모델 얼굴 위치)에 따라 레이아웃 유형을 결정할 것**
   - 얼굴이 상단에 가까우면 → 로고·텍스트를 **하단**에
   - 상단에 여백이 많으면 → 로고를 **상단**에
   - 모델이 한쪽(예: 우측)에 치우치면 → 반대쪽(좌측) 여백에 **상단 좌측** 등으로 배치
2. **로고가 화보의 중요 부분(모델 얼굴 등)을 가리지 않을 것** — 화보 크기 또는 로고 위치를 조정해 해결
3. **로고와 서브타이틀 텍스트는 동일한 컬러를 사용할 것** — 기본 흰색, 아주 밝은 화보에서만 검정. 밝은 배경과 겹쳐 가독성이 떨어지면 그림자를 추가(값은 01 섹션 「컬러 & 그림자」 참고)
4. **서브텍스트 양(행 수)에 따라 레이아웃을 결정할 것** — 텍스트가 길어지면 텍스트 블록 영역을 충분히 확보

> **원칙**: 01·02 페이지는 **같은 타입으로 통일**하는 것을 권장합니다. 요청이 있을 경우 혼합 사용도 가능합니다.

## 페이지별 규칙

> A안·B안은 아래 구성요소를 **동일하게** 포함하며, 레이아웃 변형(타입·로고 위치·정렬 등) 중 **2가지를 선택**해 서로 다른 디자인으로 제작합니다.

> · **시즌명**: 예) `26 SPRING COLLECTION`

> · **시즌 설명**: 콘셉트 본문 텍스트 (예: "견고한 구조와 유연함이 공존하는…")

### 01 — 각 시안의 표지

**핵심**: 실제 콘텐츠의 시작을 알리는 표지 페이지

**필수 요소**: 배경 화보, 로고  
**선택 요소**: 시즌명, 시즌 타이틀  
**오버레이**: 없음 (화보 위에 로고·텍스트 직접 오버레이)

**컬러 & 그림자**:
- 로고·텍스트는 **동일 컬러**, **기본은 흰색(white)**
- 배경 화보가 **아주 밝은 경우에만 검정** 사용 (밝음의 기준 = **01-D 묶음·하단 예시**, thin frame 모음 참고)
- 로고/텍스트의 **일부라도 밝은 배경과 겹쳐 가독성이 떨어지면 그림자를 반드시 추가**
  - **Drop Shadow**: 색 `#000000` 15% · 오프셋 X·Y `0` · Blur `40` · Spread `0`
  - 그림자는 로고·텍스트 **각 요소(위치)별로** 필요한 경우에만 적용

**레이아웃 유형** (thin frame / clean 공통 적용):

| 유형 | 로고 위치 | 시즌명·타이틀 | 결합 방식 |
|------|-----------|---------------|-----------|
| **01-A** 로고 상단 | 상단 (중앙 또는 좌측) | 하단에 별도 배치 | 로고·텍스트 분리 |
| **01-B** 로고 중앙 | 화면 중앙 | 하단에 별도 배치 | 로고·텍스트 분리 |
| **01-C** 묶음·중앙 | 중앙 | 로고 바로 아래 시즌명 | 로고+시즌명 한 그룹 |
| **01-D** 묶음·하단 | 하단 | 로고 바로 아래 시즌명 | 로고+시즌명 한 그룹 |

![[ref-01-thin-frame.png]]

**clean 유형 모음** (외곽선 X)

> 개별 유형(01-A~D)의 분류는 위 표를 참고하세요.

**치수 가이드** (px) — 중앙 배치는 좌우 대칭이므로 좌우 여백 생략
- **좌측 정렬 시 좌측 여백**: 약 36~40
- **01-A**: 로고 상단 여백 약 60 / 하단 시즌명·타이틀 하단 여백 약 33

- **01-C**: 로고+시즌명 그룹 세로 중앙 / 그룹 내 로고–시즌명 간격 약 8
- **01-D**: 로고+시즌명 그룹 하단 여백 약 40

> 분리형(01-A·B)은 시즌명 + 시즌 타이틀을 함께 노출, 묶음형(01-C·D)은 로고 + 시즌명만 노출하는 경향. 로고 위치·정렬은 화보의 여백·구도에 맞춰 선택합니다.

> **thick frame 적용 시**: 위 01-A~D(thin frame / clean 기준) 대신 「표지 레이아웃 타입」의 thick frame 규칙(화보 여백 프레임 + 로고 기본 하단)을 따르며, 내지(03)는 **03-basic-frame과 기본 세트**로 사용합니다 (강제 아님).

### 02 — 브랜드 및 시즌 컬렉션 소개

**핵심**: 브랜드 스토리 + 시즌 콘셉트 상세 설명

**필수 요소**: 배경 화보 + **`#000000` dim 오버레이**, 로고, 시즌 설명 텍스트  
**선택 요소**: 시즌명, 시즌 타이틀  
**오버레이**: 화보 전체에 검정 dim을 깔아 텍스트 가독성 확보
- 기본값 **40%**
- 배경 화보의 밝기에 따라 투명도 조정 가능 (밝은 화보일수록 진하게 — 예: 60%, 어두운 화보는 더 옅게)

**텍스트 블록 구성** (위→아래)
- **기본형**: 시즌명 → (시즌 타이틀) → 시즌 설명
- **본문 전용형**: 시즌 설명만 (시즌명·시즌 타이틀 모두 생략) — *시즌 타이틀이 없는 경우 사용*

> **줄바꿈**: 02는 여백을 여유 있게 사용하는 페이지이므로, 행마다 적절한 width를 유지하도록 **단어 단위로 줄바꿈**합니다 (단어 중간에서 끊기지 않게).

**레이아웃 유형** (thin frame / clean 공통 적용):

| 유형       | 텍스트 정렬 | 로고 위치 | 텍스트 구성             |
| -------- | ------ | ----- | ------------------ |
| **02-A** | 중앙 정렬  | 하단    | 기본형                |
| **02-B** | 중앙 정렬  | 상단    | 기본형                |
| **02-C** | 좌측 정렬  | 상단    | 기본형                |
| **02-D** | 중앙 정렬  | 상단    | 본문 전용 (시즌명·타이틀 생략) |

> 기본형 = 시즌명 → (시즌 타이틀) → 시즌 설명 / 본문 전용형 = 시즌/브랜드 설명만

**thin frame 유형 모음** (외곽선 O — 좌→우: 02-A 중앙·로고하단 / 02-B 중앙·로고상단 / 02-C 좌측·로고상단 / 02-D 본문 전용)
![[ref-02-thin-frame.png]]

**clean 유형 모음** (외곽선 X)
![[ref-02-clean.png]]

- **로고**: 상단 중앙, 약 146 × 20, 상단 여백 약 120

**치수 가이드** (px) — 중앙 배치는 좌우 대칭이므로 좌우 여백 생략
- **텍스트 블록 폭**: 약 251 (좌측 정렬 시 좌측 여백 약 40)
- **텍스트 블록 세로**: 상단에서 약 214부터 시작 (본문 분량에 따라 가변) / 시즌명그룹–시즌 설명 간격 약 18
- **로고**: 하단형 하단 여백 약 55 / 상단형 상단 여백 약 50 / 좌측 정렬 시 좌측 여백 약 40

> 시즌 설명 분량(행 수)에 맞춰 텍스트 블록 크기·위치를 조정합니다. 01과 동일한 표지 레이아웃 타입(thin frame / clean) 사용을 권장합니다.

---

### 03 — 내지 (화보 및 상품 정보)

**핵심**: 대표 상품 화보 + 상품 정보 제공

**구성 요소**: 상품 화보 이미지 / 상품명 / 가격 (+ 카테고리)

03 내지는 **basic(스크롤 없음)**과 **swp(좌우 스와이프)** 두 그룹으로 나뉩니다.

---

### basic (스크롤 없음, 페이지 580px 고정)

#### 03-basic-full — 화보 풀블리드 + 정보 오버레이
- 화보를 페이지 전체에 **풀블리드**로 깔고, 상품 정보를 화보 위 **상단에 오버레이**
- **상품 정보의 위치·정렬은 화보 내 여백에 따라 결정** — 모델이 좌측에 있으면 우측(우측 정렬), 우측에 있으면 좌측(좌측 정렬)에 배치
- 구성: 상품명 + 가격 (여러 상품 세로 나열 가능)
- 정보 블록: 폭 약 104 · 상단 여백 약 20 · 좌/우 여백 약 20

![[ref-03-basic-full.png]]

#### 03-basic-frame — 화보 여백 프레임 + 하단 정보
> 표지 **01의 thick frame 유형과 기본 세트** (화보 여백 프레임 구조를 공유). 단, 반드시 함께 쓸 필요는 없음.

- 화보를 **두꺼운 여백 프레임** 안에 배치 (thick frame과 동일 구조: 좌우·상단 여백 약 24, 폭 약 332)
- **로고**: 하단 중앙 (약 146 × 18)
- **상품 정보**: 하단에 **풀폭(약 320)** 배치 — 좌측=상품명 / 우측=가격 (양끝 정렬), 각 행 약 18 높이
- **텍스트 행에 가로 여유가 있어 옷 카테고리(SUIT, SHIRT, PANTS 등)를 상품명 앞에 포함**

![[ref-03-basic-frame.png]]

#### basic 공통 — 텍스트·여백·배경

**상품 정보 텍스트** (폰트: Pretendard)
| 요소 | 두께 | 크기 | 색상 | 정렬 |
|------|------|------|------|------|
| 상품명 | SemiBold | 11px | `#141414` | full=우측 / frame=좌측 |
| 가격 | Regular | 11px | full `#4A4A4A` / frame `#141414` | 우측 |

- 자간(letter-spacing) **−2%** / 행간 full **140%**, frame **160%**
- **그림자 없음** (검정 텍스트 · 밝은 화보 기준)
- **배경**: basic-frame 여백 영역 = **흰색 `#FFFFFF`** (basic-full은 화보 풀블리드라 별도 배경 없음)
- basic-frame은 카테고리(SemiBold) + 상품명(Regular)을 한 행에, 가격은 우측 끝 정렬

### swp (좌우 스와이프)

**BG 페이지는 고정**, swp 페이지(**CdBd 갤러리 카드**)만 좌우로 스와이핑되는 구조입니다. BG는 페이지 배경이 됩니다.

- **파일명**: 프레임명 기준 — `03-BG`, `03-swp1`, `03-swp2` …
- **swp 페이지 내부 프레임 border radius** 적용 가능 (clean/blur 공통) — 기본 0, 적용 시 12 / 강조 20~40 ([[공통.md]] 참고)

#### 03-swp-clean BG
- **BG**: 선명한 화보 이미지를 배경으로, 상단에 **배경과 함께 고정되는 로고(좌측)·서브타이틀(우측)**
- **swp1**(갤러리 카드 첫 이미지): **투명 이미지** — 화보가 먼저 보여야 하므로
- **swp2~**: 상품 갤러리 카드 (상품 이미지 + 상품명/가격)

![[ref-03-swp-clean-bg.png]]

#### 03-swp-blur BG
- **BG**: **블러 + 확대 + dim** 가공된 화보 이미지
- **swp1**(갤러리 카드 첫 장): **선명한 화보 이미지**
  - 첫 장 하단에 로고가 **있을 수도, 없을 수도** 있음
  - 로고가 **없는 경우**: 내부 프레임(fill 있는 박스)을 **중앙 정렬**
- **swp2~**: 상품 갤러리 카드

![[ref-03-swp-blur-bg.png]]

#### swp 공통 — 텍스트·배경

**갤러리 카드 텍스트** (CdBd 갤러리 카드 기본 폰트 = **AktivGrotesk**)
| 요소 | 두께 | 크기 | 색상 |
|------|------|------|------|
| BG 서브타이틀 | Medium | 12px | 검정 |
| 상품명 | Medium | 10px | 검정 |
| 가격 | Light | 10px | 검정 |

- 자간 **−2%** / 행간 **130%** / 갤러리 카드 텍스트 **중앙 정렬**
- **배경**:
  - clean BG 페이지 ≈ `#FAFAFA`
  - **갤러리 카드(swp 페이지 내부 프레임) 배경**: **그라데이션 없음이 기본**. 브랜드·시즌 톤에 맞춰 그라데이션을 넣을 수도 있음 (예: 연블루 → 흰색) — 단, **상품 누끼가 묻히지 않도록 매우 밝게** 적용

> swp는 CdBd 갤러리 카드를 사용하므로 기본 폰트가 **AktivGrotesk**입니다 (basic의 Pretendard와 다름).

## 작업 체크리스트

### 안 구성 확인
- [ ] A안·B안의 구성요소·내용이 동일한가
- [ ] A안·B안이 서로 다른 레이아웃/디자인 2가지를 채택했는가
- [ ] 01·02 페이지의 표지 레이아웃 타입(thin frame / clean / thick frame)이 (안 내에서) 통일되었는가

### 표지 레이아웃 핵심 원칙 확인
- [ ] 로고가 화보의 중요 부분(모델 얼굴 등)을 가리지 않는가
- [ ] 로고와 서브타이틀 텍스트가 동일 컬러인가
- [ ] 서브텍스트 행 수에 맞춰 레이아웃을 결정했는가
- [ ] 화보 여백이 많은 쪽에 로고·텍스트를 배치했는가

### 시안 표지 확인
- [ ] 피그마 기준 화면 사용, 로고만 교체
- [ ] 배경/타입 텍스트/배치는 원본과 동일

### 페이지별 확인
- [ ] 각 페이지 필수 요소 포함
- [ ] 이미지 비율 및 해상도 확인
- [ ] 텍스트 오타 검수 / 가독성 확인

### 전체 스타일 확인
- [ ] 각 안 내 색상 팔레트 일관성 유지
- [ ] 폰트 사이즈/두께 규칙 준수
