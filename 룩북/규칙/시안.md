**작성일**: 2026-05-28

## 개요

**시안이란**: 2가지 Type (A, B) × 각 4페이지로 클라이언트에게 레이아웃/스타일 옵션 제시  
**총 페이지**: Type A 4페이지 + Type B 4페이지 (총 8페이지)  
**목적**: 디자인 방향성 선택 & 피드백 수집  
**완성 후**: 선택된 Type을 기반으로 초안(전체 페이지) 제작

### 각 시안의 페이지 구성
1. **Page 1**: 시안 표지 (로고 + 타입 표시)
2. **Page 2**: 각 시안의 표지 (실제 콘텐츠 시작)
3. **Page 3**: 브랜드 및 시즌 컬렉션 소개
4. **Page 4**: 내지 (화보 및 상품 정보)

## 표지 레이아웃 타입 (frame / clean)

**01·02 페이지**(각 시안의 표지 + 브랜드·시즌 소개)는 화보를 배경으로 로고·텍스트를 얹는 표지 성격의 페이지입니다. 화보 처리 방식에 따라 두 가지 타입으로 구분합니다.

> **원칙**: 01·02 페이지는 **같은 타입으로 통일**하는 것을 권장합니다. 요청이 있을 경우 혼합 사용도 가능합니다.

### frame type
화보를 프레임(여백) 안에 담고, 로고·서브텍스트는 화보 **바깥 여백 영역**에 배치합니다.
- 화보가 페이지를 꽉 채우지 않고 상/하(또는 사방)에 여백을 둠
- 로고·텍스트가 화보를 가리지 않아 깔끔하게 분리되는 인상

![[ref-표지-frame-01.png]]

### clean type
화보를 **풀블리드(꽉 채움)**로 깔고, 로고·서브텍스트를 화보 위에 **오버레이**합니다.
- 화보의 여백이 많은 영역(빈 공간/단순한 배경)에 텍스트를 배치
- 몰입감 있는 비주얼 인상

![[ref-표지-clean-01.png]]

### 공통 핵심 원칙 (가장 중요)

1. **로고가 화보의 중요 부분(모델 얼굴 등)을 가리지 않을 것** — 화보 크기 또는 로고 위치를 조정해 해결
2. **로고와 서브타이틀 텍스트는 동일한 컬러를 사용할 것**
3. **서브텍스트 양(행 수)에 따라 레이아웃을 결정할 것** — 텍스트가 길어지면 텍스트 블록 영역을 충분히 확보
4. **화보 스타일(여백이 많은 방향)에 따라 레이아웃을 결정할 것** — 로고·텍스트를 화보의 여백이 많은 쪽에 배치

### 페이지별 구성 & 변형

#### 01 페이지 — 각 시안의 표지
- **요소**: 로고 + 짧은 서브타이틀(컬렉션명, 예: `26 SPRING COLLECTION`)
- **로고 위치 변형**: 상단 / 중앙 / 하단 (화보 여백에 맞춰 선택)

#### 02 페이지 — 브랜드 및 시즌 소개
- **요소**: 타이틀(컬렉션명 + 슬로건) + 본문 설명문(여러 줄) + 로고
- **텍스트 정렬 변형**: 중앙 정렬 / 좌측 정렬
- **로고 위치 변형**: 상단 / 하단
- 본문 분량(행 수)에 맞춰 텍스트 블록 위치·크기 조정

| 중앙 정렬 (모델 중앙·여백 상하) | 좌측 정렬 (모델 우측·여백 좌측) |
|---|---|
| ![[ref-표지-02-center.png]] | ![[ref-표지-02-left.png]] |
