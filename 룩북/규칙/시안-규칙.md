# 룩북 시안 규칙

**작성일**: 2026-05-28  
**상태**: Draft (피그마 상세 레이아웃 대기 중)

---

## 개요

**시안이란**: 2가지 Type (A, B) × 각 4페이지로 클라이언트에게 레이아웃/스타일 옵션 제시  
**총 페이지**: Type A 4페이지 + Type B 4페이지 (총 8페이지)  
**목적**: 디자인 방향성 선택 & 피드백 수집  
**완성 후**: 선택된 Type을 기반으로 초안(전체 페이지) 제작

### 각 시안의 페이지 구성
1. **Page 1**: 시안 표지 (로고 + 타입 표시)
2. **Page 2**: 각 시안의 표지 (실제 콘텐츠 시작)
3. **Page 3**: 브랜드 및 시즌 컬렉션 소개
4. **Page 4**: 내지 (화보 및 상품 정보)
