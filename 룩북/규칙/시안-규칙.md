# 룩북 시안 규칙

**작성일**: 2026-05-28  
**상태**: Draft (피그마 상세 레이아웃 대기 중)

---

## 개요

**시안이란**: 2가지 Type (A, B) × 각 4페이지로 클라이언트에게 레이아웃/스타일 옵션 제시  
**총 페이지**: Type A 4페이지 + Type B 4페이지 (총 8페이지)  
**목적**: 디자인 방향성 선택 & 피드백 수집  
**완성 후**: 선택된 Type을 기반으로 초안(전체 페이지) 제작

### 각 시안의 페이지 구성
1. **Page 1**: 표지 (로고 + 타입 표시)
2. **Page 2**: 브랜드 & 시즌 컬렉션 소개
3. **Page 3**: 내지 - 화보 및 상품 정보 (1)
4. **Page 4**: 내지 - 화보 및 상품 정보 (2)

## 표지 (Page 1) 레이아웃 규칙

### 기본 원칙
- **피그마 제공 화면을 기본 템플릿으로 사용**
- **변경 부분**: 로고 영역만 브랜드 로고로 교체
- **유지 부분**: 배경, TYPE 텍스트, 전체 배치 등 모두 동일 유지

### 로고 배치
- **위치**: 페이지 상단에 충분한 여백을 두고 중앙 정렬
- **크기**: 로고 비율을 유지하며 적절한 크기로 배치
- **처리**: 브랜드 가이드에 따라 흑백/컬러/배경 처리

### 타입 표시
- **Type A**: 페이지 하단에 "TYPE - A" 텍스트 표시
- **Type B**: 페이지 하단에 "TYPE - B" 텍스트 표시
