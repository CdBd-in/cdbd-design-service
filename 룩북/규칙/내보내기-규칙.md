# 내보내기 규칙

**작성일**: 2026-05-28  
**적용 범위**: 시안, 초안 모든 페이지

---

## 개요

**목적**: 모든 룩북 페이지를 일관된 형식으로 내보내기하여 배포/인쇄 품질 보장

### 적용 대상
- ✅ 시안 (Type A, B 모든 페이지)
- ✅ 초안 (모든 페이지)

---

## 기본 설정

### 해상도
| 항목 | 값 |
|------|-----|
| **배수** | 3배 해상도 |
| **계산** | 페이지 너비 380px × 3 = **1140px** |
| **적용** | 모든 페이지 동일 적용 |

---

## 파일 형식 규칙

### JPG 포맷
**용도**: 배경이 있는 이미지, 사진 기반 페이지

**파일명 형식**:
```
[프로젝트명]_[타입]_[페이지번호].jpg
예: prendang_typeA_01.jpg
    prendang_typeA_02.jpg
```

**내보내기 옵션**:
- 품질: 90% 이상
- 색상 프로파일: sRGB
- 메타데이터: 필요시 포함

---

### PNG 포맷
**용도**: 배경이 투명한 이미지, 그래픽 기반 페이지

**파일명 형식**:
```
[프로젝트명]_[타입]_[페이지번호]_transparent.png
예: prendang_typeA_02_transparent.png
```

**내보내기 옵션**:
- 배경: 투명(Transparent)
- 색상 프로파일: sRGB
- 최적화: 활성화

---

## 파일명 규칙

### 기본 구조
```
[프로젝트명]_[타입]_[페이지번호].[확장자]
```

### 각 항목별 규칙

#### 프로젝트명
- 클라이언트명 또는 브랜드명 (영문 소문자)
- 예: prendang, lilly, zara

#### 타입
**시안**:
- `typeA` (Type A 시안)
- `typeB` (Type B 시안)

**초안**:
- `draft` (초안, 기본)
- 또는 선택된 Type 명시: `draftA`, `draftB`

#### 페이지번호
- 2자리 숫자
- `01`, `02`, `03`, ... `20`

#### 확장자
- `.jpg` (배경 있음)
- `.png` (투명 배경)

### 파일명 예시

**시안**:
```
prendang_typeA_01.jpg   (Page 1 시안표지)
prendang_typeA_02.jpg   (Page 2 각시안표지)
prendang_typeA_03.jpg   (Page 3 브랜드소개)
prendang_typeA_04.jpg   (Page 4 내지)
prendang_typeB_01.jpg   (Page 1 시안표지)
prendang_typeB_02.jpg   (Page 2 각시안표지)
...
```

**초안**:
```
prendang_draft_01.jpg   (Page 1 표지)
prendang_draft_02.jpg   (Page 2 컬렉션소개)
prendang_draft_03.jpg   (Page 3 상품1)
prendang_draft_04.jpg   (Page 4 상품2)
...
```

## 저장 위치

### 폴더 구조
```
룩북/
├── 결과물/
│   ├── 시안_A/
│   │   ├── prendang_typeA_01.jpg
│   │   ├── prendang_typeA_02.jpg
│   │   └── ...
│   ├── 시안_B/
│   │   ├── prendang_typeB_01.jpg
│   │   └── ...
│   └── 초안/
│       ├── prendang_draft_01.jpg
│       ├── prendang_draft_02.jpg
│       └── ...
├── 규칙/
└── ...
```

### 폴더 생성 규칙
- 시안: `결과물/시안_A`, `결과물/시안_B`
- 초안: `결과물/초안`

## 내보내기 체크리스트

### 내보내기 전 확인
- [ ] 모든 페이지가 완성되었는가?
- [ ] 3배 해상도(1140px 기준)로 설정했는가?
- [ ] 배경 유무 확인: 투명 또는 배경색?
- [ ] 페이지 번호 순서가 맞는가?

### JPG 내보내기
- [ ] 품질 90% 이상으로 설정
- [ ] sRGB 색상 프로파일 선택
- [ ] 파일명 형식 확인: `[프로젝트]_[타입]_[번호].jpg`
- [ ] 저장 위치 확인: 해당 폴더(`시안_A`, `시안_B`, 또는 `초안`)

### PNG 내보내기 (투명 배경)
- [ ] 투명 배경 설정 확인
- [ ] sRGB 색상 프로파일 선택
- [ ] 파일명 형식 확인: `[프로젝트]_[타입]_[번호]_transparent.png`
- [ ] 저장 위치 확인

### 내보내기 후 확인
- [ ] 모든 파일이 정상적으로 저장되었는가?
- [ ] 파일 사이즈가 적절한가?
  - JPG: 200KB~500KB (페이지당)
  - PNG: 300KB~800KB (페이지당)
- [ ] 이미지 품질 육안 확인
- [ ] 파일명 오타 검수

## 해상도 참고

### 페이지 규격별 내보내기 크기

| 항목 | 1배 해상도 | 3배 해상도 |
|------|-----------|-----------|
| **너비** | 380px | 1140px |
| **기본 높이** | 580px | 1740px |
| **확장 높이** | 580px+ | 1740px+ |

### 3배 해상도 선택 이유
- ✅ 인쇄 품질 (300DPI 기준)
- ✅ 화면 표시 품질 (Retina 디스플레이 대응)
- ✅ 향후 확대 사용 시 품질 보장
- ✅ 디지털 배포 최적화

## 파일 형식 선택 가이드

### JPG 사용
```
✓ 배경이 있는 모든 페이지
✓ 사진/화보가 포함된 페이지
✓ 배경색이 있는 페이지

예:
- 시안 표지 (배경 색상)
- 상품 화보 페이지
- 컬러풀한 배경이 있는 페이지
```

### PNG 사용
```
✓ 배경이 투명한 페이지만
✓ 그래픽 요소만 있는 페이지
✓ 배경 없이 콘텐츠만 필요한 경우

예:
- 특수한 배경 처리가 필요한 페이지
- 투명 배경 위에 겹쳐서 사용할 페이지
- (일반적으로 시안/초안에서는 드문 경우)
```

## 품질 보증 기준

### JPG 품질 기준
- 품질: 90% 이상
- 파일 사이즈: 페이지당 200KB~500KB
- 압축 손실: 육안으로 확인 불가

### PNG 품질 기준
- 압축: 최적화된 무손실 압축
- 파일 사이즈: 페이지당 300KB~800KB
- 투명도: 완벽한 투명 배경
