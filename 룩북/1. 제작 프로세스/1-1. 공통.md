## 내보내기 규칙

### 해상도
| 항목     | 값                             |
| ------ | ----------------------------- |
| **배수** | 3배 해상도                        |
| **계산** | 페이지 너비 380px × 3 = **1140px** |
| **적용** | 모든 페이지 동일 적용                  |

### 파일 형식

#### JPG 포맷
**용도**: 배경이 있는 이미지, 사진 기반 페이지

**파일명 형식**:
```
[타입][페이지번호][-세부].jpg
예: A01.jpg
    A02-1.jpg
    A04-btn.jpg
    01.jpg (초안)
```

**내보내기 옵션**:
- 품질: 90% 이상
- 색상 프로파일: sRGB
- 메타데이터: 필요시 포함

#### PNG 포맷
**용도**: 배경이 투명한 이미지, 그래픽 기반 페이지

**파일명 형식**:
```
[타입][페이지번호][-세부].png
예: A03-insta.png
    A04-logo.png
    05-call.png (초안)
```

**내보내기 옵션**:
- 배경: 투명(Transparent)
- 색상 프로파일: sRGB
- 최적화: 활성화

#### 파일 형식 선택 가이드

**JPG 사용**
```
✓ 배경이 있는 모든 페이지
✓ 사진/화보가 포함된 페이지
✓ 배경색이 있는 페이지

예:
- 시안 표지 (배경 색상)
- 상품 화보 페이지
- 컬러풀한 배경이 있는 페이지
```

**PNG 사용**
```
✓ 배경이 투명한 페이지만
✓ 그래픽 요소만 있는 페이지
✓ 배경 없이 콘텐츠만 필요한 경우

예:
- 특수한 배경 처리가 필요한 페이지
- 투명 배경 위에 겹쳐서 사용할 페이지
- (일반적으로 시안/초안에서는 드문 경우)
```

### 파일명

#### 기본 구조
```
[타입][페이지번호][-세부].[확장자]
```

#### 각 항목별 규칙

##### 타입 & 페이지번호

**시안** (각 Type = 표지 + 01·02·03):
- `A` / `B` : 시안 표지 (TYPE-A/B 구분)
- `A01`~`A03` : Type A의 01(각 시안의 표지) · 02(브랜드·시즌 소개) · 03(내지)
- `B01`~`B03` : Type B의 01 · 02 · 03

**초안**:
- `01`, `02`, `03`, ... : 순차적 페이지 번호

**OG 이미지(썸네일)**:
- `og` : 로고/룩 타입 공통 (1배수 JPG)

**스와이프(swp) 내지** (03 swp 타입 — 프레임명 기준):
- `03-BG` : 고정 배경
- `03-swp1`, `03-swp2`, … : 좌우 스와이프 갤러리 카드

**스크롤(scl) 내지** (03 scl 타입 — 03 프레임 내 요소별 개별 내보내기):
- 각 요소를 **사이즈 그대로 · 3배 해상도**로 내보냄
- 파일명 = 프레임명과 동일 — `03-1-1`, `03-1-2`, `03-2-1` …

##### 세부 구분 (선택)

한 페이지가 여러 이미지로 나뉘는 경우:

**다중 섹션**:
```
A01-1, A01-2, A01-3
(Page A01이 3개의 섹션으로 나뉜 경우)
```

**고정 영역 (플로팅)**:
```
A01-top, A01-bottom
(Page A01의 상단/하단 고정 요소)
```

**역할 명확한 요소** (버튼, SNS 아이콘 등):
```
A01-btn      (버튼)
A01-home     (홈 화면 요소)
A01-insta    (인스타그램 아이콘/링크)
A01-call     (전화 연결 요소)
A01-logo     (로고)
A01-icon     (아이콘)
```

##### 확장자
- `.jpg` (배경 있음)
- `.png` (투명 배경)

#### 파일명 예시

**시안 - 기본**:
```
A.jpg          (Type A 시안표지)
A01.jpg        (01 - 각 시안의 표지)
A02.jpg        (02 - 브랜드·시즌 소개)

```

## 저장 위치

내보낸 결과물은 **로컬 데스크탑**에 **브랜드명(국문)** 폴더를 만들고, 그 아래 **시안 / 초안** 두 폴더에만 저장합니다.

### 폴더 구조
```
~/Desktop/  (로컬 데스크탑 / 바탕화면)
└── 브랜드명(국문)/          ← 예: 쁘렝땅
    ├── 시안/                A·A01~A03 · B·B01~B03 (+ og.jpg)
    │   ├── A.jpg  A01.jpg  A02.jpg  A03.jpg
    │   ├── B.jpg  B01.jpg  B02.jpg  B03.jpg
    │   └── og.jpg
    └── 초안/                01·02·03 …
        ├── 01.jpg  02.jpg  03.jpg
        └── ...
```

### 폴더 생성 규칙
- 로컬 **데스크탑**에 **브랜드명(국문)** 폴더 생성 (예: `프렌당`)
- 그 아래 **시안**, **초안** 2개 폴더만 생성
- **시안**: A안·B안 결과물을 한 `시안` 폴더에 함께 저장 (파일명 `A*`/`B*`로 구분)
- **초안**: `초안` 폴더에 순차 저장
