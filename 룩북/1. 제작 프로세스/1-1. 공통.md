## OG 이미지(썸네일) 규칙

콘텐츠를 공유할 때 노출되는 썸네일(OG 이미지) 규칙.

### 규격
| 항목 | 값 |
|------|-----|
| 사이즈 | 800px × 400px (2:1 비율) |

### 타입

**별도의 요청이 없는 한, 로고 타입을 기본값으로 사용합니다.**

#### 1. 로고 타입 (기본값)
단색 배경 위에 브랜드 로고를 배치

- **정렬**: 수직·수평 중앙 정렬
- **로고 너비** (OG 가로폭 800px 기준):

| 로고 형태         | 예시                        | 너비 비율        |
| ------------- | ------------------------- | ------------ |
| **가로로 긴 로고**  | PRENDANG 같은 워드마크          | 약 **60%**    |
| **가로가 짧은 로고** | 글자 수가 짧은 워드마크 혹은 하이브리드 로고 | 약 **40~50%** |

#### 2. 룩(이미지) 타입
대표 화보 이미지를 OG 영역에 배치
- 별도 요청이 있는 경우 사용

## 파일 형식 규칙

### JPG 포맷
**용도**: 배경이 있는 이미지, 사진 기반 페이지

**파일명 형식**:
```
[타입][페이지번호][-세부].jpg
예: A01.jpg
    A02-1.jpg
    A04-btn.jpg
    01.jpg (초안)
```

**내보내기 옵션**:
- 품질: 90% 이상
- 색상 프로파일: sRGB
- 메타데이터: 필요시 포함

---

### PNG 포맷
**용도**: 배경이 투명한 이미지, 그래픽 기반 페이지

**파일명 형식**:
```
[타입][페이지번호][-세부].png
예: A03-insta.png
    A04-logo.png
    05-call.png (초안)
```

**내보내기 옵션**:
- 배경: 투명(Transparent)
- 색상 프로파일: sRGB
- 최적화: 활성화

## 파일명 규칙

### 기본 구조
```
[타입][페이지번호][-세부].[확장자]
```

### 각 항목별 규칙

#### 타입 & 페이지번호

**시안** (각 Type = 표지 + 01·02·03):
- `A` / `B` : 시안 표지 (TYPE-A/B 구분)
- `A01`~`A03` : Type A의 01(각 시안의 표지) · 02(브랜드·시즌 소개) · 03(내지)
- `B01`~`B03` : Type B의 01 · 02 · 03

**초안**:
- `01`, `02`, `03`, ... : 순차적 페이지 번호

**OG 이미지(썸네일)**:
- `og` : 로고/룩 타입 공통 (1배수 JPG)

**스와이프(swp) 내지** (03 swp 타입 — 프레임명 기준):
- `03-BG` : 고정 배경
- `03-swp1`, `03-swp2`, … : 좌우 스와이프 갤러리 카드

**스크롤(scl) 내지** (03 scl 타입 — 03 프레임 내 요소별 개별 내보내기):
- 각 요소를 **사이즈 그대로 · 3배 해상도**로 내보냄
- 파일명 = 프레임명과 동일 — `03-1-1`, `03-1-2`, `03-2-1` …

#### 세부 구분 (선택)

한 페이지가 여러 이미지로 나뉘는 경우:

**다중 섹션**:
```
A01-1, A01-2, A01-3
(Page A01이 3개의 섹션으로 나뉜 경우)
```

**고정 영역 (플로팅)**:
```
A01-top, A01-bottom
(Page A01의 상단/하단 고정 요소)
```

**역할 명확한 요소** (버튼, SNS 아이콘 등):
```
A01-btn      (버튼)
A01-home     (홈 화면 요소)
A01-insta    (인스타그램 아이콘/링크)
A01-call     (전화 연결 요소)
A01-logo     (로고)
A01-icon     (아이콘)
```

#### 확장자
- `.jpg` (배경 있음)
- `.png` (투명 배경)

### 파일명 예시

**시안 - 기본**:
```
A.jpg          (Type A 시안표지)
A01.jpg        (01 - 각 시안의 표지)
A02.jpg        (02 - 브랜드·시즌 소개)
A03.jpg        (03 - 내지)
B.jpg          (Type B 시안표지)
B01.jpg        (01 - 각 시안의 표지)
B02.jpg        (02 - 브랜드·시즌 소개)
B03.jpg        (03 - 내지)
```

**시안 - 세부 구분**:
```
A02-1.jpg      (Page A02의 섹션 1)
A02-2.jpg      (Page A02의 섹션 2)
A03-top.jpg    (Page A03의 상단 고정 영역)
A03-bottom.jpg (Page A03의 하단 고정 영역)
A04-btn.jpg    (Page A04의 버튼)
A04-insta.png  (Page A04의 인스타 아이콘, 투명)
```

**초안 - 기본**:
```
01.jpg         (Page 1 표지)
02.jpg         (Page 2 컬렉션소개)
03.jpg         (Page 3 상품1)
04.jpg         (Page 4 상품2)
...
```

**초안 - 세부 구분**:
```
03-1.jpg       (Page 3의 섹션 1)
03-2.jpg       (Page 3의 섹션 2)
05-top.jpg     (Page 5의 상단 고정 영역)
07-btn.jpg     (Page 7의 버튼)
10-call.png    (Page 10의 전화 요소, 투명)
```

## 파일 형식 선택 가이드

### JPG 사용
```
✓ 배경이 있는 모든 페이지
✓ 사진/화보가 포함된 페이지
✓ 배경색이 있는 페이지

예:
- 시안 표지 (배경 색상)
- 상품 화보 페이지
- 컬러풀한 배경이 있는 페이지
```

### PNG 사용
```
✓ 배경이 투명한 페이지만
✓ 그래픽 요소만 있는 페이지
✓ 배경 없이 콘텐츠만 필요한 경우

예:
- 특수한 배경 처리가 필요한 페이지
- 투명 배경 위에 겹쳐서 사용할 페이지
- (일반적으로 시안/초안에서는 드문 경우)
```

## 품질 보증 기준

### JPG 품질 기준
- 품질: 90% 이상
- 파일 사이즈: 페이지당 200KB~500KB
- 압축 손실: 육안으로 확인 불가

### PNG 품질 기준
- 압축: 최적화된 무손실 압축
- 파일 사이즈: 페이지당 300KB~800KB
- 투명도: 완벽한 투명 배경
