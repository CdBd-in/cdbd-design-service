# CdBd 콘텐츠

**작성일**: 2026-06-01
**적용 범위**: 시안·초안 모든 페이지

> 이 문서는 시안·초안의 **내보내기 결과물**이 CdBd 멀티페이지의 **어떤 카드 유형**에 **어떤 속성**으로 들어가는지 정의합니다.
> 페이지 규격·해상도·파일명·내보내기 규칙은 [[1-1. 공통]]을, 디자인 가이드(레이아웃·치수·컬러)는 [[2-1. 공통]] 및 페이지별 문서를 참고하세요.

---

## 개요

CdBd 멀티페이지는 여러 종류의 **콘텐츠 카드**를 조합해 한 페이지를 구성합니다. 룩북 디자인 결과물은 카드 단위로 내보낸 뒤, CdBd 편집기에서 각 카드 유형에 맞게 등록됩니다.

- **피그마(디자인) ↔ CdBd(렌더)**: 디자인은 카드의 시각 결과만 책임지고, **링크·구분선·gif 등 상호작용 요소는 CdBd 측이 부여**합니다.
- **내보내기 단위 = 카드 단위**: 한 페이지가 여러 카드로 구성되면 파일도 카드 수만큼 분할해 내보냅니다 (예: scl의 `03-1`, `03-2-1`, `03-2-2`…).

---

## CdBd 카드 유형

CdBd 멀티페이지에서 사용 가능한 콘텐츠 카드 유형입니다.

| 카드 유형 | 설명 | 주로 사용되는 페이지 |
|---|---|---|
| **이미지 (단일)** | 한 장의 이미지를 페이지 단위로 표시 | 01·02 / 03-basic |
| **갤러리 카드 (좌우 스와이프)** | BG 위에 카드 여러 장이 좌우로 스와이프 | 03-swp |
| **갤러리 넘겨보기 (swipe)** | 한 영역 안에서 이미지 여러 장을 좌우로 넘겨봄 | 03-scl 메인 화보(`03-1`) |
| **갤러리 그리드** | 2/3열 격자형 카드 배치 | 03-scl frame-grid2/3 · full-grid · blur-grid |
| **갤러리 나열하기 (list)** | 행 아이템을 세로로 나열 (행 사이 구분선) | 03-scl-row |
| **구분선 카드** | 동일 색·두께의 얇은 구분선 | scl-row 행 사이 (CdBd가 추가) |
| **배경 이미지** | 페이지 또는 카드의 배경 | 03-BG (페이지 BG) · 03-2-BG (카드 BG) |
| **로고 이미지** | 상단 고정 로고 | 03-scl `03-logo` |
| **「+」 gif 버튼** | 라인 마커 끝에 얹는 구매 링크 gif | 03-basic-link (CdBd가 추가) |

### 03 — basic (스크롤 없음)

basic-full / basic-frame / basic-footer / basic-link 공통: 페이지 전체 프레임(380×580)을 **1장**으로, **페이지 순서대로** 내보냅니다. 분할 없음.

| basic 유형 | 내보내기 파일 | CdBd 카드 | 속성 |
|---|---|---|---|
| basic-full | `A03.jpg` / `03.jpg` | 이미지 (단일) | (TBD) |
| basic-frame | 동일 | 이미지 (단일) | (TBD) |
| basic-footer | 동일 | 이미지 (단일) | (TBD) |
| basic-link | 동일 (**선까지만** 그린 이미지) | 이미지 (단일) + 마커별 **「+」 gif 버튼** | gif: 상품 구매 링크 연결 — (TBD) |

> ⚠️ **basic-link**: 피그마에서는 **「+」 gif를 얹지 않고 선까지만 그린 이미지**를 내보냅니다. CdBd가 추후 이미지 위에 **「+」 gif 레이어**를 얹어 **구매 링크**를 연결합니다. (선 색상·텍스트 색상 기준은 [[2-4. 화보·상품]] 「03-basic-link」 참고)

### 03 — swp (좌우 스와이프)

**BG 페이지는 고정**, swp 페이지(좌우 스와이프 카드)만 좌우로 스와이핑되는 구조.

| swp-full | `03-swp1`, `03-swp2`, … (페이지 자체가 카드) | 갤러리 카드 (좌우 스와이프) | (TBD) |

- **갤러리 카드 배경 기본값**: `#FAFAFA` (브랜드·시즌 톤 그라데이션 가능 — 단 누끼가 묻히지 않도록 **매우 밝게**)

## CdBd가 추가/조작하는 요소

피그마에서는 만들지 않고 **CdBd 측이 부여**하는 요소들. 디자이너는 CdBd가 얹을 자리만 비워두거나 표시만 합니다.

| 요소 | 어디에 | 피그마 작업 | CdBd 작업 |
|---|---|---|---|
| **「+」 gif 버튼** | 03-basic-link 마커 끝 | 선까지만 그린 이미지 내보냄 | gif 「+」 얹고 **구매 링크** 연결 |
| **구분선 카드** | 03-scl-row 행 사이 | 행 아이템만 내보냄 (구분선 X) | 동일 색·두께로 **구분선 카드** 삽입 |
| **카드 배경 (03-2-BG)** | 03-scl-full-grid · blur-grid 그리드 카드 | `03-2-BG`로 별도 내보냄 | 갤러리 그리드 카드의 **카드 배경**으로 사용 |
