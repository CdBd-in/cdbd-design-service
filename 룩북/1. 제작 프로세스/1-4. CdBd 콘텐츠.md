## 개요

CdBd 멀티페이지는 **페이지 컨테이너** 안에 **여러 페이지**가 있고, 각 페이지는 **여러 카드**로 구성됩니다. 룩북 결과물은 카드 단위로 내보낸 뒤, CdBd 에디터에서 적절한 카드에 등록합니다.

- **피그마(디자인) ↔ CdBd(렌더)**: 디자인은 카드의 시각 결과만 책임지고, **링크·구분선·gif 등 상호작용 요소는 CdBd 측이 부여**합니다.
- **내보내기 단위 = 카드 단위**: 한 페이지가 여러 카드로 구성되면 파일도 카드 수만큼 분할해 내보냅니다 (예: scl의 `03-1`, `03-2-1`, `03-2-2`…).

## 페이지 유형별 카드 매핑

각 룩북 페이지 유형이 **어떤 CdBd 카드**에 **어떤 옵션 값**으로 들어가는지. 파일명은 [[1-1. 공통]] 참고.

> **속성 표기 규칙**: `옵션명=값` 형식. 카드 디자인 옵션 중 룩북 기본값(외부여백=0 등)은 생략. (확인 필요)는 실측 미완 항목.

### 시안 표지 (`A` / `B`) · 01 · 02

각 페이지는 **1 멀티페이지 페이지**에 **1 이미지 카드**가 풀화면으로 들어감.

| 파일 | CdBd 카드 | 속성 |
|---|---|---|
| `A.jpg` / `B.jpg` (시안 표지) | 이미지 | 비율=원본 · 크기=100 · 모양=각진 · 정렬=중앙 · 내부여백=0 · 외부여백=0 |
| `A01.jpg` / `B01.jpg` / `01.jpg` (01) | 이미지 | 위와 동일 |
| `A02.jpg` / `B02.jpg` / `02.jpg` (02) | 이미지 | 위와 동일 |

### 03 — basic (스크롤 없음)

페이지 380×580 안에 **이미지 1장**이 풀화면으로.

| basic 유형 | 파일 | CdBd 카드 | 속성 |
|---|---|---|---|
| basic-full | `A03.jpg` / `03.jpg` | 이미지 | 비율=원본 · 크기=100 · 내부여백=0 · 외부여백=0 |
| basic-frame | 동일 | 이미지 | 위와 동일 (프레임은 이미지 자체에 포함) |
| basic-footer | 동일 | 이미지 | 위와 동일 |
| basic-link (이미지) | 동일 (**선까지만** 그린 이미지) | 이미지 | 위와 동일 |
| basic-link (마커별 「+」) | (CdBd 측 gif 자산) | 이미지 카드 → **레이어 추가** | 각 「+」 gif를 마커 위치에 레이어로 얹고 **링크 연결 = URL 열기**(상품 구매 URL) · 새 창에서 열기=ON |

> ⚠️ **basic-link**: 피그마에서는 **「+」 gif를 얹지 않고 선까지만 그린 이미지**를 내보냅니다. CdBd가 추후 이미지 카드의 **레이어 추가**로 「+」 gif를 마커 위치마다 얹고 각 레이어에 구매 URL을 연결합니다. (선 색상·텍스트 색상 기준은 [[2-4. 화보·상품]] 「03-basic-link」 참고)

### 03 — swp (좌우 스와이프)

**1 멀티페이지 페이지 안의 1 갤러리 카드(넘겨보기)** 로 구현. BG는 **페이지 배경 설정**(케밥 → 페이지 배경 설정 → 이미지)으로 들어가 좌우 스와이프 동안 고정됨.

| swp 유형 | 파일 | CdBd 카드 / 설정 | 속성 |
|---|---|---|---|
| **swp-clean** (선명 BG + 카드) | `03-BG` + `03-swp1`, `03-swp2`, … | 페이지 배경(이미지) + 갤러리 (넘겨보기) | 페이지 배경 = `03-BG` 이미지 / 갤러리: 유형=넘겨보기 · 내비게이션=ON · 무한 반복=OFF · 자동 넘김=OFF · **카드 디자인 → 외부여백=20 · 내부여백=20** · 모서리=각진(또는 둥근 적용 12) · 첫 카드=투명 이미지(swp1) |
| **swp-full** (풀페이지, BG 없음) | `03-swp1`, `03-swp2`, … | 갤러리 (넘겨보기) | 페이지 배경 없음 · 카드 디자인 → 외부여백=0(풀블리드) · 내부여백=0 |
| **swp-blur** (블러 BG + 카드) | `03-BG`(블러·확대·dim) + `03-swp1`, … | 페이지 배경(이미지) + 갤러리 (넘겨보기) | 페이지 배경 = `03-BG`(블러 가공본) · 갤러리: 카드 디자인 → 외부여백=20 · 내부여백=20 · 첫 카드=선명한 화보(swp1) |

- **갤러리 카드 배경 기본값** (clean·blur): `#FAFAFA` 톤 또는 BG 이미지
- **스와이프 페이지 수는 과금 기준** — 페이지 분할은 [[1-2. 시안]] 「스와이프(swp) 페이지 분할」 참고

### 03 — scl (스크롤)

**1 멀티페이지 페이지**(높이 580 초과 → 자동 스크롤)에 **여러 카드가 세로로 쌓임**.

#### 공통 (모든 scl 유형)

| 파일 | CdBd 카드 / 페이지 설정 | 속성 |
|---|---|---|
| `03-logo` | 이미지 카드 | 비율=원본 · 크기=(146/380≈38)% · 정렬=중앙 · 내부여백=상단 32px (또는 외부여백 활용) · **고정 X** (별도 요청 없으면 스크롤과 함께 흐름) |
| `03-1` (메인 화보, 여러 장이면 `03-1-1`, …) | 갤러리 (넘겨보기) | 유형=넘겨보기 · 비율=원본 또는 직접입력 · 내비게이션=ON |
| `03-BG` *(BG가 있는 타입만)* | **페이지 사이드바 → 썸네일 케밥(︙) → 페이지 배경 설정 → 이미지** | 페이지 단위 배경 (카드 아님) — 해당 scl 페이지에만 적용. 상세는 아래 「추가 결정 사항 → 페이지 배경」 참고 |

#### 상품 영역 (`03-2`) — scl 유형별 다름

| scl 유형 | 파일 | CdBd 카드 | 속성 |
|---|---|---|---|
| scl-frame-grid2 | `03-2-1`, `03-2-2`, … | 갤러리 (그리드) | 유형=그리드 · 단=2 · 간격=16 · 비율=원본 · 카드 디자인 → 배경=`#F3F3F3`(또는 없음) · 내부여백=20 |
| scl-frame-grid3 | `03-2-1`, `03-2-2`, … | 갤러리 (그리드) | 유형=그리드 · 단=3 · 간격=16 · 비율=원본 · 카드 디자인 → 배경=`#F3F3F3`(또는 없음) |
| scl-full-grid | `03-2-1`, … + `03-2-BG` | 갤러리 (그리드) | 단=2 · 간격=0 · **카드 디자인 → 배경=이미지(`03-2-BG`)** · 내부여백=0(풀블리드) |
| scl-blur-grid | `03-2-1`, … + `03-2-BG` | 갤러리 (그리드) | 단=2 · 간격=0 · **카드 디자인 → 배경=이미지(`03-2-BG`)** · 페이지 자체에는 별도 `03-BG`(블러)가 깔림 |
| scl-row | `03-2-1`, `03-2-2`, … (**행 아이템만**) | 갤러리 (나열하기) + 행 사이 **구분선 카드** | 유형=나열하기 · 간격=0 · 행 사이 구분선 카드: 모양=실선 · 두께=1 · 색=`#292929` 투명도 20% · 상하여백=0 (피그마 노드 `14016:271` 실측) |

> ⚠️ **scl-row 구분선**: 피그마에서는 **구분선을 내보내지 않습니다**. CdBd 측이 행 사이에 **「구분선」 카드**를 동일 색·두께로 삽입합니다.
> ⚠️ **`03-2-BG`**: 그리드 갤러리 카드의 **카드 디자인 → 배경(이미지)** 으로 들어갑니다. 페이지 자체 배경 `03-BG`와는 별개.

## 「버튼·마커」 유형별 매핑

[[1-2. 시안]] ⑤단계의 **누끼컷 × URL 매트릭스**에서 등장하는 「버튼·마커」는 CdBd에서 다음과 같이 구현됩니다.

| 유형 | 등장 위치 | CdBd 구현 |
|---|---|---|
| **「+」 gif 버튼** | 03-basic-link 마커 끝 | 이미지 카드 → **레이어 추가** (마커 위치마다 「+」 gif를 오버레이) + 각 레이어에 **링크 연결 = URL 열기** |
| **chevron 「›」 버튼** | 03-scl-row 행 끝 | 행 아이템 이미지 자체에 포함되어 내보내짐 (CdBd 별도 카드 추가 없음). 행 전체에 링크 연결 시 갤러리 이미지에 **링크 연결 = URL 열기** |
| **swp 내비게이션 화살표(◂ ▸)** | 03-swp 좌우 | 갤러리 카드 → 유형=넘겨보기 → **내비게이션 토글 ON** (CdBd 자동 표시) |
| **선(라인) 마커** | 03-basic-link | 이미지 자체에 그려서 내보냄 (CdBd 별도 처리 없음). 선 끝이 「+」 gif 레이어 위치 |

> **「버튼」의 통합 정의**: 위 「+」/chevron/gif/내비게이션 화살표 등 **링크 진입을 시각적으로 표시하는 모든 요소**를 통칭. 유형마다 구현 방식(이미지에 포함 vs 별도 레이어 vs CdBd 자동 표시)이 다름.

## CdBd 측 작업 흐름 요약

| 룩북 출력 | CdBd 등록 절차 |
|---|---|
| **단일 이미지** (01·02·basic) | 새 페이지 → 이미지 카드 → 이미지 업로드 → 비율=원본·크기=100 |
| **basic-link** (선까지 그린 이미지) | 이미지 카드 → 본 이미지 업로드 → **레이어 추가**로 「+」 gif를 마커 위치에 얹고 각 레이어에 URL 열기 링크 |
| **swp** (BG + swp1, swp2…) | 새 페이지 → 갤러리 카드 → 유형=넘겨보기 → swp1·swp2 순서로 업로드 → 카드 디자인 → 배경=이미지(03-BG) |
| **scl** (logo + 03-1 + 03-2 …) | 새 페이지 → 이미지 카드(로고) → 갤러리(넘겨보기, 03-1) → 갤러리(그리드/나열하기, 03-2) → 필요시 구분선 카드 |

## 추가 결정 사항 (2차 실측)

초안 문서화 후 사용자 확인·재실측으로 명확해진 항목들:

### 페이지 배경 (03-BG)

**위치**: 좌측 페이지 사이드바 → 페이지 썸네일 위로 호버 → 우측 상단 **케밥(︙) 메뉴** → **「페이지 배경 설정」**

![[ref-cdbd-21-page-kebab.png]]
*페이지 썸네일 호버 시 나타나는 케밥 메뉴*

![[ref-cdbd-22-page-bg.png]]
*「현재 페이지 배경 설정하기」 다이얼로그 — 색상 / 이미지 선택*

- 다이얼로그 제목: **「현재 페이지 배경 설정하기」** — 선택한 페이지에만 적용 (페이지별 독립)
- 옵션: **색상** (컬러 팔레트·피커) / **이미지** (업로드)
- 룩북 03-BG 적용 시: **이미지** 선택 → `03-BG.jpg` 업로드

### swp/scl 카드 여백

- **별도 메뉴 없음.** 갤러리 카드 → **「카드 디자인」 → 내부여백 / 외부여백** 으로 일괄 설정
- 풀블리드 구현 = 외부여백 0 + 내부여백 0 (카드 디자인 섹션 참고)

### scl 로고 (`03-logo`) 고정 여부

- **별도 요청이 없는 한 고정하지 않는다.** 스크롤 시 다른 카드와 함께 스크롤되도록 둠 (기본 동작)
- 사용자가 명시적으로 「로고 고정」을 요청한 경우에만 상단 고정 처리

### 구분선 카드 속성 (scl-row 행 사이)

피그마 노드 `14016:271` (scl-row Line 3) 기준 실측값 — **CdBd 구분선 카드에 동일 속성 적용**:

| 옵션 | 값 |
|---|---|
| 색 | `#292929` (rgb 41, 41, 41) |
| 투명도 | **20%** (`#292929`에 alpha 0.2 적용) |
| 두께 | **1px** |
| 모양 | **실선** (dashPattern 없음) |
| 너비 | 340px (콘텐츠 폭 일치) |

> **원칙**: 피그마의 속성을 그대로 CdBd 카드에 적용. 향후 유형별로 다른 구분선이 등장하면 [[2-4. 화보·상품]] 각 유형 섹션에 속성을 명시한 뒤 여기에 반영.
