## 개요

CdBd 멀티페이지는 **페이지 컨테이너** 안에 **여러 페이지**가 있고, 각 페이지는 **여러 카드**로 구성됩니다. 룩북 결과물은 카드 단위로 내보낸 뒤, CdBd 에디터에서 적절한 카드에 등록합니다.

- **피그마(디자인) ↔ CdBd(렌더)**: 디자인은 카드의 시각 결과만 책임지고, **링크·구분선·gif 등 상호작용 요소는 CdBd 측이 부여**합니다.
- **내보내기 단위 = 카드 단위**: 한 페이지가 여러 카드로 구성되면 파일도 카드 수만큼 분할해 내보냅니다 (예: scl의 `03-1`, `03-2-1`, `03-2-2`…).

## CdBd 멀티페이지 구조

### 페이지 컨테이너 ↔ 페이지 ↔ 카드

```
멀티페이지 (1 프로젝트)
├── 페이지 1   ← 좌우 스와이프로 페이지 간 전환
│   ├── 카드 A
│   ├── 카드 B
│   └── ... (높이 580 초과 시 자동 스크롤)
├── 페이지 2
└── ...
```

### URL 게시 (상단 우측 「URL 생성하기」)

상단 우측 **「URL 생성하기」** 버튼을 누르면 **「URL 정보 편집하기」 모달**이 열린다. 룩북에서는 이 모달에서 **OG 이미지·제목·설명**을 등록한다.

![[ref-cdbd-23-url-modal.png]]

| 항목 | 룩북 입력값 |
|---|---|
| **페이지 주소** | `https://cdbd.in/2account/{page_name}` — 슬러그 입력 (브랜드 영문명 등) |
| **공유 데이터 → 썸네일** | **OG 이미지(`og.jpg`)** 업로드 — 권장 사이즈 **800×400px** ([[1-1. 공통]] OG 규격과 일치) |
| **공유 데이터 → 제목** | **브랜드명(영문)** (예: `PRENDANG`) |
| **공유 데이터 → 설명** | **컬렉션명** (예: `26 SS Collection`) |
| 페이지 비밀번호 | (요청 시) |
| 페이지 상단 메뉴 | ON (기본) — 페이지 구독·저장·공유 기능 노출 |

> ⚠️ **OG는 멀티페이지 전체 1개** — 페이지별이 아니라 멀티페이지(프로젝트) 전체의 공유 카드. 따라서 시안에서도 OG는 시안 표지(A·B)와 별개의 1장.
> 채널(카카오톡·페이스북 등)에 따라 URL 정보가 반영되는 데 시간이 걸릴 수 있음 (모달 안내 문구).

## 페이지 유형별 카드 매핑

각 룩북 페이지 유형이 **어떤 CdBd 카드**에 **어떤 옵션 값**으로 들어가는지. 파일명은 [[1-1. 공통]] 참고.

> **속성 표기 규칙**: `옵션명=값` 형식. 카드 디자인 옵션 중 룩북 기본값(외부여백=0 등)은 생략. (확인 필요)는 실측 미완 항목.

### OG 이미지 (멀티페이지 1장)

| 파일 | 등록 위치 | 속성 |
|---|---|---|
| `og.jpg` | **상단 「URL 생성하기」 → URL 정보 편집하기 → 공유 데이터 → 썸네일** | 권장 800×400px · 1배수 JPG ([[1-1. 공통]] 참고) · 멀티페이지 전체 1장 |
| (제목) | 같은 모달 → 제목 | **브랜드명(영문)** (예: `PRENDANG`) |
| (설명) | 같은 모달 → 설명 | **컬렉션명** (예: `26 SS Collection`) |

### 시안 표지 (`A` / `B`) · 01 · 02

각 페이지는 **1 멀티페이지 페이지**에 **1 이미지 카드**가 풀화면으로 들어감.

| 파일 | CdBd 카드 | 속성 |
|---|---|---|
| `A.jpg` / `B.jpg` (시안 표지) | 이미지 | 비율=원본 · 크기=100 · 모양=각진 · 정렬=중앙 · **내부여백=0 · 외부여백=0** (카드 여백 없이) · **링크 연결=페이지 이동하기 → 다음 페이지** (A 표지→A01 / B 표지→B01) |
| `A01.jpg` / `B01.jpg` / `01.jpg` (01) | 이미지 | 비율=원본 · 크기=100 · 모양=각진 · 정렬=중앙 · **내부여백=0 · 외부여백=0** (카드 여백 없이) · **링크 연결=페이지 이동하기 → 다음 페이지** (A01→A02 / B01→B02 / 01→02) |
| `A02.jpg` / `B02.jpg` / `02.jpg` (02) | 이미지 | 비율=원본 · 크기=100 · 모양=각진 · 정렬=중앙 · **내부여백=0 · 외부여백=0** (카드 여백 없이) · 링크 연결=없음 (사용자가 스와이프로 03으로 이동) |

### 03 — basic (스크롤 없음)

페이지 380×580 안에 **이미지 1장**이 풀화면으로. **01·02와 동일하게 카드 여백 없는(내부=0·외부=0) 크기 100 이미지 카드로 등록.**

| basic 유형 | 파일 | CdBd 카드 | 속성 |
|---|---|---|---|
| basic-full | `A03.jpg` / `03.jpg` | 이미지 | **01·02 동일**: 비율=원본 · 크기=100 · 카드 여백 없음(내부=0·외부=0) · 링크 없음 |
| basic-frame | 동일 | 이미지 | 동일 (프레임은 이미지 자체에 포함) |
| basic-footer | 동일 | 이미지 | 동일 |
| **basic-link** (예외) | 동일 (**선까지만** 그린 이미지) | 이미지 + **레이어 추가**(「+」 gif 다수) | 베이스 이미지는 위 basic과 동일. **마커 위치마다 「+」 gif 레이어 추가** + 각 레이어에 **링크 연결 → URL 열기**(상품 구매 URL · 새 창에서 열기=ON) |

> ⚠️ **basic-link 예외 처리**: 기본 이미지 카드 등록은 다른 basic 타입과 동일(여백 없는 크기 100). **예외사항은 「+」 gif 레이어 + URL 링크 추가**. 피그마에서는 「+」 gif를 얹지 않고 **선까지만 그린 이미지**를 내보내고, CdBd 등록 시 이미지 카드 위에 **「+」 gif 레이어**를 마커 개수만큼 얹어 각 레이어에 구매 URL을 연결합니다. (선 색상·텍스트 색상 기준은 [[2-4. 화보·상품]] 「03-basic-link」 참고)

| swp | 새 페이지 → 사이드바 케밥 → **페이지 배경 설정 → 이미지(`03-BG`)** (있으면) → 갤러리 카드(유형=넘겨보기, 내비게이션=ON) → `03-swp1`·`03-swp2`·… 순서로 업로드 |

| 매장 정보 | **요소별 카드 조합으로 등록** (페이지 1장 이미지 X). 텍스트(타이틀) → 이미지 카드(list 행, 1행=1장 / grid는 2단 카드) → 구분선 카드(행 사이) → 버튼 카드(텍스트만, chevron 없음) → 이미지 카드(헤더 또는 푸터 로고). **각 list 행에 `tel:{전화번호}` 링크 레이어 추가**. 푸터 로고는 basic류=**하단 고정** / scl류=**고정 X**. **`store-basic-cover`만 예외**: basic-link 방식(합본 이미지 + 외부 링크별 레이어). 페이지 유형별 카드 시퀀스는 위 「페이지 유형별 카드 매핑 → 매장 정보」 참고 |

#### 6. URL 정보 편집 (상단 「URL 생성하기」)
- **페이지 주소 슬러그**:
  - **시안**: `{브랜드영문명 소문자}-{YYMM}` 자동 (예: `prendang-2606` — 작업 시점 년월). 사용자에게 묻지 않음
  - **초안**: `[문서]`에서 슬러그 요청 확인 → 없으면 **사용자에게 묻기**
- **공유 데이터**:
  - 썸네일 = `og.jpg` 업로드 (800×400)
  - 제목 = 브랜드 영문명 (예: `PRENDANG`)
  - 설명 = 컬렉션명 (예: `26 SS Collection`)
- 페이지 비밀번호: OFF (요청 없으면) · 페이지 상단 메뉴: ON (기본)

#### 7. 게시 전 사용자 확인 → 게시 → URL 보고
- **게시 직전 사용자에게 한 번 확인** — 모달 입력값(슬러그·제목·설명·OG)이 의도와 맞는지
- 사용자 승인 후 게시 → 생성된 URL 보고
- 보고 형식 예시:
  ```
  ✓ CdBd 멀티페이지 등록 완료
  - 브랜드: PRENDANG (26 SS Collection)
  - 종류: 시안 (8페이지 — A·A01~A03 + B·B01~B03)
  - URL: https://cdbd.in/2account/prendang-2606
  - OG: og.jpg 등록 완료
  - 페이지 ID: /editor/{ID}
  ※ 카카오톡 등 채널 반영에 시간이 걸릴 수 있습니다.
  ```

## 「버튼·마커」 유형별 매핑

[[1-2. 시안]] ⑤단계의 **누끼컷 × URL 매트릭스**에서 등장하는 「버튼·마커」는 CdBd에서 다음과 같이 구현됩니다.

| 유형 | 등장 위치 | CdBd 구현 |
|---|---|---|
| **「+」 gif 버튼** | 03-basic-link 마커 끝 | 이미지 카드 → **레이어 추가** (마커 위치마다 「+」 gif를 오버레이) + 각 레이어에 **링크 연결 = URL 열기** |
| **chevron 「›」 버튼** | 03-scl-row 행 끝 | 행 아이템 이미지 자체에 포함되어 내보내짐 (CdBd 별도 카드 추가 없음). 행 전체에 링크 연결 시 갤러리 이미지에 **링크 연결 = URL 열기** |
| **swp 내비게이션 화살표(◂ ▸)** | 03-swp 좌우 | 갤러리 카드 → 유형=넘겨보기 → **내비게이션 토글 ON** (CdBd 자동 표시) |
| **선(라인) 마커** | 03-basic-link | 이미지 자체에 그려서 내보냄 (CdBd 별도 처리 없음). 선 끝이 「+」 gif 레이어 위치 |

> **「버튼」의 통합 정의**: 위 「+」/chevron/gif/내비게이션 화살표 등 **링크 진입을 시각적으로 표시하는 모든 요소**를 통칭. 유형마다 구현 방식(이미지에 포함 vs 별도 레이어 vs CdBd 자동 표시)이 다름.

## CdBd 측 작업 흐름 요약

| 룩북 출력 | CdBd 등록 절차 |
|---|---|
| **OG (`og.jpg`)** | 상단 「URL 생성하기」 → URL 정보 편집하기 → 공유 데이터: **썸네일=`og.jpg`** · **제목=브랜드명(영문)** · **설명=컬렉션명** |
| **시안 표지** (`A`/`B`) | 새 페이지 → 이미지 카드 → 파일 업로드 → 크기=100·**카드 여백 0**·**링크 연결=페이지 이동하기 → 다음 페이지**(A→A01 / B→B01) |
| **01 페이지** | 새 페이지 → 이미지 카드 → 파일 업로드 → 크기=100·**카드 여백 0**·**링크 연결=페이지 이동하기 → 다음 페이지**(01→02) |
| **02 페이지** | 새 페이지 → 이미지 카드 → 파일 업로드 → 크기=100·**카드 여백 0**·링크 없음 |
| **basic** (03 단일 이미지) | 새 페이지 → 이미지 카드 → 이미지 업로드 → 비율=원본·크기=100·카드 여백 0 |
| **basic-link** (선까지 그린 이미지) | 이미지 카드 → 본 이미지 업로드 → **레이어 추가**로 「+」 gif를 마커 위치에 얹고 각 레이어에 **링크 연결 → URL 열기** (구매 링크) |
| **swp** (BG + swp1, swp2…) | 새 페이지 → 페이지 사이드바 케밥(︙) → **페이지 배경 설정 → 이미지(`03-BG`)** → 갤러리 카드 → 유형=넘겨보기 → swp1·swp2 순서로 업로드 |

## 추가 결정 사항 (2차 실측)

초안 문서화 후 사용자 확인·재실측으로 명확해진 항목들:

### 페이지 배경 (03-BG)

**위치**: 좌측 페이지 사이드바 → 페이지 썸네일 위로 호버 → 우측 상단 **케밥(︙) 메뉴** → **「페이지 배경 설정」**

![[ref-cdbd-21-page-kebab.png]]
*페이지 썸네일 호버 시 나타나는 케밥 메뉴*

![[ref-cdbd-22-page-bg.png]]
*「현재 페이지 배경 설정하기」 다이얼로그 — 색상 / 이미지 선택*

- 다이얼로그 제목: **「현재 페이지 배경 설정하기」** — 선택한 페이지에만 적용 (페이지별 독립)
- 옵션: **색상** (컬러 팔레트·피커) / **이미지** (업로드)
- 룩북 03-BG 적용 시: **이미지** 선택 → `03-BG.jpg` 업로드

### swp/scl 카드 여백

- **별도 메뉴 없음.** 갤러리 카드 → **「카드 디자인」 → 내부여백 / 외부여백** 으로 일괄 설정
- 풀블리드 구현 = 외부여백 0 + 내부여백 0 (카드 디자인 섹션 참고)

### scl 로고 (`03-logo`) 고정 여부

- **별도 요청이 없는 한 고정하지 않는다.** 스크롤 시 다른 카드와 함께 스크롤되도록 둠 (기본 동작)
- 사용자가 명시적으로 「로고 고정」을 요청한 경우에만 상단 고정 처리

### 구분선 카드 속성 (scl-row 행 사이)

피그마 노드 `14016:271` (scl-row Line 3) 기준 실측값 — **CdBd 구분선 카드에 동일 속성 적용**:

| 옵션 | 값 |
|---|---|
| 색 | `#292929` (rgb 41, 41, 41) |
| 투명도 | **20%** (`#292929`에 alpha 0.2 적용) |
| 두께 | **1px** |
| 모양 | **실선** (dashPattern 없음) |
| 너비 | 340px (콘텐츠 폭 일치) |

> **원칙**: 피그마의 속성을 그대로 CdBd 카드에 적용. 향후 유형별로 다른 구분선이 등장하면 [[2-4. 화보·상품]] 각 유형 섹션에 속성을 명시한 뒤 여기에 반영.

### 매장 정보

[[2-5. 매장 정보]]에 7유형 확정. 다른 03 페이지와 다른 핵심 특징:

- **요소별 카드 조합 (페이지 1장 X)**: 매장 정보는 list·헤더·푸터·버튼이 개별 카드로 분해된다. 03 basic이 페이지를 1장 이미지 카드로 등록하는 것과 대비.
- **list 행 = 이미지 카드 + 전화 링크 레이어**: 각 매장 행을 별도 이미지로 export하고 **레이어 추가 → 링크 연결 → URL 열기 → `tel:{전화번호}`** 부여. 모바일에서 행 탭 시 전화 앱 호출.
- **모든 텍스트 버튼은 chevron 없음** (디자인 갱신 — 2026-06-02): 브랜드관 / INSTAGRAM / KAKAOTALK / 공식몰 모두 텍스트만 가운데 정렬. CdBd 버튼 카드는 텍스트 입력 + 링크 연결만.
- **푸터 로고 고정 분기**:
  - `store-basic`·`store-basic-grid` → **하단 고정** (페이지 580 안에 마무리)
  - `store-multi-3`·`store-multi-grid-3` → 고정 없이 마지막 카드 (분할의 마지막 페이지)
  - `store-scl`·`store-scl-grid` → **고정 X** (스크롤과 함께 흐름 — 03 scl 로고와 동일 원리)
- **`store-basic-cover` 예외**: basic-link과 동일 메커니즘 (합본 이미지 + 레이어 hit-area). 외부 링크 3-버튼 영역마다 레이어 + URL 열기.
- 상세 카드 매핑·페이지 유형별 시퀀스: 위 「페이지 유형별 카드 매핑 → 매장 정보」 참고.
