# 초안 제작 프로세스

**작성일**: 2026-05-28

> 이 문서는 초안 **작업 프로세스**(구성·흐름·체크리스트)를 정의합니다.
> 페이지 유형별 **디자인 가이드**(레이아웃·치수·컬러 등)는 [[디자인 가이드/0. 공통]] 및 각 페이지 문서를 참고하세요.

---

## 개요

**초안이란**: 시안(A안 또는 B안)에서 선택된 디자인을 기반으로 **모든 페이지를 완성**한 버전
**페이지 구성**: 표지 + 시즌 소개 + 상품 카테고리별 내지 페이지 (복수) + 뒷표지 등
**목적**: 배포/인쇄 전 최종 완성본
**총 페이지**: 보통 10-30페이지 이상

> 디자인(레이아웃·색상·폰트 등)은 **선택된 시안 안(A 또는 B)의 기준을 그대로 승계**합니다. 세부 규칙은 디자인 가이드 문서를 참고합니다.

## 페이지 구성 (흐름)

### 01 — 표지
**핵심**: 룩북 타이틀 + 브랜드/시즌 정보
**대응 시안 페이지**: 시안의 **01(각 시안의 표지)**를 기반으로 제작
- 시안의 "시안 표지"(`A`/`B`, TYPE-A/B 구분용)는 초안에 포함하지 않음
- 초안 표지는 시안 표지와 **다른 별도 규칙**이 적용됨 (로고 배치 등)

**구성 요소**: 브랜드 로고 / 룩북 제목·타이틀 / 브랜드명·시즌명 / 배경 이미지·컬러

### 02 — 컬렉션 소개
**핵심**: 시즌 콘셉트 및 영감 제시
**구성 요소**: 시즌 타이틀 / 콘셉트 스토리텔링 텍스트 / 분위기 이미지 / (선택) 테마 컬러 팔레트

### 03~ — 상품 카테고리별 내지
**핵심**: 각 카테고리의 상품 화보 + 정보
**구성 요소**: 카테고리명(또는 상품 이름) / 상품 이미지(화보) / 상품 설명 텍스트 / 상세 정보(가격·색상·사이즈·SKU 등)
**페이지 수**: 상품 수량 및 정보량에 따라 결정 (최소 3페이지 이상)

### 마지막 — 뒷표지 또는 연락처
**핵심**: 브랜드 마감 정보 → 디자인: [[디자인 가이드/4. 매장 정보]]
**구성 요소**: 로고(선택) / 브랜드 연락처·웹사이트 / 추가 정보(배송·AS 등) / (선택) 뒷표지 이미지

## 페이지별 구성 요소

### 01 — 표지
- **필수**: 브랜드 로고(초안 표지 별도 규칙에 따라 배치), 룩북 타이틀, 브랜드/시즌명
- **선택**: 배경 이미지, 서브 타이틀

### 02 — 컬렉션 소개
- **필수**: 시즌 타이틀, 콘셉트 설명 텍스트
- **선택**: 대표 이미지, 컬러 팔레트, 그래픽 요소

### 03~ — 상품 내지 (각 상품마다)
- **필수**: 상품 이미지, 상품명, 상품 설명, 기본 정보(가격·사이즈 등)
- **선택**: 색상 옵션, 상세 스펙, 추가 텍스트

### 마지막 — 뒷표지
- **필수**: 브랜드 연락처
- **선택**: 로고, 웹사이트/SNS 정보, 배송 정보
