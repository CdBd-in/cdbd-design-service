## 핵심 원칙

매장 정보 페이지는 룩북 끝에 들어가, 사용자를 **오프라인 매장 / 공식몰 / SNS** 등 **외부 채널로 연결**합니다.

1. **화보 페이지가 아니다** — 화보 비크롭 원칙([[2-1. 공통]]) 대신 **정렬·여백·가독성**이 1순위. 정보 페이지의 톤을 유지한다.
2. **두 갈래의 큰 갈래로 선택한다**
   - **리스트형** (`store-basic / store-basic-grid / store-multi / store-multi-grid / store-scl / store-scl-grid`) — 매장 목록을 1열(line) 또는 2열(grid)로 나열. 매장 수에 따라 single page / multi-page / scroll 선택.
   - **외부 링크형** (`store-basic-cover`) — 매장 리스트 없이 **대표 화보 + 외부 링크 3 버튼**(공식몰·SNS·카톡)으로 단순화. 룩북 마지막 화면용.
3. **light / dark 두 컬러 모드** — 리스트형은 전부 light(흰 배경/검은 텍스트), dark(검은 배경/흰 텍스트) 2종을 제공한다. **앞 페이지(01·02)의 톤에 맞춘다** — 어두운 톤 룩북 = dark, 밝은 톤 = light. (외부 링크형은 화보 위 오버레이라 mode 구분 없음, 항상 흰색.)
4. **로고는 화보·표지와 동일하게 「배경 제거 + 여백 없이 + 원본 비율」** 원칙 — [[2-1. 공통]] 「로고·누끼 이미지 처리」 준수.
5. **버튼·아이콘은 텍스트와 같은 컬러** — light에서 모두 `#000000` 계열, dark에서 모두 `#FFFFFF` 계열로 통일.

> **매장 정보 파일명**: 이 페이지 유형의 컴포넌트 자산은 모두 `store-*` prefix를 사용한다 (`store-logo`·`store-btn`·`store-list`·`store-header`). **매장 정보는 초안에만 포함**(시안 4페이지 = 표지·01·02·03에는 없음)되므로 시안 `A*`/`B*` prefix는 사용하지 않는다. 페이지 자체를 1장으로 내보낼 때는 **초안 순차번호** (예: `09.jpg`) — multi 분할은 `09-1.jpg`·`09-2.jpg`·`09-3.jpg`. ([[1-1. 공통]] 파일명 예시 참고)

## 공통 텍스트·로고 스펙

모든 수치는 기본 페이지 규격 **380 × 580px** 기준 (`store-scl` = 380×852, `store-scl-grid` = 380×760). 폰트는 **Pretendard** 기본.

**텍스트**

| 요소 | 두께 | 크기 (≈) | 비고 |
|---|---|---|---|
| 페이지 타이틀 (`STORE INFORMATION`) | Bold | 14 | 영문 대문자, letter-spacing 약간 넓게 |
| 매장명 (line) | Bold | 13 | 행 좌측, 전화번호와 한 줄 |
| 전화번호 (line) | Regular | 12 | 매장명 우측 10px 간격, 보조 컬러 |
| 매장명 (grid) | Bold | 12 | 셀 1행 |
| 전화번호 (grid) | Regular | 11 | 셀 2행, 매장명 아래 4px 간격, 보조 컬러 |
| 버튼 (`브랜드관 바로가기`) | Medium | 13 | 가운데 정렬 |
| 버튼 (`INSTAGRAM` / `KAKAOTALK` / `미샤 공식몰` 등) | Medium | 13~16 | 가운데 정렬 |
| product chip 라벨 (`TOP` / `SKIRT` 등) | Bold | 9~10 | 영문 대문자 |
| product chip 코드 (SKU) | Regular | 9~10 | 라벨 우측 |

> 매장명·전화번호 등 실제 콘텐츠는 브랜드마다 다르다. 피그마 모형의 `롯데잠실점 3F` · `02-2143-7341`은 더미 값.

**로고 크기 (면적 기준)** — **표준 viewport 380 × 580 = 220,400 px²** 기준 (store-scl/store-scl-grid 등 가변 높이 페이지도 동일 기준으로 환산):

| 사용처 | 면적 비율 | 참고 (px²) |
|---|---|---|
| 푸터 로고 (store-basic / store-basic-grid / store-multi-3 / store-multi-grid-3 / store-scl / store-scl-grid, **중앙**) | 약 **1.0%** | ≈ 2,200 |
| 헤더 로고 (store-multi-1 / store-multi-grid-1, **좌측**, **가로형 우선**) | 약 **0.55%** | ≈ 1,200 |
| cover 로고 (store-basic-cover 하단, **중앙**) | 약 **1.5%** | ≈ 3,300 |

> **면적 기준**이므로 로고 가로세로 비율에 관계없이 시각 비중이 일정 ([[2-1. 공통]] OG 로고 규칙과 동일 원리). 페이지별 위치·정렬은 「공통 컴포넌트 → store-logo」와 각 레이아웃 유형 항목 참고.

**컬러**

| 모드 | 배경 | 텍스트(주) | 텍스트(보조: 전화번호) | 디바이더 (1px) | 버튼 (브랜드관 바로가기) |
|---|---|---|---|---|---|
| **light** | `#FFFFFF` | `#000000` | `#999999` | `#EBEBEB` | BG=`#000000` · 텍스트=`#FFFFFF` |
| **dark** | `#000000` | `#FFFFFF` | `#999999` | `#333333` | BG=transparent + 1px `#FFFFFF` 외곽선 · 텍스트=`#FFFFFF` |

- **phone 아이콘 (line 타입)**: 핸드셋 모양 16×16, 행 우측 끝. 컬러 = 주 텍스트와 동일 (light=검정 / dark=흰색).
- **phone 아이콘 (grid 타입)**: 원형 24×24 wrapper + 내부 핸드셋 12×12, **반전 컬러**.
  - light = `#000000` filled 원형 + `#FFFFFF` 핸드셋
  - dark = `#FFFFFF` filled 원형 + `#000000` 핸드셋
- **SNS 버튼 (store-multi-3 / store-basic-cover)**: dark·product는 **투명 BG + 1px 흰 외곽선**, light은 BG=`#000000` 채움.

## 레이아웃 유형

7가지로 구분합니다. 매장 수와 외부 링크 노출 여부에 따라 선택합니다.

### store-basic (single page · line list · 매장 6개 이내)

가장 단순한 단일 페이지(380×580) 라인 리스트.

**구성** (좌우 여백 40):
- 타이틀 `STORE INFORMATION` — 상단 중앙, y=40, 폭 185
- 매장 리스트 6행 — y=94, 300 × 300 (행 50, 행 사이 1px 디바이더)
- 버튼 `브랜드관 바로가기` — y=418, 300 × 46
- 푸터 로고 — y=524, 면적 약 **1.0%**, 중앙

**매장 행 (300×50)**: 매장명(좌) + 전화번호(10px 우측) + phone 아이콘(우 16×16). 행 사이 1px 라인.

![[ref-store-basic.png]]
*좌: light · 우: dark*

### store-basic-grid (single page · 2-col grid · 매장 10개)

store-basic과 같은 단일 페이지(380×580)에 매장을 **2단 그리드** 5행으로.

**구성** (좌우 여백 40):
- 타이틀 — y=40
- 그리드 — y=90, 300 × 320 (5행 × 2열, 셀 138 × 64, 좌우 셀 간 24px gap, 행 사이 1px 디바이더)
- 버튼 — y=434, 300 × 46
- 푸터 로고 — y=524

**그리드 셀 (138×64)**: 좌측에 매장명(위) + 전화번호(아래 4px 간격), 우측에 **원형 phone 아이콘 24×24** (안에 12×12 핸드셋, 6px inset).

![[ref-store-basic-grid.png]]

### store-multi (multi-page · line list)

매장이 20개 이상이라 **여러 페이지로 분할**할 때. 3가지 페이지 변형(`store-multi-1` · `store-multi-2` · `store-multi-3`)을 조합한다.

| 변형 | 용도 | 매장 수 | 페이지 구성 |
|---|---|---|---|
| `store-multi-1` | **첫 페이지** | 10 | 상단 헤더 바(380×52, 좌 store-logo 100×12 / 우 타이틀 라벨 129×13) + 리스트 10행 (y=65, 316×500) |
| `store-multi-2` | **중간 페이지** | 11 | 헤더·푸터 없이 리스트만 (y=15, 316×550) — 매장만 가득 |
| `store-multi-3` | **마지막 페이지** | 5 + 버튼 스택 | 리스트 5행 (y=15, 316×250) + 3-버튼 스택(`INSTAGRAM` / `KAKAOTALK` / `브랜드관 바로가기`, y=330) + 푸터 로고 (y=524) |

**좌우 여백 32** (store-basic의 40보다 8 좁아 행 폭 316).

**3-버튼 스택 (316×153)**: 각 버튼 316×45, 세로 간격 9px. 텍스트 가운데 정렬. light = 검정 채움 + 흰 텍스트, dark = 흰 외곽선 + 흰 텍스트.

![[ref-store-multi.png]]

### store-multi-grid (multi-page · 2-col grid)

store-multi와 같은 3-페이지 구조를 **2단 그리드**로 — 페이지당 매장 수가 약 2배.

| 변형 | 매장 수 | 행 수 |
|---|---|---|
| `store-multi-grid-1` | 16 | 8행 (헤더 바 380×48 — store-multi의 line 52보다 4 낮음) |
| `store-multi-grid-2` | 18 | 9행 (리스트만, y=20) |
| `store-multi-grid-3` | 8 | 4행 + 3-버튼 스택 |

**셀**: 146 × 60 (좌우 셀 간 24px gap). store-basic-grid(138×64)와 미세 차이.

![[ref-store-multi-grid.png]]

### store-scl (scroll · line list · 매장 12개)

페이지 높이를 **852px**로 확장한 단일 스크롤 페이지.

**구성** (좌우 여백 40):
- 타이틀 — y=40, **폭 300 (좌측 정렬)** — store-basic의 폭 185 중앙 정렬과 다름
- 리스트 wrapper — y=94, 300 × 670
  - 리스트 12행 (300 × 600)
  - 버튼 (y=624, 300 × 46)
- 푸터 로고 — y=800, 중앙

> ⚠️ **store-scl은 페이지 높이 852** — CdBd 멀티페이지에 등록할 때 580 기본 페이지 위에 **세로 스크롤이 발생하는 페이지**로 처리.

![[ref-store-scl.png]]

### store-scl-grid (scroll · 2-col grid · 매장 16개)

store-scl의 그리드 버전. 페이지 높이 **760px**, 매장 16개를 8행 × 2열로.

**구성** (좌우 여백 40):
- 타이틀 — y=40, 폭 300 (좌측 정렬)
- 그리드 wrapper — y=90, 300 × 582 (8행 × 2열 셀 138×64, 24px gap, 1px 디바이더 + 버튼 y=536)
- 푸터 로고 — y=704, 중앙

![[ref-store-scl-grid.png]]

### store-basic-cover (photo BG + 외부 링크 3종)

매장 리스트 없이 **대표 화보 + 외부 링크 3 버튼**으로 마무리하는 단순 외부 연결 페이지. **룩북 마지막 페이지**에 자주 사용.

**구성**:
- **풀블리드 배경 화보** (380×580 안에 모델 화보) — 화보 비크롭 원칙 준수 ([[2-1. 공통]]). 모델 얼굴·중요 부위 잘리지 않게 위치 조정.
- **상단 좌측 product chip** (117×28, x=18, y=14) — 화보에 등장한 모델의 **착장 상품 SKU 노출** (2줄까지):
  ```
  TOP   MIQ4WTS600
  SKIRT MIQ4WSK340
  ```
- **데코 가로 라인 2개** (Vector, 약 40×0 stroke) — 화보 우측 상단·좌측 하단에 작은 액센트
- **하단 외부 링크 3-버튼 스택** (300×180, x=40, y=311) — 위에서 아래로:
  1. `미샤 공식몰` (또는 브랜드 공식몰명) — 300 × 52
  2. `INSTAGRAM` — 300 × 52
  3. `KAKAOTALK` — 300 × 52
  - 버튼 간 세로 간격 12px
- **푸터 로고** (면적 약 **1.5%**, x=40, y=535, 중앙) — 워드마크 (예: `M I C H A A` 스페이스 강조 가능)

> **컬러**: 화보 위 오버레이라 **버튼·텍스트·로고 모두 흰색**, 버튼은 **투명 BG + 1px 흰 외곽선**.
> **dim 오버레이**: 화보가 너무 밝아 흰 버튼·로고 가독성이 떨어지면 `#000000` dim 오버레이를 얹는다 (02 dim 원칙 — [[2-3. 브랜드·컬렉션 소개]] 참고, 기본 40%부터 조정).

![[ref-store-basic-cover.png]]
*좌: chip 없음 · 우: chip 2줄 (TOP·SKIRT)*

## 레이아웃 유형 선택 가이드

매장 수와 외부 링크 노출 여부에 따라:

| 상황 | 권장 유형 |
|---|---|
| 매장 6개 이내, line으로 충분 | **store-basic** |
| 매장 6~10개, 2단 그리드 선호 | **store-basic-grid** |
| 매장 10~12개, 스크롤 허용 (line) | **store-scl** |
| 매장 12~16개, 스크롤 허용 (grid) | **store-scl-grid** |
| 매장 20개 이상 (line, 페이지 분할) | **store-multi** (10·11·5+ 구조) |
| 매장 30개 이상 (grid, 페이지 분할) | **store-multi-grid** (16·18·8+ 구조) |
| 매장 리스트 없이 **외부 링크 + 화보**만 노출 | **store-basic-cover** |

- 사용자 별도 요청이 없으면 **`store-basic` (10 미만)** 또는 **`store-multi-grid` (다수)** 가 기본 선택
- **외부 링크(INSTAGRAM·KAKAOTALK·공식몰)** 노출이 필요한 경우 — `store-multi-3` / `store-multi-grid-3`(분할 마지막 페이지) 또는 `store-basic-cover`(단일 페이지) 사용
- 컬러 모드(light/dark)는 **01·02 톤에 맞춘다**

## 공통 컴포넌트

다음 컴포넌트가 리스트형 6유형에서 반복 사용됩니다.

### store-list (매장 리스트 wrapper)

| 항목 | line 타입 | grid 타입 |
|---|---|---|
| 행 폭 | 300 (store-basic·store-scl) / 316 (store-multi) | 300 (store-basic-grid·store-scl·store-scl-grid) / 316 (store-multi-grid) |
| 행 높이 | 50 | 64 (store-basic-grid·store-scl-grid) / 60 (store-multi-grid) |
| 셀 수 | 1 (행 전체) | 2 (좌·우, 셀 간 24px gap) |
| 셀 안 텍스트 | 매장명 + 전화번호 **한 줄**, 10px 간격 | 매장명 **위** / 전화번호 **아래**, 4px 간격 |
| phone 아이콘 | 16×16 핸드셋 (행 우측 끝) | 24×24 원형 wrapper + 12×12 핸드셋 (6px inset) |
| 디바이더 | 행 사이 1px | 행 쌍 사이 1px |

### store-btn (버튼)

| 종류 | 크기 | 텍스트 | 부속 |
|---|---|---|---|
| **브랜드관 바로가기** | 300×46 (store-basic·store-scl) / 316×45 (store-multi) | `브랜드관 바로가기` | 없음 |
| **SNS — INSTAGRAM / KAKAOTALK** | 316×45 (store-multi-3) / 300×52 (store-basic-cover) | 텍스트 가운데 정렬 | 없음 |
| **공식몰 — 미샤 공식몰 등** | 300×52 (store-basic-cover) | 텍스트 가운데 정렬 | 없음 |

### store-logo (브랜드 로고)

크기는 **면적 기준** (380×580 viewport, 220,400 px²) — 「공통 텍스트·로고 스펙」 참고. 아래는 위치·정렬 가이드.

| 사용처 | 면적 (≈) | 위치 |
|---|---|---|
| 푸터 중앙 | 약 **1.0%** (≈ 2,200 px²) | 페이지 하단, 중앙 정렬 |
| 헤더 좌측 (store-multi-1 / store-multi-grid-1) | 약 **0.55%** (≈ 1,200 px²) | 헤더 바 안, 좌측 padding 32 |
| store-basic-cover 하단 중앙 | 약 **1.5%** (≈ 3,300 px²) | 화보 위 흰색 워드마크 |

> **⚠️ multi 유형 헤더 로고는 가로형 우선**: `store-multi-1` / `store-multi-grid-1`의 헤더 바는 가로로 긴 형태(380×52 / 380×48)이므로, **브랜드가 가로형(워드마크형) 로고를 별도로 제공하면 정사각형·세로형 기본 로고 대신 가로형을 우선 사용**한다. 가로형이 없을 때만 기본 로고를 면적 비율(약 0.55%)에 맞춰 적용. 푸터·cover 위치는 면적 기준이 우선이므로 이 규칙의 영향을 받지 않는다.

### product chip (store-basic-cover 전용)

화보 좌측 상단(x=18, y=14)에 얹는 **상품 SKU 안내** 칩.

- **2줄 기본** (TOP / SKIRT 등 카테고리 영문 대문자 + SKU 코드). 1줄·3줄도 가능 (착장 상품 수에 따라)
- 라벨과 코드는 한 줄에, 라벨은 Bold·코드는 Regular
- 화보 명도에 따라 컬러 결정 (어두운 화보 = 흰색, 밝은 화보 = 검정)

## CdBd 매핑

매장 정보 페이지는 **요소별 카드 조합**으로 등록한다 (다른 03 페이지처럼 페이지 1장 이미지가 아님). 각 매장 행이 개별 이미지 카드가 되어 행마다 **전화 링크 레이어**(`tel:` URL)를 부여하기 위함.

| 페이지 유형 | CdBd 구성 |
|---|---|
| `store-basic` · `store-basic-grid` | 텍스트 카드(타이틀) + 이미지 카드(list 행) + 구분선 카드(행 사이) + 버튼 카드(브랜드관) + 이미지 카드(푸터 로고, **하단 고정**). **grid는 list가 2단 카드(이미지+이미지)**. |
| `store-multi` · `store-multi-grid` | (첫 페이지) 이미지 카드(헤더 바) + list + 구분선. (중간 페이지) list + 구분선만. (마지막 페이지) list + 구분선 + 버튼 카드 ×3(INSTAGRAM/KAKAOTALK/브랜드관) + 이미지 카드(푸터 로고). **grid는 list가 2단 카드**. |
| `store-scl` · `store-scl-grid` | basic류와 동일 카드 구성 — 단 푸터 로고는 **고정 X**(스크롤과 함께 흐름). 페이지 높이 852/760이므로 CdBd 페이지 사이즈도 그에 맞춰 등록. |
| `store-basic-cover` | **basic-link 방식(예외)** — 화보·chip·푸터 로고가 포함된 합본 이미지를 이미지 카드 1장으로 등록 + **레이어 추가**로 외부 링크 3-버튼 영역에 투명 hit-area + 각 레이어에 **링크 연결 → URL 열기**(공식몰·INSTAGRAM·KAKAOTALK). |

> **list 행 → 전화 링크**: 각 list 이미지 카드(또는 2단 카드의 각 셀)에 **레이어 추가 → 링크 연결 → URL 열기 → `tel:{전화번호}`** — 모바일에서 행 탭 시 전화 앱 호출. 매장별 전화번호는 `[문서]`에서 확인.
>
> **상세 매핑**(파일명·요소별 카드 조합·페이지 유형별 카드 시퀀스): [[1-4. CdBd 콘텐츠]] 「페이지 유형별 카드 매핑 → 매장 정보」 참고.
