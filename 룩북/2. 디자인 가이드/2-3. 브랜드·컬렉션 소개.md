## 01·02 표지 페이지 공통 핵심 원칙

> 01·02(표지·브랜드/컬렉션 소개) 공통 원칙입니다. [[2-2. 표지]]에도 동일하게 기재되어 있습니다.

> 표지 성격 페이지(01·각 시안의 표지 / 02·브랜드·시즌 소개)에서 **레이아웃 결정의 1순위 = 배경 화보의 여백**입니다.
> 모델의 **얼굴이 상단·양옆에서 얼마나 떨어져 있는지**에 따라 로고·텍스트의 위치(상단 / 하단 / 상단 좌측 등)를 결정합니다.

1. **화보의 여백(모델 얼굴 위치)에 따라 레이아웃을 결정할 것**
   - 얼굴이 상단에 가까우면 → 로고·텍스트를 **하단**에
   - 상단에 여백이 많으면 → 로고를 **상단**에
   - 모델이 한쪽(예: 우측)에 치우치면 → 반대쪽(좌측) 여백에 **상단 좌측** 등으로 배치
2. **로고가 화보의 중요 부분(모델 얼굴 등)을 가리지 않을 것** — 화보 크기 또는 로고 위치를 조정해 해결
3. **로고와 서브타이틀 텍스트는 동일한 컬러를 사용할 것** — 기본 흰색, 아주 밝은 화보에서만 검정. 밝은 배경과 겹쳐 가독성이 떨어지면 그림자를 추가(값은 [[2-2. 표지]] 「컬러 & 그림자」 참고)
4. **서브텍스트 양(행 수)에 따라 레이아웃을 결정할 것** — 텍스트가 길어지면 텍스트 블록 영역을 충분히 확보
5. **화보의 중요 부분(모델 얼굴, 상품 정보에 포함된 착장 상품 영역)이 잘리지 않도록 화보 위치를 조정할 것** — [[2-1. 공통]] 「화보 이미지 배치」 원칙 준수.

> **권장**: 01·02 페이지는 **같은 레이아웃 타입으로 통일**합니다. 요청이 있을 경우 혼합 사용도 가능합니다.

## 01·02 공통 텍스트·로고 스펙

> 01·02 공통 스펙입니다. [[2-2. 표지]]에도 동일하게 기재되어 있습니다.

모든 수치는 페이지 규격 **380 × 580px** 기준이며, 화보 구도에 따라 미세 조정될 수 있습니다.

**텍스트** (폰트: Pretendard)

| 요소 | 두께 | 크기 | 행간 |
|------|------|------|------|
| 시즌명 | Medium | 15px | 1.3 |
| 시즌 타이틀 | Bold | 20px | 1.3 |
| 시즌 설명 | Medium | 14px | 1.5 |

- 컬러: 로고와 텍스트는 **항상 동일 컬러** (화보 명도에 따라 흑/백 선택)
- 02는 dim 오버레이 위에 **흰색** 사용이 일반적

**로고 크기 (면적 기준)** — 페이지 프레임 면적(380 × 580 = **220,400 px²**) 대비:

| 사용처 | 면적 비율 | 참고 (px²) |
|--------|-----------|------------|
| **01 분리형 로고** (01-A·B, 로고 단독) | 약 **2.5~2.6%** | ≈ 5,500~5,700 |
| **01 묶음형 로고** (01-C·D, 로고+시즌명 그룹) | 약 **1.8~2.2%** | ≈ 3,900~4,900 |
| **02 로고** (브랜드·컬렉션 소개) | 약 **1.2%** | ≈ 2,600 |

> **면적 기준**이므로 로고 가로세로 비율(가로로 긴 워드마크 · 정사각 · 세로로 긴 심볼)에 관계없이 시각 비중이 일정 ([[2-1. 공통]] OG 로고 규칙과 동일 원리). thick frame · blur BG 변형은 [[2-2. 표지]] 「레이아웃 타입」 참고.
> 참조 노드: 전체 타입 라이브러리 보드 `16328:522` (브랜드별 예시: PRENDANG / FURSAC / HCROL).

> **용어**
> · **시즌명**: 예) `26 SPRING COLLECTION`
> · **시즌 타이틀**: 예) `Soft Structured Transition` (슬로건 성격, 생략 가능)
> · **시즌 설명**: 콘셉트 본문 텍스트 (예: "견고한 구조와 유연함이 공존하는…")

## 레이아웃 타입

## 레이아웃 가이드

**핵심**: 브랜드 스토리 + 시즌 콘셉트 상세 설명

**필수 요소**: 배경 화보 + **`#000000` dim 오버레이**, 로고, 시즌 설명 텍스트
**선택 요소**: 시즌명, 시즌 타이틀
**오버레이**: 화보 전체에 검정 dim을 깔아 텍스트 가독성 확보
- 기본값 **40%**
- 배경 화보의 밝기에 따라 투명도 조정 가능 (밝은 화보일수록 진하게 — 예: 60%, 어두운 화보는 더 옅게)

### 텍스트 블록 구성 (위→아래)
- **기본형**: 시즌명 → (시즌 타이틀) → 시즌 설명
- **본문 전용형**: 시즌 설명만 (시즌명·시즌 타이틀 모두 생략) — *시즌 타이틀이 없는 경우 사용*

> **줄바꿈**: 02는 여백을 여유 있게 사용하는 페이지이므로, 행마다 적절한 width를 유지하도록 **단어 단위로 줄바꿈**합니다 (단어 중간에서 끊기지 않게).

### 로고·텍스트 배치 유형 (02-A~D)
> thin frame / clean 공통 적용. 배치 예시는 위 「레이아웃 타입」의 thin frame / clean 캡처에서 확인할 수 있습니다 (좌→우: 02-A 중앙·로고하단 / 02-B 중앙·로고상단 / 02-C 좌측·로고상단 / 02-D 본문 전용).

| 유형       | 텍스트 정렬 | 로고 위치 | 텍스트 구성             |
| -------- | ------ | ----- | ------------------ |
| **02-A** | 중앙 정렬  | 하단    | 기본형                |
| **02-B** | 중앙 정렬  | 상단    | 기본형                |
| **02-C** | 좌측 정렬  | 상단    | 기본형                |
| **02-D** | 중앙 정렬  | 상단    | 본문 전용 (시즌명·타이틀 생략) |

> 기본형 = 시즌명 → (시즌 타이틀) → 시즌 설명 / 본문 전용형 = 시즌/브랜드 설명만

**02-D 본문 전용형** — 시즌명·시즌 타이틀 없이 **시즌 설명 본문만** (시즌 타이틀이 없는 경우). **thin frame / clean 공통**.
- **로고**: 상단 중앙, 페이지 면적의 **약 1.3%** (≈ 2,900 px²), 상단 여백 약 120
- **본문**: 중앙 정렬, 폭 약 295 (좌우 여백 약 43), 상단 약 222부터
- **dim 오버레이** 적용 (화보 밝기에 따라 조정, 예: 60%)

### 치수 가이드 (px) — 중앙 배치는 좌우 대칭이므로 좌우 여백 생략
- **텍스트 블록 폭**: 약 251 (좌측 정렬 시 좌측 여백 약 40)
- **텍스트 블록 세로**: 상단에서 약 214부터 시작 (본문 분량에 따라 가변) / 시즌명그룹–시즌 설명 간격 약 18
- **로고**: 하단형 하단 여백 약 55 / 상단형 상단 여백 약 50 / 좌측 정렬 시 좌측 여백 약 40

> 시즌 설명 분량(행 수)에 맞춰 텍스트 블록 크기·위치를 조정합니다. 01과 동일한 레이아웃 타입(thin frame / clean) 사용을 권장합니다.
