## basic (스크롤 없음, 페이지 580px 고정)

### basic 공통 — 폰트·배경

- **폰트**: 전 유형 **Pretendard**
- **배경**: frame·footer의 여백/정보 영역 = **흰색 `#FFFFFF`** (full·link은 화보 풀블리드라 별도 배경 없음)
- **텍스트 속성은 유형마다 다르므로**(크기·색·정렬·행간) **각 유형 항목에 개별 표기**한다 — 특히 **가격 색**은 full만 `#4A4A4A`(회색)·나머지 `#141414`, **link만 12px·`#000000`**(상품명/가격이 아닌 카테고리+품번)

### 03-basic-full — 화보 풀블리드 + 정보 오버레이
- 화보를 페이지 전체에 **풀블리드**로 깔고, 상품 정보를 화보 위 **상단에 오버레이**
- **상품 정보의 위치·정렬은 화보 내 여백에 따라 결정** — 모델이 좌측에 있으면 우측(우측 정렬), 우측에 있으면 좌측(좌측 정렬)에 배치
- 구성: 상품명 + 가격 (여러 상품 세로 나열 가능)
- 정보 블록: 폭 약 104 · 상단 여백 약 20 · 좌/우 여백 약 20
- **텍스트** (우측 정렬 · 상품명 위·가격 아래 세로 배치 · 자간 −2% · 행간 **140%** · 그림자 없음—밝은 화보 영역 전제):
  - 상품명 — Pretendard **SemiBold · 11px** · `#141414`
  - 가격 — Pretendard **Regular · 11px** · `#4A4A4A` (회색)

### 03-basic-frame — 화보 여백 프레임 + 하단 정보
> 표지 **01의 thick frame 유형과 기본 세트** (화보 여백 프레임 구조를 공유). 단, 반드시 함께 쓸 필요는 없음.

- 화보를 **두꺼운 여백 프레임** 안에 배치 (thick frame과 동일 구조: 좌우·상단 여백 약 24, 폭 약 332)
- **로고**: 하단 중앙, 페이지 면적(380×580 = 220,400 px²)의 **약 1.2%** (≈ 2,600 px²)
- **상품 정보**: 하단에 **풀폭(약 320)** 배치 — 좌측=카테고리+상품명 / 우측=가격 (양끝 정렬), 각 행 약 18 높이
- **텍스트 행에 가로 여유가 있어 옷 카테고리(SUIT, SHIRT, PANTS 등)를 상품명 앞에 포함**
- **텍스트** (양끝 정렬 · 자간 −2% · 행간 **160%** · 모두 `#141414`):
  - 좌 — 카테고리 Pretendard **SemiBold · 11px**(대문자) + 상품명 **Regular · 11px** (같은 행)
  - 우 — 가격 Pretendard **Regular · 11px**

### 03-basic-footer — 화보 풀블리드 + 하단 정보 바
화보를 **풀블리드(380 × 494)**로 페이지 상단에 깔고, 그 아래 흰 영역에 **로고**와 **하단 정보 바**를 둔다 (basic-frame과 달리 화보 여백 프레임 없음). 화보는 비크롭 — clip 프레임 안에서 위치만 조정.

- **로고**: 화보 아래 **중앙**, 페이지 면적의 **약 1.2%** (≈ 2,600 px², basic-frame과 동일)
- **하단 정보 바**: 폭 **340**(좌우 여백 20) · **하단 정렬**(페이지 하단에서 약 16 위) · 행 높이 **18**
  - 각 행 **양끝 정렬** — 좌 = **카테고리 + 상품명**(예: `SUIT 울 스트라이프 수트`) / 우 = **가격**(예: `₩ 2,190,000`)
  - 상품 수만큼 **1~N행**, 정보 바 하단을 고정한 채 위로 쌓임
- **텍스트**: **frame과 동일** — 좌 = 카테고리 **SemiBold 11px** + 상품명 **Regular 11px** / 우 = 가격 **Regular 11px** · 모두 `#141414` · 양끝 정렬 · 자간 −2% · 행간 **160%**

### 03-basic-link — 화보 풀블리드 + 라인 마커 (구매 링크용)
화보를 풀블리드로 깔고 **각 상품에 선(라인) 마커**를 표시하는 유형. **피그마에서는 선까지만 그린 이미지를 내보내고**, 「+」 gif·구매 링크는 CdBd 측에서 부여한다 → [[1-4. CdBd 콘텐츠]] 참고.

- **구성**: 화보(풀블리드) + **좌측 상단 상품 정보 텍스트**(상품별 카테고리 + 품번 · 마킹한 상품 수만큼) + 각 상품을 가리키는 **선 마커**
- **선 마커**: 상품 지점에서 빈 공간 쪽으로 **짧은 직선(약 24~32px · 1px)**을 빼고, **선 끝은 추후 인터랙션 버튼이 놓이는 자리**다 (마커 개수 = 상품 수)
- **⚠️ 선 색상(블랙/화이트)**: **인터랙션 버튼이 놓일 위치(선 끝)의 배경 명도**로 결정 — 밝으면 블랙 / 어두우면 화이트. **전체 이미지 명도가 아니라 마커·버튼이 실제 올라가는 지점** 기준.
- **좌측 상단 텍스트 색상**: 마찬가지로 **텍스트 영역의 배경 명도**로 블랙/화이트 결정. **선과 텍스트는 각자의 배경으로 따로 판단**한다 (예: 텍스트는 흰색, 선은 검정일 수 있음).
- **텍스트 그림자** (필요 시 — 밝은 배경과 겹쳐 가독성이 떨어질 때): 텍스트 박스에 **Drop Shadow** — 색 `#000000` **40%** · 오프셋 X·Y `0` · **Blur 10** · Spread `0`
- **텍스트** (좌측 상단 · 자간 0 · 행간 **100%**): 카테고리 Pretendard **SemiBold · 12px**(대문자) + 품번 **Regular · 12px** · 색 `#000000` (배경 명도에 따라 블랙/화이트는 위 참고). ⚠️ basic 중 **유일하게 12px**이며 상품명·가격이 아니라 **카테고리 + 품번** 구성.

![[ref-03-basic-link.png]]

## 공통 — 누끼 이미지 가공 (swp·scl)

swp·scl의 상품 누끼컷 가공 순서. 상품마다 가로/세로 비율이 다르므로:
1. **배경 제거** — 상품 이미지의 배경을 **Figma AI(`Remove background`)**로 제거(외부 ML 사용 안 함). Figma AI는 **에디터 기능이라 자동화로는 호출 불가** → 원본을 올린 뒤 **에디터에서 `Remove background` 적용** 후 진행.
2. **크롭** — 여백(제거된 배경) 없이 **상품 사이즈에 딱 맞게** 크롭.

## 공통 — 상품 누끼 alpha bbox 크롭 (swp·scl 사전 조건)

⚠️ **swp/scl product 셀을 빌드하기 전, 모든 누끼 PNG는 alpha bbox로 크롭되어야 한다.** Figma AI Remove background는 배경 픽셀을 alpha=0으로 만들 뿐 캔버스 크기는 유지하므로, 처리 직후 PNG에는 **alpha=0인 투명 여백**이 그대로 남아 있다. 이 상태로 셀에 fill 하면 셀마다 노출 면적이 달라져 그리드 통일감이 무너진다. 「[[2-1. 공통]] alpha bbox 크롭은 배경 제거의 필수 후속 단계」 참고.

**워크플로우 (5단계)**

1. **Export 가공된 PNG bytes** — `use_figma`에서 `figma.getImageByHash(hash).getBytesAsync()` → base64 return → 디스크 저장
2. **alpha bbox 계산** — `from PIL import Image; bbox = Image.open(path).getbbox()`
3. **crop** — `img.crop(bbox).save(...)` (RGBA 유지)
4. **재업로드** — `upload_assets`로 cropped PNG 업로드 → 새 imageHash 발급
5. **fill 교체 + RECT 사이즈 재산정** — 모든 product 셀의 RECT fill을 새 hash로 swap. RECT 사이즈는 동일 면적 S 유지하며 비율은 크롭 후 a = bbox_w/bbox_h를 따른다: `w = √(S·a), h = √(S/a)`. 결과적으로 **시각 면적은 균등 + 비율은 원본 유지**.

**면적 정규화 (페이지 단위)**

- swp/scl product 셀의 RECT 면적 S는 **페이지(또는 한 swp 시리즈) 내 모든 셀에서 비슷한 값으로 정규화**한다 — 단 수(2단/3단)·페이지(2-col vs 3-col)와 무관하게 누끼의 **시각 면적이 균일**해야 한다.
- 셀별 **alpha bbox 크롭 후 비율 `a = bbox_w / bbox_h`**에 맞춰 RECT를 산정 (`w = √(S·a), h = √(S/a)`) → **비율은 원본 유지 + 면적은 균일**.
- **S 결정**: 페이지 내 가장 제약 큰 셀(가장 작은 `min(cell_w² / a, avail_h² × a)`)을 기준으로 S를 잡는다. 그러면 모든 셀이 가용 영역에 들어맞고 페이지 통일감이 보존된다 — 한 셀이라도 넘치면 비율 깨짐.
- 셀 가용 영역: `availH = textTop − 10` (10px 갭), `availW = cell_w`. 산정한 `w, h`가 가용을 넘으면 `k = availH / h` (또는 `availW / w`)로 균등 축소.
- 산정 후 **이미지 좌우 중앙**(`x = (cell_w − w) / 2`) + **상하 중앙**(`y = (availH − h) / 2`)에 배치.

**Anti-pattern**

- ❌ 크롭하지 않은 PNG를 일률 RECT(예: 70×91.875) + `scaleMode: FILL`로 박는 것 → alpha 여백이 그대로 표시되어 상품마다 시각 면적이 다르게 보임.
- ❌ Remove background 단계로 자산 처리를 끝냈다고 간주하는 것 → 크롭 누락은 그리드 통일감 룰 위반.
- ❌ 셀 RECT 비율을 임의로 두고 `scaleMode: CROP` + 비율 안 맞는 imageTransform으로 채우는 것 → 상품이 가로/세로로 늘어남(원본 비율 손실). RECT 비율 = 크롭 비율로 재산정 필요.

## 공통 — 상품 순서 결정 (swp·scl)

엑셀(또는 디자인 의뢰서)에 상품 이미지가 **매트릭스로 배치되어 전달된 경우**, **이미지의 시각적 위치를 따라 좌→우, 상→하** 순서로 페이지에 배치한다. 엑셀 row 인덱스(텍스트 데이터 row 12, 13, …) 순서가 아니라 **디자이너의 시각적 의도**(셀 anchor / offset 좌표)를 따른다.

**예시**: 엑셀 안 row 1에 `A · B`(2 셀) / row 2에 `C · D · E · F`(4 셀) / row 3에 `G · H · I · J`(4 셀) 배치 →
페이지 배치 순서 = `A · B · C · D · E · F · G · H · I · J` (좌→우 상→하)

> 「행 구성」(3개까지 한 행) · 「행 순서 재배열」(단조 증가 시) 같은 카드 안 행 분할 규칙은 이 순서를 **어떻게 카드/행에 분배**할지 결정하는 별도 단계. 시각적 순서 자체는 위 좌→우 상→하 기준이 우선이며, 행 분할 규칙으로 인해 시각적 순서가 흐트러지지 않도록 한다.

## swp (좌우 스와이프)

**BG 페이지는 고정**, swp 페이지만 좌우로 스와이핑되는 구조입니다. (CdBd 카드 매핑은 [[1-4. CdBd 콘텐츠]] 참고)

- **swp 페이지 내부 프레임 border radius** 적용 가능 — 기본 0 / 적용 12 / 강조 20~40 ([[2-1. 공통]] 참고)
- 스와이프 페이지 수는 **과금 기준** — 페이지 분할은 [[1-2. 시안]] 참고
- 누끼 가공은 위 [[#공통 — 누끼 이미지 가공 (swp·scl)]] 참고

### 03-BG (clean·blur 공통 — 배경 화보 풀샷 마진)

- **clean BG와 blur BG는 380×580 풀페이지 배경**으로 화보(모델) 위에 카드/스와이프가 얹히는 구조. 모델은 BG의 핵심 시각 요소이므로 너무 작거나 잘리지 않게 사이즈를 잡는다.
- ⚠️ **풀샷 화보(머리~발끝 보이는 컷)는 380×580 프레임 기준 `상단 여백(머리 위) ≥ 40` · `하단 여백(발 아래) ≥ 20`을 반드시 확보**한다 → 모델 키 ≥ 520(뷰포트의 약 90%). **머리·발이 잘리지 않게** 사이즈/위치 조정 ([[2-1. 공통]] 「위치·사이즈 결정 트리」 규칙 A).
  - 마진 분배는 정확히 **2:1**(상단 40 : 하단 20)이 기본. 더 큰 여백이 필요하면 같은 비율로 늘리되, 둘 다 최소값 이상 유지.
  - **자식 RECT 사이즈/위치 계산**: 화보 자식 rect는 원본 비율, `rect_h = (frame_h − top − bottom) / 모델_가시영역_비율` (모델 가시영역 = 머리끝부터 발끝까지 / 원본 이미지 높이). `rect_y = top − 머리끝_y_in_scaled_rect`. 보통 음수 값(위쪽 오버플로) + 좌우 중앙 정렬.
  - blur BG의 BG 화보는 dim·blur 후에도 동일 마진 규칙 적용.
- 풀샷이 아닌 경우(웨이스트~니샷, 바스트샷)는 [[2-1. 공통]] 「위치·사이즈 결정 트리」의 규칙 C·D 적용.

### swp 공통 — 텍스트·배경·로고
- **BG 서브타이틀** (BG 상단, 로고 반대쪽): **컬렉션명**(예: `26 SS Collection`) — Pretendard **Medium 12px** · 자간 −2% / 행간 130% · 로고와 동일 컬러(clean=밝은 화보엔 검정 / blur=흰색)
- **배경**: clean 페이지 ≈ `#FAFAFA` · **swp 카드 배경 기본 `#FAFAFA`** (브랜드·시즌 톤 그라데이션 가능 — 단 **누끼가 묻히지 않도록 매우 밝게**)
- **로고 크기 (면적 기준)** — 페이지 면적(380×580 = 220,400 px²) 대비:
  - `clean BG` (BG 상단 좌측, 항상 노출) · `full` (페이지 상단 중앙, swp2~ 노출): 약 **0.5%** (≈ 1,100 px²) — 작은 마커형
  - `blur BG` (swp1 cover 하단 중앙, **swp1에만** 노출): 약 **2.3%** (≈ 5,100 px²) — clean·full 대비 크게

### 페이지 유형 & 프레임 규격 (오토레이아웃)
swp는 **3가지 유형**(BG 처리·화면 커버 범위로 구분). 모두 **세로 AL + 행별 가로 AL** 구조이며, **셀(컬럼) 높이 142 고정**, 각 행은 콘텐츠 폭을 **셀 수만큼 균등 분할해 꽉 채운다**(셀 간 간격 0). 각 유형에 **그리드 가이드** 노드가 있음.

| 유형 | 섹션 / 가이드 | 프레임 · 세로 AL | 콘텐츠(폭·행간) | 1단 셀 | 2단 셀 | 3단 셀 |
|------|--------------|------------------|------------------|--------|--------|--------|
| **clean** (선명 화보 BG 위 카드) | `16008:562` / `16089:966` | 카드 **340×501** · 패딩 상20·좌우20·하18 · 행간 18 | 폭 **300** | 300×142 | 150×142 | 100×142 |
| **full** (풀페이지) | `16041:339` / `16089:1191` | 페이지 **380×580** + 상단 로고 중앙 · 패딩 상28·좌우20·하35 | 콘텐츠 **340×478**(행간 26) | 340×142 | 170×142 | 113.3×142 |
| **blur** (블러 화보 BG 위 카드) | `16008:563` / `16100:1732` | 페이지 **380×580** · 내부 콘텐츠 카드 **340×520**(패딩 상22·좌우20·하24 · 행간 24) | 폭 **300** | 300×142 | 150×142 | 100×142 |

> 행 프레임 = 가로 AL(간격 0, 세로 CENTER). **프레임 색상 코드(가이드): 3단 `#ECECEC` · 1단 `#D9D9D9` · 2단 `#AFAFAF`.**

### 페이지 행 수 (⚠️ 최소 2행)

- **swp 페이지는 반드시 2행 이상**으로 구성한다. 1행만 배치된 페이지는 만들지 않는다(스와이프 페이지는 과금 단위이므로 빈 영역이 크게 남는 1행 페이지는 비효율 + 시각적 균형이 깨짐). 상품 수가 적어 1행만 나오면 다른 페이지와 통합하거나 행을 더 추가한다.
- **정확히 2행일 때**: 카드 자체를 **세로 auto-layout** (`primaryAxisAlignItems = "CENTER"`)으로 설정해 두 행을 카드 안에서 **수직 중앙 정렬**한다 (가이드 노드 `16615:330`).
  - 각 행은 가로 auto-layout으로 래핑 (`itemSpacing 0`, `counterAxisAlignItems CENTER`).
  - **2행 전용 행간 = 40** (3행 이상에서 쓰는 기본 행간 18/24보다 크게 — 두 행 사이가 비어 보이지 않도록 시각 무게 분산). 카드 패딩은 유형별 규격(`clean` 상20·좌우20·하18 / `blur` 상22·좌우20·하24)을 그대로 유지.
  - 결과 행 y 좌표 예시 — `clean BG` (340×501) + 행간 40: 카드 패딩 적용 후 행이 수직 중앙 정렬 → **Row 1 y ≈ 89.5, Row 2 y ≈ 271.5** (top gap 89.5 ≈ bottom gap 87.5, 행간 40).
  - ⚠️ auto-layout 적용 직후 카드가 hug로 줄면 (`primaryAxisSizingMode "AUTO"`로 잡혀서) `card.resize(340, 501)` 등으로 명시적으로 다시 고정한다.
- **3행 이상**은 카드 콘텐츠 영역을 행+간격으로 채우면 자연스럽게 균등하게 분포한다 (별도 auto-layout 불필요, 절대 좌표로도 가능). 행간은 swp 유형 기본값 사용 — `clean` 18 / `blur` 24.

### 그리드 배치
1. **행 구성** (동일 라인 = **상품명으로 판단**) — 같은 라인 제품은 동일 행, **3개까지 한 행 / 4개 이상 2단 그리드**. **동일 제품명 색상 변형**(이미지 2개 이상)은 **좌우 간격을 좁히고 제품명은 하나만 중앙 정렬**.
2. **균등 컬럼 분배** — 한 행은 콘텐츠 폭을 상품 수만큼 **등분한 균등 컬럼**에 배치하고, 각 상품을 컬럼 **좌우·상하 중앙**에 둔다. 가운데로 몰지 말고 **행 전체 폭에 고르게 분배**(3개→3등분 / 1개→풀폭 중앙 / 2개→2등분).
3. **상품 크기** — **단 수와 무관하게 누끼의 가로×세로 면적이 비슷하도록 정규화**(2단↔3단 통일감), **과하지 않게**(카드 여백이 살도록). 누끼는 (scl과 달리 배경 박스 없이) 셀 안에 **직접 배치**.
4. **행 순서 재배열** — 엑셀/전달 순서 고정 아님. 행별 상품 수가 **1·2·3개처럼 단조 증가**하면 균형이 떨어지므로 **2·1·3 등으로 재배열**하고 사용자에게 알린다.
5. **같은 라인 안 셀 순서** — 같은 라인 상품을 한 행에 배치할 때는 **고정된 순서**를 따른다:
   - **2개 셀**: **좌측 상의(top) / 우측 하의(bottom)** (예: Jacket 좌 + Pants 우, Cropped Jkt 좌 + Cotton Short 우)
   - **3개 셀 (상의 + 하의 + 악세사리)**: **좌부터 상의 → 하의 → 악세사리** (예: Crochet Floral Mini Top 좌 + Crochet floral mini short 중 + Crochet hair accessory 우)
   - **동일 제품명 다색상 2개**: 좌우 간격 좁혀 붙이고 제품명은 가운데 1번만 표시 (행 1 참조). 색상 순서는 라이트 → 다크 또는 컬렉션 컬러 칩 순서에 맞춘다.

### 셀 구조 & 상품명

**셀 구조 — 절대 좌표 + 텍스트 wrapper만 auto-layout** (가이드 와이어프레임 `16089:991`)

```
cell (FRAME, FIXED size, layoutMode: NONE)            ← 셀 자체는 절대 좌표 (auto-layout 걸지 않음)
├─ padding: 0, itemSpacing: 0
└─ children:
   ├─ ① image RECTANGLE (FIXED w·h, 절대 좌표)
   │      x = (cell.w − rect.w) / 2                   ← 좌우 중앙
   │      y = ((wrapper.y − 10) − rect.h) / 2         ← 가용 영역(셀 상단~wrapper.y−10) 상하 중앙
   └─ ② text wrapper FRAME (절대 좌표, VERTICAL hug auto-layout)
        ├─ primaryAxisAlignItems: MAX  (= bottom 기준 정렬)
        ├─ counterAxisAlignItems: CENTER
        ├─ itemSpacing: 0, padding: 0
        ├─ x = (cell.w − wrapper.w) / 2               ← 좌우 중앙
        ├─ y = cell.h − wrapper.h                     ← 셀 하단 anchor
        └─ children: nameText (위) + priceText (아래)
```

- ⚠️ **셀에는 auto-layout을 걸지 않는다** — 상품마다 누끼 이미지 높이가 달라서 **같은 행 안에서 상하 중앙 정렬을 수동 조정**해야 한다(image RECT를 자유롭게 드래그 가능해야 함). 셀에 SPACE_BETWEEN/MAX 등을 걸면 구조적으로 고정되어 수동 미세조정이 차단된다.
- **텍스트 박스만 auto-layout으로 묶는다**: name + price 2개를 hug VERTICAL frame으로 그룹화 → 가격 baseline이 항상 name 바로 아래에 붙고, wrapper를 통째로 이동·복사할 수 있음.
- **wrapper 위치 (절대 좌표)**: `x = (cell.w − wrapper.w) / 2` (좌우 중앙), `y = cell.h − wrapper.h` (셀 하단 여백 없이 anchor).
- **image rect 기본 위치 (절대 좌표)**: `x = (cell.w − rect.w) / 2` (좌우 중앙), `y = ((wrapper.y − 10) − rect.h) / 2` (가용 영역 = 셀 상단 ~ wrapper.y − 10, 그 안 상하 중앙).
- **같은 행 vertical-center 정렬**: 같은 행 셀들의 wrapper.h가 동일하면(needs2Lines row → 모두 h=39) 각 셀의 가용 영역도 동일 → 자동 계산만으로 행 단위 상하 중앙 정렬 보장. 누끼 alpha bbox 크롭으로 RECT 비율은 달라도 면적 정규화로 시각 면적은 균등.
- **수동 미세조정**: 자동 계산이 시각적으로 어색하면(예: 발이 잘려 보임·상의가 셀 상단에 너무 붙음) 사용자가 image RECT의 y만 드래그해서 미세조정. wrapper는 항상 셀 하단 anchor 유지.
- ⚠️ deprecated (이전 셀 auto-layout 패턴): `cell.layoutMode = "VERTICAL"` + `primaryAxis = SPACE_BETWEEN`. 같은 행 vertical-center를 강제하지만 수동 조정이 불가능해 누끼 키 차이가 큰 경우 시각적 어색함이 남는다.

**텍스트 속성** (폰트: Pretendard · 중앙 정렬 · 자간 −2% / 행간 130%)

| 요소 | 두께 | 크기 | 색상 | 케이스 |
|------|------|------|------|--------|
| 상품명 | Medium | 10px | 검정 | **CAPS (UPPER)** |
| 가격 | Light | 10px | 검정 | 원본 (₩+숫자) |

⚠️ **swp 상품명은 모두 대문자(`textCase = "UPPER"`)** — 카테고리 라벨 같은 시각적 위계를 부여. 가격은 ₩와 숫자라 영향 없음.

- 자동화 적용 시: `nameText.textCase = "UPPER"` → 폭이 커져 줄바꿈이 달라질 수 있으므로 텍스트 박스를 `width = cell.width − 4`, `textAutoResize = "HEIGHT"`로 둔 뒤 `nameText.height`로 재계산. 이어서 텍스트 박스를 셀 하단 고정(`name.y = cell.h − name.h − price.h`), 이미지 rect를 (셀 − 텍스트 − 10px 갭) 영역 중앙으로 재정렬한다.
- 원본 라벨에 대소문자 의도(예: "**`MAJE`**", "**`SS`**")가 있어도 자동화는 그대로 두고 `textCase`만 UPPER로 적용 — 원본 characters는 손대지 않는다(소문자로 되돌릴 때 깨지지 않도록).

**상품명 줄바꿈 규칙** (상품명 **1행 렌더 폭이 임계값 초과**면 2행으로)

**줄바꿈 임계값 (단 수별)**:

| 단 수 | 셀 폭 | 임계값 |
|-------|-------|--------|
| **1단** | 300 | **120px** |
| **2단** | 150 | **120px** |
| **3단** | 100 | **90px** |

- **1단 · 상품 1개**: 1행 폭이 120 초과 시 2행
- **1단 · 동일 상품 다색상(이미지 2개 이상)**: 상품명은 **무조건 1행**
- **2단**: 행 내 **하나라도 120 초과 → 같은 행 전부 2행**(행 단위 통일)
- **3단**: 행 내 **하나라도 90 초과 → 같은 행 전부 2행**(셀이 좁아 임계값도 낮음)
- ⚠️ **「같은 행 = 같은 라인 수」는 frame height 26 + BOTTOM 정렬만으로는 부족**: 짧은 셀이 자동 wrap되지 않으면 시각적으로 1행으로 남아 옆 2행 셀과 불일치(가격 baseline은 맞아도 텍스트 라인 수가 다르게 보임). **needs2Lines row의 모든 셀에 `\n`을 명시 삽입**해서 실제 렌더 라인 수까지 통일한다. 짧은 셀에 `\n`을 끼울 위치는 「줄바꿈 위치」 규칙을 따른다 (특징/카테고리, 접속사 앞, 단어 2개뿐이면 단일 공백). 예: row의 한 셀이 `Suit jacket\nwith brooch`(2행)이면 옆 셀 `Suit trousers`도 `Suit\ntrousers`로, `Cotton skirt shorts`도 `Cotton skirt\nshorts`로, `Linen Blended Short`도 `Linen Blended\nShort`로 변환.
- **줄바꿈 위치 (자연스러운 끊기 우선)**:
  - **`with` 등 접속사 포함**: **접속사 앞에서 끊는다** (예: `SUIT JACKET` / `WITH BROOCH`, `STRIPED KNIT TOP` / `WITH BOAT NECK`). 접속사가 새 절(sub-clause)을 시작하므로 의미 단위가 자연스럽게 분리됨. 자동화: `/(\s+)(with\b)/gi` → `\n$2` (case-insensitive 매칭, 원본 case 보존).
  - **상품명이 `[상품특징 - 사이즈 - 카테고리]` 구조**: **「상품특징」 / 「사이즈·카테고리」** 로 끊는다 (예: `CARDPRINT` / `MINI SKIRT`, `COTTON SKIRT` / `SHORTS`, `LINEN BLENDED` / `SHORT`)
  - **단어 2개뿐(짧은 이름)**: 단일 공백에서 끊기 (예: `SUIT` / `TROUSERS`)
  - **`with` 같은 접속사 키워드 (확장 가능)**: `with`, `for`, `and` 등 — 현재는 `with`만 자동 처리, 다른 접속사 발견 시 패턴 추가
  - Figma 자동 wrap만 신뢰하면 부자연스러운 위치(예: `SUIT JACKET WITH` / `BROOCH`)에서 끊길 수 있으므로 **needs2Lines + 접속사 포함 셀은 `characters`에 `\n` 명시 삽입**으로 우선순위를 강제한다.

**자동화 구현 (임계값 = 텍스트 박스 width)**

자동화로 셀을 빌드/수정할 때 줄바꿈 규칙을 강제하는 방법:

1. **임계값 결정** — row 내 셀 수로 결정: `threshold = cells.length >= 3 ? 90 : 120`.
2. **clean baseline (이전 자동 삽입된 `\n` 제거)** — `chars = chars.replace(/\n/g, ' ').replace(/\s+/g, ' ').trim()`. 색상 접미사(`- White` 등)도 이 단계에서 strip ([[#CLAUDE.md 「엑셀 상품명 - 대시 포함 시 사용자 확인」]] 참고).
3. **셀별 1행 렌더 폭 측정** — 각 cell의 nameText를 임시로 clone → `textAutoResize = "WIDTH_AND_HEIGHT"`로 폭 추출 → `clone.remove()`.
4. **행 단위 판단** — 한 row 내 cell들의 **max 1행 폭이 임계값 초과** 또는 **하나라도 `\n` 또는 접속사(`with` 등)를 포함**하면 `needs2Lines = true` (그 row 전체가 2행).
5. **`with` 등 접속사 우선 break 삽입** — needs2Lines인 row의 각 cell에 대해 `chars.replace(/(\s+)(with\b)/gi, '\n$2')` 적용 (case-insensitive 매칭, 원본 case 보존). 이게 Figma 자동 wrap보다 우선.
6. **짧은 셀에도 강제 `\n` 삽입 (행 단위 라인 수 일치)** — needs2Lines row 안에서 5단계 후에도 `\n`이 없는 셀(= 자동 wrap도 안 되고 접속사도 없는 짧은 이름)은 시각적으로 1행으로 남아 옆 2행 셀과 불일치. 「줄바꿈 위치」 규칙으로 `\n`을 강제 삽입한다:
   - 단어 2개뿐: 단일 공백에서 끊기 (`Suit trousers` → `Suit\ntrousers`)
   - 「상품특징」 / 「카테고리」 경계가 명확: 그 경계에서 끊기 (`Cotton skirt shorts` → `Cotton skirt\nshorts`, `Linen Blended Short` → `Linen Blended\nShort`)
   - 단어 3개 이상 + 경계 불명확: 중간 공백에서 끊기 (마지막 단어를 2행 또는 가장 균형 잡힌 split)
7. **텍스트 박스 width = 임계값 고정** — needs2Lines인 cell의 nameText에 `width = threshold`(셀 너비 100/150과 무관). 접속사가 없거나 추가 break가 필요한 경우 Figma가 임계값을 기준으로 자동 wrap.
8. **행 단위 통일 (frame height 26)** — 같은 row 안 모든 셀이 같은 시각 위계를 갖도록:
   - `textAutoResize = "NONE"`
   - `height = 26` (2행분 = 13px × 2)
   - `textAlignVertical = "BOTTOM"` → 만약 1행 텍스트가 남았다면 26-tall 프레임 하단에 정렬되어 가격 baseline 자연히 맞음 (6단계로 정상 케이스는 모두 2행이지만 fallback).
9. **이미지 rect 재정렬** — name.y 변경 후 가용 영역 = `name.y - 10` 으로 다시 잡고 image rect 사이즈/위치 재계산(면적 정규화 공식 `w = √(S·a), h = √(S/a)`).

needs2Lines가 아닌 row(전 셀 ≤ 임계값 + 접속사·`\n` 없음)는 `textAutoResize = "HEIGHT"` + height 13 + `textAlignVertical = "TOP"`으로 둔다.

⚠️ **anti-pattern**:
- 텍스트 박스 width를 `cell.width - 4`(146·96)로 두면 임계값 ~ cell.width 사이의 긴 상품명이 1행으로 표시되어 규칙 위반.
- 모든 단 수에 동일한 임계값(예: 90)을 쓰면 2단 셀에서 너무 일찍 줄바꿈되어 가독성 저하. 반드시 단 수별로 다른 임계값을 적용.

#### 03-swp-clean (선명 화보 BG 위 카드)

- **swp2~**: 상품 카드 (상품 이미지 + 상품명/가격)

## scl (스크롤)

스크롤되는 긴 내지 페이지. **메인 화보에 번호 마커(➊➋➌ …)로 상품 위치를 표시**하고, 하단에 상품 목록을 둡니다.

- **구성**: 상단 로고 + 메인 화보(번호 마커) + 상품 목록 + 하단 시즌명·시즌 타이틀
- 누끼 가공은 [[#공통 — 누끼 이미지 가공 (swp·scl)]] 참고. (요소별 개별 내보내기 규칙은 [[1-1. 공통]] 참고)

### 메인 화보 마커 (상품 위치 표시)
- 메인 화보(약 **340 × 440**, 좌우 여백 약 20) 위, 각 상품이 보이는 위치에 **번호 마커(➊➋➌ … 원형 숫자)**를 올림
- 마커: 폰트 **Pretendard Medium 15px** · 크기 약 **15 × 15**
- **마커 색상**: 기본 **흰색**. 단, **마커가 올라가는 상품(배경 옷)이 매우 밝은 경우에는 예외적으로 블랙(`#141414`)** 사용 — 밝은 옷 위에서 흰색 마커가 묻혀 안 보이는 것을 방지
- 번호는 하단 상품 목록(03-2-x)의 번호와 **매칭** — **마커 개수 = 상품 목록 행 수 = 상품 개수**와 일치
- **마커 배치 원칙**:
  - 상품의 **중요 부분(로고 등)**이나 **모델의 중요 부위**를 가리지 않도록 주의
  - 상품 **정중앙보다는**, 마커가 표시된 다른 제품과 **구분되는 위치**에 두는 것이 중요
  - 풀샷 내 악세사리 등 **화면 대비 제품 사이즈가 작은 경우**, 마커가 제품을 너무 가리지 않도록 **가장자리쯤**에 배치
  - 마커는 **반드시 해당 상품이 명확히 식별되는 면 위**에 올린다. **손·팔·가방(끈) 등 다른 요소와 겹치지 않게** 하고, 필요하면 화보를 **확대해 옷의 경계를 확인**한 뒤 배치한다.
  - **상·하의처럼 인접한 상품의 명도·색이 비슷할 때**는 **허리밴드·솔기 등 경계선을 기준**으로 정확한 해당 상품 위에 올린다.
- **상품이 화보에서 잘 보이지 않는 경우**(예: 아우터에 가려진 `03-1-2`): **연결선(흰색 1px, 약 30)을 빼서** 마커를 보이는 위치로 빼내고, 선이 가려진 상품을 가리키도록 표시

### 03-scl-frame-grid — 카드 구조 · 컨테이너 · 하단 바
**누끼 카드** (이미지 박스 + 하단 정보)
- **이미지 박스**: **정사각형**(카드 폭과 동일, 3열 ≈102.7 / 2열 ≈162) · 배경 **`#F3F3F3`** · overflow clip. 누끼는 상품 크기에 맞게 크롭해 **세로 중앙**(어두운 누끼는 박스를 꽉 채움, 배경 `#F6F6F6` 등). 박스 아래 정보가 붙어 **카드 전체는 더 긺**(예: 3열 103×147).
- **플러스(+) 버튼**: 이미지 박스 **우하단**(가장자리 약 8 안쪽) · **24×24 원형** · 아이콘 16 · 패딩 4. 기본 **`#292929` 원 + 흰색 아이콘**, **누끼/배경이 어두우면 반전**(흰 원 + 다크 아이콘).
- **하단 텍스트** (이미지 아래 · 좌측 정렬 · 색 `#292929` · 자간 −2%):

| 요소 | 폰트·크기 | 비고 |
|------|-----------|------|
| 번호 + 카테고리 (예: `➊ OUTER`) | Pretendard **Bold 13px** · 행간 1.4 | 번호 = 메인 화보 마커와 동일 |
| 품번/가격 (예: `PA1NC020MS-53`) | Pretendard **Regular 12px** · opacity 70% | 행간 normal |

- 카테고리 괄호 보조(예: `➍ ACC (가방)`)는 **괄호 부분 Regular**

**컨테이너 · 하단 바** (380 페이지, 좌우 여백 20 → 폭 약 340)
- 그리드 오토레이아웃: **frame-grid2 = Grid 2열**(rowGap 20·colGap 16·하단 패딩 32) / **frame-grid3 = 가로 wrap 3열**(gap 16) · 카드 내부(이미지↔정보) 세로 간격 10

- **메인 화보(03-1) + 그리드(03-2) + 하단 바(03-bottom)** 구성, 페이지 높이는 상품 수에 따라 가변

### 03-scl-full-grid · 03-scl-blur-grid — 풀블리드 스크롤 그리드 (오토레이아웃 Grid)
긴 스크롤 페이지에 상품을 **Figma Grid 오토레이아웃**으로 채우는 유형. frame 타입과 달리 **카드 간격 0**(셀이 맞붙음)이고 **하단 다크 바(03-bottom)는 없다**.

- **구성**: 상단 **메인 화보(03-1)** + 하단 **상품 그리드(03-2)**
  - `full-grid`: 메인 화보 **풀블리드 380×580** + 그리드 (페이지 높이 ≈ 1634)
  - `blur-grid`: **블러 페이지 배경(`03-BG`)** 위에 그리드 · 상단 로고 (페이지 높이 ≈ 1454)
- **상품 그리드(03-2) = Grid 오토레이아웃**: **2열 · row/column gap 0 · 패딩 0**. **행 수는 상품 수에 따라 가변**(예: 5행·7행).
- **셀(누끼 카드) 크기**: `full-grid` **166 × 196**(폭 332) · `blur-grid` **150 × 177**(폭 300) — 상품 이미지 비율에 따라 **long(166×246) / half(166×196·7행)** 변형 사용.
- **`03-2-BG`**: 그리드 영역 배경 = **그리드 카드의 카드 배경** (blur-grid의 페이지 배경 `03-BG`와 별개). 별도로 내보낸다. (내보내기는 [[1-1. 공통]], CdBd 카드 매핑은 [[1-4. CdBd 콘텐츠]] 참고)
- 카드 내부(이미지·번호·정보) 구조는 위 「03-scl-frame-grid」 카드 구조와 동일.
