# 디자인 가이드 — 4. 화보·상품

**대상 페이지**: 03(내지 — 화보 및 상품 정보)

> 공통 원칙(특히 **화보 비크롭**·폰트·radius)은 [[2-1. 공통]]을 먼저 참고하세요.

**핵심**: 대표 상품 화보 + 상품 정보 제공
**구성 요소**: 상품 화보 이미지 / 상품명 / 가격 (+ 카테고리)

03 내지는 **basic(스크롤 없음)**, **swp(좌우 스와이프)**, **scl(스크롤)** 세 그룹으로 나뉩니다.

> **타입 선택 기준 (리소스 기준 · 시안·초안 공통)**: 전달받은 리소스에 따라 결정합니다 — **화보 + 상품 정보 텍스트만** → `basic` / **누끼(상품) 이미지까지** → `swp`·`scl`. (시안 단계 채택 기준은 [[1-2. 시안]] 참고)

## basic (스크롤 없음, 페이지 580px 고정)

### 03-basic-full — 화보 풀블리드 + 정보 오버레이
- 화보를 페이지 전체에 **풀블리드**로 깔고, 상품 정보를 화보 위 **상단에 오버레이**
- **상품 정보의 위치·정렬은 화보 내 여백에 따라 결정** — 모델이 좌측에 있으면 우측(우측 정렬), 우측에 있으면 좌측(좌측 정렬)에 배치
- 구성: 상품명 + 가격 (여러 상품 세로 나열 가능)
- 정보 블록: 폭 약 104 · 상단 여백 약 20 · 좌/우 여백 약 20

![[ref-03-basic-full.png]]

### 03-basic-frame — 화보 여백 프레임 + 하단 정보
> 표지 **01의 thick frame 유형과 기본 세트** (화보 여백 프레임 구조를 공유). 단, 반드시 함께 쓸 필요는 없음.

- 화보를 **두꺼운 여백 프레임** 안에 배치 (thick frame과 동일 구조: 좌우·상단 여백 약 24, 폭 약 332)
- **로고**: 하단 중앙 (약 146 × 18)
- **상품 정보**: 하단에 **풀폭(약 320)** 배치 — 좌측=상품명 / 우측=가격 (양끝 정렬), 각 행 약 18 높이
- **텍스트 행에 가로 여유가 있어 옷 카테고리(SUIT, SHIRT, PANTS 등)를 상품명 앞에 포함**

![[ref-03-basic-frame.png]]

### basic 공통 — 텍스트·여백·배경

**상품 정보 텍스트** (폰트: Pretendard)

| 요소 | 두께 | 크기 | 색상 | 정렬 |
|------|------|------|------|------|
| 상품명 | SemiBold | 11px | `#141414` | full=우측 / frame=좌측 |
| 가격 | Regular | 11px | full `#4A4A4A` / frame `#141414` | 우측 |

- 자간(letter-spacing) **−2%** / 행간 full **140%**, frame **160%**
- **그림자 없음** (검정 텍스트 · 밝은 화보 기준)
- **배경**: basic-frame 여백 영역 = **흰색 `#FFFFFF`** (basic-full은 화보 풀블리드라 별도 배경 없음)
- basic-frame은 카테고리(SemiBold) + 상품명(Regular)을 한 행에, 가격은 우측 끝 정렬

## 공통 규칙 — 누끼 가공·그리드·마커

여러 유형에서 공통으로 쓰이는 **누끼 이미지 가공 · 그리드 규칙**(swp·scl)과 **메인 화보 마커**(scl) 규칙입니다. 각 레이아웃 유형 섹션에서 이 섹션을 참조합니다.

### 누끼 이미지 가공
누끼컷은 상품마다 가로/세로 비율이 다르므로, 다음 순서로 가공합니다.
1. **배경 제거** — 피그마로 가져온 상품 이미지의 배경(누끼)을 제거
2. **크롭** — 여백(제거된 배경) 없이 **상품 사이즈에 딱 맞게** 이미지 크롭

### 그리드 규칙
누끼 카드를 그리드로 배치하는 규칙. 페이지 유형에 따라 다릅니다.

#### 스와이핑(swp) 페이지

**그리드 배치**
1. **행 구성** (동일 라인 = **상품명으로 판단**)
   - 같은 라인의 다른 제품: 개수에 따라 동일 행에 배치 — **3개까지 한 행**, **4개 이상은 2단 그리드**
   - 동일 제품명에 **색상만 다른** 경우: 다른 제품보다 **좌우 간격을 좁히고**, 제품명은 **하나만 중앙 정렬**
   - 그 외: 제품 간 간격을 **일정하게 유지**
2. **전체 정렬** — 전체 프레임의 **상하/좌우 간격이 일정하게** 보이도록 배치

**이미지 규격**
- 누끼 이미지는 **고정 박스 없이 상품 비율 그대로 가변 크기** — 카드 배경 위에 직접 배치 (scl과 달리 정사각 배경 박스 없음)
- 카드(페이지) 폭 **340** · 좌우 여백 가변(약 20~30) · 행 높이 가변
- 같은 행 내 상품들은 시각적 크기·간격이 균형을 이루도록 배치

**텍스트 속성** (폰트: Pretendard · 이미지 바로 아래 **중앙 정렬** · 자간 −2% / 행간 130%)

| 요소 | 두께 | 크기 | 색상 |
|------|------|------|------|
| 상품명 | Medium | 10px | 검정 |
| 가격 | Light | 10px | 검정 |

![[ref-그리드-swp.png]]

#### 스크롤(scl) 페이지
**배경이 있는 이미지 프레임**(누끼 상품) + 그 **아래에 정보**를 기재하는 카드 그리드입니다. **기본 3열**, 요청 시 **2열**.

**누끼 이미지 규격**
- 이미지 박스: **정사각형**(카드 폭과 동일, 3열 기준 약 **102.7**) · 배경 **`#F3F3F3`**(밝은 회색) · overflow clip
- 누끼는 **상품 크기에 맞게 크롭**해 박스에 배치(기본 **세로 중앙**), 비율에 따라 좌우 여백 가변
- 어두운/풀블리드 누끼(예: 어두운 스카프)는 박스를 **꽉 채워** 배치 가능 (배경 `#F6F6F6` 등 미세 조정)

**플러스(+) 버튼**
- 이미지 박스 **우하단**, 가장자리에서 약 **8** 안쪽 · **24 × 24 원형** · 내부 아이콘 **16** · 패딩 4
- 색: 기본 **`#292929` 원 + 흰색 아이콘**, **누끼/배경이 어두우면 흰색 원 + 다크 아이콘으로 반전** (대비 확보 — 마커 색상 규칙과 동일)

**하단 텍스트 속성** (이미지 아래 · 좌측 정렬 · 색 `#292929` · 자간 −2%)

| 요소 | 폰트·크기 | 비고 |
|------|-----------|------|
| 번호 + 카테고리 (예: `➊ OUTER`) | Pretendard **Bold 13px** · 행간 1.4 | 번호 = 메인 화보 마커와 동일 |
| 품번/가격 (예: `PA1NC020MS-53`) | Pretendard **Regular 12px** · opacity 70% | 행간 normal |

- 카테고리 괄호 보조(예: `➍ ACC (가방)`)는 **괄호 부분 Regular**

![[ref-그리드-scl.png]]

### 메인 화보 마커 (상품 위치 표시)
- 메인 화보(약 **340 × 440**, 좌우 여백 약 20) 위, 각 상품이 보이는 위치에 **번호 마커(➊➋➌ … 원형 숫자)**를 올림
- 마커: 폰트 **Pretendard Medium 15px** · 크기 약 **15 × 15**
- **마커 색상**: 기본 **흰색**. 단, **마커가 올라가는 상품(배경 옷)이 매우 밝은 경우에는 예외적으로 블랙(`#141414`)** 사용 — 밝은 옷 위에서 흰색 마커가 묻혀 안 보이는 것을 방지
- 번호는 하단 상품 목록(03-2-x)의 번호와 **매칭** — **마커 개수 = 상품 목록 행 수 = 상품 개수**와 일치 (상품이 2개면 마커도 2개, 행도 2개)
- **마커 배치 원칙**:
  - 상품의 **중요 부분(로고 등)**이나 **모델의 중요 부위**를 가리지 않도록 주의
  - 상품 **정중앙보다는**, 마커가 표시된 다른 제품과 **구분되는 위치**에 두는 것이 중요
  - 풀샷 내 악세사리 등 **화면 대비 제품 사이즈가 작은 경우**, 마커가 제품을 너무 가리지 않도록 **가장자리쯤**에 배치
  - 마커는 **반드시 해당 상품이 명확히 식별되는 면 위**에 올린다. **손·팔·가방(끈) 등 다른 요소와 겹치지 않게** 하고, 필요하면 화보를 **확대해 옷의 경계를 확인**한 뒤 배치한다.
  - **상·하의처럼 인접한 상품의 명도·색이 비슷할 때**는 **허리밴드·솔기 등 경계선을 기준**으로 정확한 해당 상품 위에 올린다 (예: 셔츠 밑단 ↔ 쇼츠 허리밴드 아래를 구분).
- **상품이 화보에서 잘 보이지 않는 경우** (예: 아우터에 가려져 마커를 직접 올리기 어려운 경우 — `03-1-2` 예시): **연결선(흰색 1px, 약 30)을 빼서** 마커를 보이는 위치로 빼내고, 선이 가려진 상품을 가리키도록 표시

## swp (좌우 스와이프)

**BG 페이지는 고정**, swp 페이지(**CdBd 갤러리 카드**)만 좌우로 스와이핑되는 구조입니다. BG는 페이지 배경이 됩니다.

- **swp 페이지 내부 프레임 border radius** 적용 가능 (clean/blur 공통) — 기본 0, 적용 시 12 / 강조 20~40 ([[2-1. 공통]] 참고)
- (스와이프 페이지 수는 과금 기준 — 페이지 분할은 [[1-2. 시안]] 참고)

### 03-swp-clean BG
- **BG**: 선명한 화보 이미지를 배경으로, 상단에 **배경과 함께 고정되는 로고(좌측)·서브타이틀(우측)**
- **swp1**(갤러리 카드 첫 이미지): **투명 이미지** — 화보가 먼저 보여야 하므로
- **swp2~**: 상품 갤러리 카드 (상품 이미지 + 상품명/가격)

![[ref-03-swp-clean-bg.png]]

### 03-swp-blur BG
- **BG**: **블러 + 확대 + dim** 가공된 화보 이미지
- **swp1**(갤러리 카드 첫 장): **선명한 화보 이미지**
  - 첫 장 하단에 로고가 **있을 수도, 없을 수도** 있음
  - 로고가 **없는 경우**: 내부 프레임(fill 있는 박스)을 **중앙 정렬**
- **swp2~**: 상품 갤러리 카드

![[ref-03-swp-blur-bg.png]]

### swp 공통 — 텍스트·배경

- **BG 서브타이틀** (BG 상단): Pretendard **Medium 12px** · 검정 · 자간 −2% / 행간 130%
- **배경**:
  - clean BG 페이지 ≈ `#FAFAFA`
  - **갤러리 카드(swp 페이지 내부 프레임) 배경**: **기본 `#FAFAFA`**. 브랜드·시즌 톤에 맞춰 그라데이션을 넣을 수도 있음 (예: 연블루 → 흰색) — 단, **상품 누끼가 묻히지 않도록 매우 밝게** 적용

> 갤러리 카드 **상품명·가격 텍스트 속성**과 **이미지 규격**은 [[#공통 규칙 — 누끼 가공·그리드·마커]] 「그리드 규칙 — 스와이핑(swp)」 참고.

### 갤러리 카드 — 누끼 가공·그리드 배치
누끼 이미지 가공(배경 제거·크롭)과 카드 그리드 배치(행 구성·간격·정렬)는 **[[#공통 규칙 — 누끼 가공·그리드·마커]]**(「누끼 이미지 가공」·「그리드 규칙 — 스와이핑(swp)」)를 따릅니다.

## scl (스크롤)

스크롤되는 긴 내지 페이지. **메인 화보에 번호 마커(➊➋➌ …)로 상품 위치를 표시**하고, 하단에 상품 목록을 둡니다.

- **구성**: 상단 로고 + 메인 화보(번호 마커) + 상품 목록 + 하단 시즌명·시즌 타이틀
- (요소별 개별 내보내기 규칙은 [[1-1. 공통]] 참고)

### 메인 화보 마커 (상품 위치 표시)
메인 화보 위 번호 마커 규칙은 **[[#공통 규칙 — 누끼 가공·그리드·마커]]**(「메인 화보 마커」)를 따릅니다.

### 03-scl-grid
scl 페이지에 **누끼 카드 그리드 + 하단 고정 바**를 배치하는 레이아웃입니다. **카드 구조(이미지 박스·+버튼·하단 텍스트)는 [[#공통 규칙 — 누끼 가공·그리드·마커]] 「그리드 규칙 — 스크롤(scl)」 참고.** 아래는 03-scl-grid 고유의 컨테이너·하단 바 레이아웃.

**그리드 컨테이너** (380 페이지, 좌우 여백 20 → 폭 약 340)
- auto-layout, **가로 wrap**, 카드 간 **간격(gap) 16** · 상단 패딩 8 · 하단 패딩 20
- 카드 폭 = (340 − 16×2) ÷ 3 ≈ **102.7** (3열 균등) · 카드 내부(이미지↔정보) 세로 간격 **10**

**03-bottom (하단 고정 바)** — scl 하단 시즌명·시즌 타이틀 영역
- 페이지 하단 **풀폭 380 × 높이 44** 바, 배경 **`#292929`(다크)**
- 좌우 패딩 16 · 세로 중앙 · **양끝 정렬(space-between)** · 텍스트 **흰색** · 행간 1.3
- **좌측 = 시즌명** (예: `26 SPRING COLLECTION`): **Pretendard Medium 13px**
- **우측 = 시즌 타이틀** (예: `Soft Structured Transition`): **Pretendard Bold 13px**

![[ref-03-scl-grid.png]]

### 03-scl-row
