# 디자인 가이드 — 4. 화보·상품

**대상 페이지**: 03(내지 — 화보 및 상품 정보)

> 공통 원칙(특히 **화보 비크롭**·폰트·radius)은 [[2-1. 공통]]을 먼저 참고하세요.

## basic (스크롤 없음, 페이지 580px 고정)

### basic 공통 — 폰트·배경

- **폰트**: 전 유형 **Pretendard**
- **배경**: frame·footer의 여백/정보 영역 = **흰색 `#FFFFFF`** (full·link은 화보 풀블리드라 별도 배경 없음)
- **텍스트 속성은 유형마다 다르므로**(크기·색·정렬·행간) **각 유형 항목에 개별 표기**한다 — 특히 **가격 색**은 full만 `#4A4A4A`(회색)·나머지 `#141414`, **link만 12px·`#000000`**(상품명/가격이 아닌 카테고리+품번)

### 03-basic-full — 화보 풀블리드 + 정보 오버레이
- 화보를 페이지 전체에 **풀블리드**로 깔고, 상품 정보를 화보 위 **상단에 오버레이**
- **상품 정보의 위치·정렬은 화보 내 여백에 따라 결정** — 모델이 좌측에 있으면 우측(우측 정렬), 우측에 있으면 좌측(좌측 정렬)에 배치
- 구성: 상품명 + 가격 (여러 상품 세로 나열 가능)
- 정보 블록: 폭 약 104 · 상단 여백 약 20 · 좌/우 여백 약 20
- **텍스트** (우측 정렬 · 상품명 위·가격 아래 세로 배치 · 자간 −2% · 행간 **140%** · 그림자 없음—밝은 화보 영역 전제):
  - 상품명 — Pretendard **SemiBold · 11px** · `#141414`
  - 가격 — Pretendard **Regular · 11px** · `#4A4A4A` (회색)

![[ref-03-basic-full.png]]

### 03-basic-frame — 화보 여백 프레임 + 하단 정보
> 표지 **01의 thick frame 유형과 기본 세트** (화보 여백 프레임 구조를 공유). 단, 반드시 함께 쓸 필요는 없음.

- 화보를 **두꺼운 여백 프레임** 안에 배치 (thick frame과 동일 구조: 좌우·상단 여백 약 24, 폭 약 332)
- **로고**: 하단 중앙 (약 146 × 18)
- **상품 정보**: 하단에 **풀폭(약 320)** 배치 — 좌측=카테고리+상품명 / 우측=가격 (양끝 정렬), 각 행 약 18 높이
- **텍스트 행에 가로 여유가 있어 옷 카테고리(SUIT, SHIRT, PANTS 등)를 상품명 앞에 포함**
- **텍스트** (양끝 정렬 · 자간 −2% · 행간 **160%** · 모두 `#141414`):
  - 좌 — 카테고리 Pretendard **SemiBold · 11px**(대문자) + 상품명 **Regular · 11px** (같은 행)
  - 우 — 가격 Pretendard **Regular · 11px**

![[ref-03-basic-frame.png]]

### 03-basic-footer — 화보 풀블리드 + 하단 정보 바
화보를 **풀블리드(380 × 494)**로 페이지 상단에 깔고, 그 아래 흰 영역에 **로고**와 **하단 정보 바**를 둔다 (basic-frame과 달리 화보 여백 프레임 없음). 화보는 비크롭 — clip 프레임 안에서 위치만 조정.

- **로고**: 화보 아래 **중앙**, 약 **146 × 18** (basic-frame과 동일)
- **하단 정보 바**: 폭 **340**(좌우 여백 20) · **하단 정렬**(페이지 하단에서 약 16 위) · 행 높이 **18**
  - 각 행 **양끝 정렬** — 좌 = **카테고리 + 상품명**(예: `SUIT 울 스트라이프 수트`) / 우 = **가격**(예: `₩ 2,190,000`)
  - 상품 수만큼 **1~N행**, 정보 바 하단을 고정한 채 위로 쌓임
- **텍스트**: **frame과 동일** — 좌 = 카테고리 **SemiBold 11px** + 상품명 **Regular 11px** / 우 = 가격 **Regular 11px** · 모두 `#141414` · 양끝 정렬 · 자간 −2% · 행간 **160%**

![[ref-03-basic-footer.png]]
*화보 풀블리드(380×494) + 하단 정보 바(좌: 카테고리·상품명 / 우: 가격) · 상품 수에 따라 1~3행*

### 03-basic-link — 화보 풀블리드 + 라인 마커 (구매 링크용)
화보를 풀블리드로 깔고 **각 상품에 선(라인) 마커**를 표시하는 유형. **피그마에서는 선까지만 그린 이미지를 내보내고**, 「+」 gif·구매 링크는 CdBd 측에서 부여한다 → [[1-4. CdBd 콘텐츠]] 참고.

- **구성**: 화보(풀블리드) + **좌측 상단 상품 정보 텍스트**(상품별 카테고리 + 품번 · 마킹한 상품 수만큼) + 각 상품을 가리키는 **선 마커**
- **선 마커**: 상품 지점에서 빈 공간 쪽으로 **짧은 직선(약 24~32px · 1px)**을 빼고, **선 끝은 추후 인터랙션 버튼이 놓이는 자리**다 (마커 개수 = 상품 수)
- **⚠️ 선 색상(블랙/화이트)**: **인터랙션 버튼이 놓일 위치(선 끝)의 배경 명도**로 결정 — 밝으면 블랙 / 어두우면 화이트. **전체 이미지 명도가 아니라 마커·버튼이 실제 올라가는 지점** 기준.
- **좌측 상단 텍스트 색상**: 마찬가지로 **텍스트 영역의 배경 명도**로 블랙/화이트 결정. **선과 텍스트는 각자의 배경으로 따로 판단**한다 (예: 텍스트는 흰색, 선은 검정일 수 있음).
- **텍스트 그림자** (필요 시 — 밝은 배경과 겹쳐 가독성이 떨어질 때): 텍스트 박스에 **Drop Shadow** — 색 `#000000` **40%** · 오프셋 X·Y `0` · **Blur 10** · Spread `0`
- **텍스트** (좌측 상단 · 자간 0 · 행간 **100%**): 카테고리 Pretendard **SemiBold · 12px**(대문자) + 품번 **Regular · 12px** · 색 `#000000` (배경 명도에 따라 블랙/화이트는 위 참고). ⚠️ basic 중 **유일하게 12px**이며 상품명·가격이 아니라 **카테고리 + 품번** 구성.

![[ref-03-basic-link.png]]
*좌: 밝은 배경(텍스트·선 블랙) / 우: 어두운 배경(텍스트 흰색 + 그림자, 선은 밝은 지점이라 블랙)*

## 공통 — 누끼 이미지 가공 (swp·scl)

swp·scl의 상품 누끼컷 가공 순서. 상품마다 가로/세로 비율이 다르므로:
1. **배경 제거** — 상품 이미지의 배경을 **Figma AI(`Remove background`)**로 제거(외부 ML 사용 안 함). Figma AI는 **에디터 기능이라 자동화로는 호출 불가** → 원본을 올린 뒤 **에디터에서 `Remove background` 적용** 후 진행.
2. **크롭** — 여백(제거된 배경) 없이 **상품 사이즈에 딱 맞게** 크롭.

## swp (좌우 스와이프)

**BG 페이지는 고정**, swp 페이지만 좌우로 스와이핑되는 구조입니다. (CdBd 카드 매핑은 [[1-4. CdBd 콘텐츠]] 참고)

- **swp 페이지 내부 프레임 border radius** 적용 가능 — 기본 0 / 적용 12 / 강조 20~40 ([[2-1. 공통]] 참고)
- 스와이프 페이지 수는 **과금 기준** — 페이지 분할은 [[1-2. 시안]] 참고
- 누끼 가공은 위 [[#공통 — 누끼 이미지 가공 (swp·scl)]] 참고

### swp 공통 — 텍스트·배경
- **BG 서브타이틀** (BG 상단, 로고 반대쪽): **컬렉션명**(예: `26 SS Collection`) — Pretendard **Medium 12px** · 자간 −2% / 행간 130% · 로고와 동일 컬러(clean=밝은 화보엔 검정 / blur=흰색)
- **배경**: clean 페이지 ≈ `#FAFAFA` · **swp 카드 배경 기본 `#FAFAFA`** (브랜드·시즌 톤 그라데이션 가능 — 단 **누끼가 묻히지 않도록 매우 밝게**)

### 페이지 유형 & 프레임 규격 (오토레이아웃)
swp는 **3가지 유형**(BG 처리·화면 커버 범위로 구분). 모두 **세로 AL + 행별 가로 AL** 구조이며, **셀(컬럼) 높이 142 고정**, 각 행은 콘텐츠 폭을 **셀 수만큼 균등 분할해 꽉 채운다**(셀 간 간격 0). 각 유형에 **그리드 가이드** 노드가 있음.

| 유형 | 섹션 / 가이드 | 프레임 · 세로 AL | 콘텐츠(폭·행간) | 1단 셀 | 2단 셀 | 3단 셀 |
|------|--------------|------------------|------------------|--------|--------|--------|
| **clean** (선명 화보 BG 위 카드) | `16008:562` / `16089:966` | 카드 **340×501** · 패딩 상20·좌우20·하18 · 행간 18 | 폭 **300** | 300×142 | 150×142 | 100×142 |
| **full** (풀페이지) | `16041:339` / `16089:1191` | 페이지 **380×580** + 상단 로고 중앙 · 패딩 상28·좌우20·하35 | 콘텐츠 **340×478**(행간 26) | 340×142 | 170×142 | 113.3×142 |
| **blur** (블러 화보 BG 위 카드) | `16008:563` / `16100:1732` | 페이지 **380×580** · 내부 콘텐츠 카드 **340×520**(패딩 상22·좌우20·하24 · 행간 24) | 폭 **300** | 300×142 | 150×142 | 100×142 |

> 행 프레임 = 가로 AL(간격 0, 세로 CENTER). **프레임 색상 코드(가이드): 3단 `#ECECEC` · 1단 `#D9D9D9` · 2단 `#AFAFAF`.**

### 그리드 배치
1. **행 구성** (동일 라인 = **상품명으로 판단**) — 같은 라인 제품은 동일 행, **3개까지 한 행 / 4개 이상 2단 그리드**. **동일 제품명 색상 변형**(이미지 2개 이상)은 **좌우 간격을 좁히고 제품명은 하나만 중앙 정렬**.
2. **균등 컬럼 분배** — 한 행은 콘텐츠 폭을 상품 수만큼 **등분한 균등 컬럼**에 배치하고, 각 상품을 컬럼 **좌우·상하 중앙**에 둔다. 가운데로 몰지 말고 **행 전체 폭에 고르게 분배**(3개→3등분 / 1개→풀폭 중앙 / 2개→2등분).
3. **상품 크기** — **단 수와 무관하게 누끼의 가로×세로 면적이 비슷하도록 정규화**(2단↔3단 통일감), **과하지 않게**(카드 여백이 살도록). 누끼는 (scl과 달리 배경 박스 없이) 셀 안에 **직접 배치**.
4. **행 순서 재배열** — 엑셀/전달 순서 고정 아님. 행별 상품 수가 **1·2·3개처럼 단조 증가**하면 균형이 떨어지므로 **2·1·3 등으로 재배열**하고 사용자에게 알린다.

### 셀 구조 & 상품명

**셀 구조** (가이드 와이어프레임 `16089:991`)
- **텍스트 박스**: 셀(프레임) **하단에 여백 없이** + **좌우 중앙** 정렬
- **이미지**: 좌우 중앙 + 텍스트 박스에서 **10px 위** · **(프레임 − 텍스트 박스) 영역의 상하 중앙**에 배치

**텍스트 속성** (폰트: Pretendard · 중앙 정렬 · 자간 −2% / 행간 130%)

| 요소 | 두께 | 크기 | 색상 |
|------|------|------|------|
| 상품명 | Medium | 10px | 검정 |
| 가격 | Light | 10px | 검정 |

**상품명 줄바꿈 규칙** (상품명 **1행 렌더 폭이 90px 초과**면 2행으로)
- **1단 · 상품 1개**: 1행 폭이 90 초과 시 2행
- **1단 · 동일 상품 다색상(이미지 2개 이상)**: 상품명은 **무조건 1행**
- **2단 / 3단**: 행 내 **하나라도 90 초과 → 같은 행 전부 2행**(행 단위 통일)
- **줄바꿈 위치**: 상품명이 `[상품특징 - 사이즈 - 카테고리]` 구조면 **「상품특징」 / 「사이즈·카테고리」** 로 끊는다 (예: `CARDPRINT` / `MINI SKIRT`)

![[ref-그리드-swp.png]]

### BG 처리별 (유형 상세)

#### 03-swp-clean (선명 화보 BG 위 카드)
- **BG**: 선명한 화보 이미지를 배경으로, 상단에 **배경과 함께 고정되는 로고(좌측)·서브타이틀(우측)**
- **swp1**(첫 카드): **투명 이미지** — 화보가 먼저 보여야 하므로
- **swp2~**: 상품 갤러리 카드 (상품 이미지 + 상품명/가격)

![[ref-03-swp-clean-bg.png]]

#### 03-swp-full (풀페이지)
- swp 페이지 자체가 **풀페이지 380×580** — 별도 고정 BG 없이 화면 전체를 덮는 유형. **상단 로고 중앙**.
- 콘텐츠 프레임 **340×478**(행간 26) — 셀 폭이 콘텐츠 **340 기준**(3단 113.3 / 2단 170 / 1단 340)으로 clean·blur(폭 300)보다 큼.

#### 03-swp-blur (블러 화보 BG 위 카드)
- **BG**: **블러 + 확대 + dim** 가공된 화보 이미지 (페이지 배경)
- **swp1**(첫 카드): **선명한 화보 이미지** — 하단 로고는 있을 수도/없을 수도. 로고가 없으면 내부 프레임을 **중앙 정렬**
- **swp2~**: 상품 갤러리 카드 (내부 콘텐츠 카드 340×520 위)

## scl (스크롤)

스크롤되는 긴 내지 페이지. **메인 화보에 번호 마커(➊➋➌ …)로 상품 위치를 표시**하고, 하단에 상품 목록을 둡니다.

- **구성**: 상단 로고 + 메인 화보(번호 마커) + 상품 목록 + 하단 시즌명·시즌 타이틀
- 누끼 가공은 [[#공통 — 누끼 이미지 가공 (swp·scl)]] 참고. (요소별 개별 내보내기 규칙은 [[1-1. 공통]] 참고)

### 메인 화보 마커 (상품 위치 표시)
- 메인 화보(약 **340 × 440**, 좌우 여백 약 20) 위, 각 상품이 보이는 위치에 **번호 마커(➊➋➌ … 원형 숫자)**를 올림
- 마커: 폰트 **Pretendard Medium 15px** · 크기 약 **15 × 15**
- **마커 색상**: 기본 **흰색**. 단, **마커가 올라가는 상품(배경 옷)이 매우 밝은 경우에는 예외적으로 블랙(`#141414`)** 사용 — 밝은 옷 위에서 흰색 마커가 묻혀 안 보이는 것을 방지
- 번호는 하단 상품 목록(03-2-x)의 번호와 **매칭** — **마커 개수 = 상품 목록 행 수 = 상품 개수**와 일치
- **마커 배치 원칙**:
  - 상품의 **중요 부분(로고 등)**이나 **모델의 중요 부위**를 가리지 않도록 주의
  - 상품 **정중앙보다는**, 마커가 표시된 다른 제품과 **구분되는 위치**에 두는 것이 중요
  - 풀샷 내 악세사리 등 **화면 대비 제품 사이즈가 작은 경우**, 마커가 제품을 너무 가리지 않도록 **가장자리쯤**에 배치
  - 마커는 **반드시 해당 상품이 명확히 식별되는 면 위**에 올린다. **손·팔·가방(끈) 등 다른 요소와 겹치지 않게** 하고, 필요하면 화보를 **확대해 옷의 경계를 확인**한 뒤 배치한다.
  - **상·하의처럼 인접한 상품의 명도·색이 비슷할 때**는 **허리밴드·솔기 등 경계선을 기준**으로 정확한 해당 상품 위에 올린다.
- **상품이 화보에서 잘 보이지 않는 경우**(예: 아우터에 가려진 `03-1-2`): **연결선(흰색 1px, 약 30)을 빼서** 마커를 보이는 위치로 빼내고, 선이 가려진 상품을 가리키도록 표시

### 03-scl-frame-grid — 카드 구조 · 컨테이너 · 하단 바
**누끼 카드** (이미지 박스 + 하단 정보)
- **이미지 박스**: **정사각형**(카드 폭과 동일, 3열 ≈102.7 / 2열 ≈162) · 배경 **`#F3F3F3`** · overflow clip. 누끼는 상품 크기에 맞게 크롭해 **세로 중앙**(어두운 누끼는 박스를 꽉 채움, 배경 `#F6F6F6` 등). 박스 아래 정보가 붙어 **카드 전체는 더 긺**(예: 3열 103×147).
- **플러스(+) 버튼**: 이미지 박스 **우하단**(가장자리 약 8 안쪽) · **24×24 원형** · 아이콘 16 · 패딩 4. 기본 **`#292929` 원 + 흰색 아이콘**, **누끼/배경이 어두우면 반전**(흰 원 + 다크 아이콘).
- **하단 텍스트** (이미지 아래 · 좌측 정렬 · 색 `#292929` · 자간 −2%):

| 요소 | 폰트·크기 | 비고 |
|------|-----------|------|
| 번호 + 카테고리 (예: `➊ OUTER`) | Pretendard **Bold 13px** · 행간 1.4 | 번호 = 메인 화보 마커와 동일 |
| 품번/가격 (예: `PA1NC020MS-53`) | Pretendard **Regular 12px** · opacity 70% | 행간 normal |

- 카테고리 괄호 보조(예: `➍ ACC (가방)`)는 **괄호 부분 Regular**

**컨테이너 · 하단 바** (380 페이지, 좌우 여백 20 → 폭 약 340)
- 그리드 오토레이아웃: **frame-grid2 = Grid 2열**(rowGap 20·colGap 16·하단 패딩 32) / **frame-grid3 = 가로 wrap 3열**(gap 16) · 카드 내부(이미지↔정보) 세로 간격 10
- 카드 폭 = 3열 (340−16×2)÷3 ≈ **102.7**(셀 103×147) / 2열 **162**(셀 162×208)
- **메인 화보(03-1) + 그리드(03-2) + 하단 바(03-bottom)** 구성, 페이지 높이는 상품 수에 따라 가변
- **03-bottom (하단 고정 바)**: 풀폭 **380 × 44** 다크 바 `#292929` · 좌우 패딩 16 · 세로 중앙 · **양끝 정렬** · 텍스트 흰색 · 좌=시즌명 **Medium 13px** / 우=시즌 타이틀 **Bold 13px**

### 03-scl-full-grid · 03-scl-blur-grid — 풀블리드 스크롤 그리드 (오토레이아웃 Grid)
긴 스크롤 페이지에 상품을 **Figma Grid 오토레이아웃**으로 채우는 유형. frame 타입과 달리 **카드 간격 0**(셀이 맞붙음)이고 **하단 다크 바(03-bottom)는 없다**.

- **구성**: 상단 **메인 화보(03-1)** + 하단 **상품 그리드(03-2)**
  - `full-grid`: 메인 화보 **풀블리드 380×580** + 그리드 (페이지 높이 ≈ 1634)
  - `blur-grid`: **블러 페이지 배경(`03-BG`)** 위에 그리드 · 상단 로고 (페이지 높이 ≈ 1454)
- **상품 그리드(03-2) = Grid 오토레이아웃**: **2열 · row/column gap 0 · 패딩 0**. **행 수는 상품 수에 따라 가변**(예: 5행·7행).
- **셀(누끼 카드) 크기**: `full-grid` **166 × 196**(폭 332) · `blur-grid` **150 × 177**(폭 300) — 상품 이미지 비율에 따라 **long(166×246) / half(166×196·7행)** 변형 사용.
- **`03-2-BG`**: 그리드 영역 배경 = **그리드 갤러리 카드의 배경** (blur-grid의 페이지 배경 `03-BG`와 별개). 별도로 내보내 추후 CdBd가 카드 배경으로 사용 (내보내기는 [[1-1. 공통]] 참고).
- 카드 내부(이미지·번호·정보) 구조는 위 「03-scl-frame-grid」 카드 구조와 동일.

### 03-scl-row
상품 목록을 **텍스트 리스트(행)**로 배치 — 행마다 번호·카테고리·품번 + chevron(`>`) 아이콘 + 구분선.
- 내보내기: **행 아이템만** 내보내 **갤러리 나열하기(list)** 유형으로 사용. **구분선은 내보내지 않고** CdBd가 **동일 색·두께로 구분선 카드**를 추가 ([[1-1. 공통]] 참고).
