# 디자인 가이드 — 1. 공통

**적용 범위**: 시안·초안 / 01·02·03 등 모든 페이지

> 페이지 유형(표지·브랜드/컬렉션·화보/상품·매장 정보)에 묶이지 않고, **모든 페이지에 공통으로 적용되는 디자인 원칙**을 정의합니다.
> 페이지 규격·파일명·내보내기 등 **작업 프로세스**는 [[1-1. 공통]]을 참고하세요.

## 화보 이미지 배치 (⚠️ 가장 중요 — 모든 화보 페이지 공통)

- **모든 화보 이미지는 절대 크롭하지 않는다.** 이미지는 **원본 비율을 유지**한다.
- 화보 프레임에는 **clip contents**가 적용되어 있으므로, 노출 영역은 **이미지의 위치(필요 시 크기)만 조정**해 정한다. (이미지 자체를 잘라내지 않음)
  - Figma에서는 **이미지를 프레임 크기에 맞춰 줄이는 scale-to-fill 크롭이 아니라, 원본 비율 그대로 두고 위치·배율만 조정**해 프레임 clip이 잘라내게 한다.
- 위치를 정할 때 **모델 얼굴, 상품 정보에 포함된 착장 상품 영역 등 중요한 부분이 잘리지 않도록** 한다.
- **모델이 한쪽으로 심하게 치우친 컷이 아니면, 웬만하면 모델이 노출 영역의 정중앙에 오도록** 배치한다.
- **프레임 비율과 맞지 않아 화보로 다 채우기 어려우면**: 크롭·왜곡 대신 **Figma AI 배경 늘림(확장)**으로 여백을 채운다. (배경 작업은 Figma AI 사용 — 에디터에서 적용)
- **blur BG에서는 배경 화보를 더 크게 확대**해 배경감을 살린다. (선명한 화보 카드/내부 프레임은 별도)
- 적용 범위: **OG 이미지 / 시안·초안 / 01·02·03 등 모든 화보 페이지 공통.**

## 로고·누끼 이미지 처리 (배경 제거 · 여백 없이 · 원본 비율 유지)

> 로고와 상품 누끼 이미지에 **공통으로 적용**되는 원칙입니다. 화보(크롭 금지)와는 별개의 **자산 처리 규칙**입니다.

- **로고와 누끼(상품) 이미지는 모두 「배경 제거 + 여백 없이 + 원본 비율」 상태로 사용한다.**
  - 화보와 마찬가지로 **크롭 금지** — 원본 비율 그대로 유지.
  - 이미지 주변 **여백(흰색·회색 공간)을 제거**해 콘텐츠가 프레임 가장자리까지 닿게 배치한다.
- **배경이 있는 경우**: Figma 에디터에서 **Figma AI(Remove background)**로 제거한다. 자동화 API(`use_figma`)로 호출 불가하므로, **업로드 위치(노드 ID·페이지명)를 사용자에게 알리고 직접 적용을 요청**한다.
- **이미 배경이 없는 경우(SVG · 투명 PNG 등)**: **사용자에게 배경 제거를 요청할 필요 없이** 그대로 사용한다.
  - 업로드 직후 이미지에 **alpha 채널이 있는지(투명 배경인지) 먼저 확인**한다 — 투명이면 그대로 진행, 불투명이면 요청.
- 적용 범위: **시안·초안 모든 페이지 공통.** 로고(01·02·표지·OG)와 누끼(03 swp·scl)에 동일하게 적용.

## 기본 폰트

- **기본 폰트: Pretendard** — 모든 시안·초안에 기본 적용 (swp 카드 텍스트 등 모든 페이지 공통).
- 별도의 요청이 있는 경우에만 해당 폰트를 사용.

---

## 모서리 (border radius)

- **모든 타입의 기본 border-radius = 0**
- **내부 이미지 프레임(메인 이미지)이 있는 타입**(01-thick frame, 01-blur BG, 03-swp clean/blur)은 내부 프레임에 radius 적용 가능:
  - 기본 **12**
  - 귀여운/젊은/발랄/튀는 느낌을 강조하고 싶을 때 **20~40**

## OG 이미지(썸네일) 디자인

> 규격(800 × 400px)·내보내기·파일명 등 제작 사양은 [[1-1. 공통]] 「OG 이미지(썸네일) 규칙」을 참고하세요.

**별도의 요청이 없는 한, 로고 타입을 기본값으로 사용합니다.**

### 1. 로고 타입 (기본값)
단색 배경 위에 브랜드 로고를 배치

- **정렬**: 수직·수평 중앙 정렬
- **로고 너비** (OG 가로폭 800px 기준):

| 로고 형태         | 예시                        | 너비 비율        |
| ------------- | ------------------------- | ------------ |
| **가로로 긴 로고**  | PRENDANG 같은 워드마크          | 약 **60%**    |
| **가로가 짧은 로고** | 글자 수가 짧은 워드마크 혹은 하이브리드 로고 | 약 **40~50%** |

### 2. 룩(이미지) 타입
대표 화보 이미지를 OG 영역에 배치
- 별도 요청이 있는 경우 사용
