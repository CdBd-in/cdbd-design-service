## 01·02 표지 페이지 공통 핵심 원칙

> 01·02(표지·브랜드/컬렉션 소개) 공통 원칙입니다. [[2-3. 브랜드·컬렉션 소개]]에도 동일하게 기재되어 있습니다.

> 표지 성격 페이지(01·각 시안의 표지 / 02·브랜드·시즌 소개)에서 **레이아웃 결정의 1순위 = 배경 화보의 여백**입니다.
> 모델의 **얼굴이 상단·양옆에서 얼마나 떨어져 있는지**에 따라 로고·텍스트의 위치(상단 / 하단 / 상단 좌측 등)를 결정합니다.

1. **화보의 여백(모델 얼굴 위치)에 따라 레이아웃을 결정할 것**
   - 얼굴이 상단에 가까우면 → 로고·텍스트를 **하단**에
   - 상단에 여백이 많으면 → 로고를 **상단**에
   - 모델이 한쪽(예: 우측)에 치우치면 → 반대쪽(좌측) 여백에 **상단 좌측** 등으로 배치
2. **로고가 화보의 중요 부분(모델 얼굴 등)을 가리지 않을 것** — 화보 크기 또는 로고 위치를 조정해 해결
3. **로고와 서브타이틀 텍스트는 동일한 컬러를 사용할 것** — 기본 흰색, 아주 밝은 화보에서만 검정. 밝은 배경과 겹쳐 가독성이 떨어지면 그림자를 추가(값은 「01 — 각 시안의 표지」의 컬러 & 그림자 참고)
4. **서브텍스트 양(행 수)에 따라 레이아웃을 결정할 것** — 텍스트가 길어지면 텍스트 블록 영역을 충분히 확보
5. **화보의 중요 부분(모델 얼굴, 상품 정보에 포함된 착장 상품 영역)이 잘리지 않도록 화보 위치를 조정할 것** — [[2-1. 공통]] 「화보 이미지 배치」 원칙 준수.

> **권장**: 01·02 페이지는 **같은 레이아웃 타입으로 통일**합니다. 요청이 있을 경우 혼합 사용도 가능합니다.

## 01·02 공통 텍스트·로고 스펙

> **용어**
> · **시즌명**: 예) `26 SPRING COLLECTION`

## 레이아웃 타입

화보 처리 방식에 따라 네 가지로 구분합니다. **(01·02 공통)**

- **thin frame / clean**: 화보를 풀블리드(꽉 채움)로 깔고 로고·서브텍스트를 화보 위에 **오버레이**. 둘의 차이는 페이지 **바깥쪽 외곽선(테두리) 유무** (thin frame=있음 / clean=없음).
- **thick frame**: 화보를 페이지 안쪽에 **두꺼운 여백(프레임)**을 두고 배치하고, 로고는 화보 **바깥 흰 여백**에 배치(오버레이 아님). → 내지는 **03-basic-frame과 기본 세트**.
- **blur BG**: **블러+확대**된 화보 배경 위에 **선명한 화보(내부 이미지 프레임)**·로고·서브타이틀을 올림 (주로 01 표지 / 03-swp-blur와 유사).

### thick frame type
주로 **01 표지**에 사용 (오버레이가 아닌 화보 여백 프레임 구조).

**치수** (페이지 380 × 580 기준, 괄호는 가로폭 대비 비율)
- **화보 영역**: 폭 약 332 (**87%**) · 좌우 여백 각 약 24 (**6%**) · 높이 약 486
- **로고**: 페이지 면적의 **약 1.7%** (≈ 3,700 px²) · **중앙 정렬**
- **로고 위치는 모델 얼굴의 상단 여백에 따라 결정, 기본은 하단**:
  - **하단 (기본)**: 화보 상단 여백 약 24 / 화보 하단↔로고 간격 약 22 / 로고 하단 여백 약 22 → *모델 얼굴이 화보 상단에 가까울 때*
  - **상단**: 화보 상단 여백 약 70(로고 공간 확보) / 로고 상단 여백 약 24 / 로고↔화보 간격 약 20 → *화보 상단에 여백이 있을 때*
- **내부 이미지 프레임(화보) border radius**: 기본 0 / 적용 12 / 강조 20~40 ([[2-1. 공통]] 참고)

![[ref-표지-thick-frame.png]]
*왼쪽: 로고 하단(기본) / 오른쪽: 로고 상단*

### blur BG type
**블러+확대 화보 배경 + 선명한 내부 이미지 프레임**. 주로 **01 표지** (03-swp-blur와 유사 구조).

**변형 3종** (이미지 좌→우, 페이지 면적 220,400 px² 대비):
1. **로고 볼드** — 큰 로고 (페이지 면적의 **약 5.5%** ≈ 12,000 px²) 상단 + 서브타이틀 하단
2. **로고 미니멀** — 작은 로고 (페이지 면적의 **약 1.6%** ≈ 3,600 px²) 상단 + 서브타이틀 하단
3. **서브타이틀 없음** — 로고 하단 (페이지 면적의 **약 2.1%** ≈ 4,600 px²), 내부 화보 영역을 더 크게

**치수** (380 × 580): 내부 이미지 프레임 폭 약 340 · 좌우 여백 약 20 · **border radius** 기본 0 / 적용 12 / 강조 20~40

### 인너 photo 프레임 사용 시 — 로고·텍스트 거리 규칙 (thick frame · blur BG 공통)

> 인너 photo 프레임이 있는 레이아웃(thick frame · blur BG)에서 **로고와 텍스트는 페이지 경계보다 인너 photo 프레임에 더 가까이** 위치한다.

**거리 정의**:
- `a` = 로고/텍스트 ↔ 인너 photo 프레임 사이 간격
- `b` = 로고/텍스트 ↔ 페이지 경계 사이 간격 (위 로고=페이지 상단 / 아래 로고·텍스트=페이지 하단)

**규칙**: `a ≈ b` (거의 같음), 단 `b = a + 2` (페이지 경계 거리가 2px 더 멈 = 인너 photo에 2px 더 가까이)

**산식** (요소가 페이지 마진을 모두 채우는 경우):
- 페이지 마진 = `a + 요소_height + b` = `2a + 요소_height + 2`
- → `a = (페이지 마진 − 요소_height − 2) / 2`, `b = a + 2`
- → 요소 top y = (위 로고) `b` / (아래 로고·텍스트) `인너 bottom + a`

**적용 예시** (380 × 580 페이지 · PRENDANG 워드마크 기준):

| 위치 | 인너 photo | 페이지 마진 | 요소 (h) | a | b | 요소 top y |
|---|---|---|---|---|---|---|
| BLUR BG 위 로고 | (20, 77, 340, 440) | 77 (위) | 미니멀 PRENDANG (21.05) | 26.975 | 28.975 | **28.975** |
| BLUR BG 아래 텍스트 | (20, 77, 340, 440) | 63 (아래) | 시즌명 1행 (19.5) | 20.75 | 22.75 | **537.75** |
| THICK FRAME 아래 로고 | (24, 24, 332, 486) | 70 (아래) | thick PRENDANG (21.7) | 23.15 | 25.15 | **533.15** |

> 위 thick frame 표준 「화보 하단↔로고 22 / 로고 하단 22」(균등)는 이 규칙에 의해 「약 23 / 약 25」(b=a+2)로 보정된다.

## 레이아웃 가이드

**핵심**: 실제 콘텐츠의 시작을 알리는 표지 페이지

**필수 요소**: 배경 화보, 로고
**선택 요소**: 시즌명, 시즌 타이틀
**오버레이**: 없음 (화보 위에 로고·텍스트 직접 오버레이)

### 컬러 & 그림자
- 로고·텍스트는 **동일 컬러**, **기본은 흰색(white)**
- 배경 화보가 **아주 밝은 경우에만 검정** 사용 (밝음의 기준 = **01-D 묶음·하단 예시**, thin frame 모음 참고)
- 로고/텍스트의 **일부라도 밝은 배경과 겹쳐 가독성이 떨어지면 그림자를 반드시 추가**
  - **Drop Shadow**: 색 `#000000` 15% · 오프셋 X·Y `0` · Blur `40` · Spread `0`
  - 그림자는 로고·텍스트 **각 요소(위치)별로** 필요한 경우에만 적용

### 로고·텍스트 배치 유형 (01-A~D)
> thin frame / clean 공통 적용. 배치 예시는 위 「레이아웃 타입」의 thin frame / clean 캡처에서 확인할 수 있습니다 (01-A~D가 함께 보임).

| 유형 | 로고 위치 | 시즌명·타이틀 | 결합 방식 |
|------|-----------|---------------|-----------|
| **01-A** 로고 상단 | 상단 (중앙 또는 좌측) | 하단에 별도 배치 | 로고·텍스트 분리 |
| **01-B** 로고 중앙 | 화면 중앙 | 하단에 별도 배치 | 로고·텍스트 분리 |
| **01-C** 묶음·중앙 | 중앙 | 로고 바로 아래 시즌명 | 로고+시즌명 한 그룹 |
| **01-D** 묶음·하단 | 하단 | 로고 바로 아래 시즌명 | 로고+시즌명 한 그룹 |

> 분리형(01-A·B)은 시즌명 + 시즌 타이틀을 함께 노출, 묶음형(01-C·D)은 로고 + 시즌명만 노출하는 경향. 로고 위치·정렬은 화보의 여백·구도에 맞춰 선택합니다.

### 치수 가이드 (px) — 중앙 배치는 좌우 대칭이므로 좌우 여백 생략
- **좌측 정렬 시 좌측 여백**: 약 36~40
- **01-A**: 로고 상단 여백 약 60 / 하단 시즌명·타이틀 하단 여백 약 33
- **01-B**: 로고 세로 중앙 / 하단 시즌명·타이틀 동일
- **01-C**: 로고+시즌명 그룹 세로 중앙 / 그룹 내 로고–시즌명 간격 약 8
- **01-D**: 로고+시즌명 그룹 하단 여백 약 40

> **thick frame 적용 시**: 위 01-A~D(thin frame / clean 기준) 대신 「레이아웃 타입」의 thick frame 규칙(화보 여백 프레임 + 로고 기본 하단)을 따르며, 내지(03)는 **03-basic-frame과 기본 세트**로 사용합니다 (강제 아님).
