## 이번 세션 핵심 기법

- **제품컷 배경 이음새 제거 = 「이미지 가장자리 실측 → 존 fill 매칭」**. 누끼(배경삭제) 없이 해결.
  - 플랫컷 5종은 배경이 균일 `#F8F8F8` → 존 fill 솔리드로 동일색.
  - 모델컷 2종(원피스·데님자켓)은 배경이 **비네트형 세로 그라디언트** → 존 노출 구간의 소스 행을 **7등분 샘플링**해 GRADIENT_LINEAR 7-stop으로 재현. (2-stop 선형은 중간부가 10~15레벨 어긋나 밴드가 보였음 — 실측 후 교정)
  - 샘플 코드: `PIL`로 `(zoneY − rectY)/scale` → 소스 행 → 좌우 가장자리 36px 중앙값.
- **제품 크기 정규화**: `alpha` 대신 **밝기 임계값(<200) bbox**로 상품 실루엣을 잡고, 면적 S=55,000 고정 + `w=√(S·a), h=√(S/a)` + 폭 300 / 높이 270 캡. 모델 전신컷은 면적 정규화 대상에서 빼고 **전신 높이 290px** 기준으로 별도 처리.
- **`upload_assets`의 `nodeIds`**로 7장을 RECT fill에 직접 꽂으면 RECT 사이즈·위치가 보존된다(원본비율 유지 구조 그대로).
