### C. 이미지 배치 구조 전면 교체 ✅

지난 시안 노드를 `clone()`으로 재사용하면서 **fill의 CROP(`imageTransform`)** 이 딸려온 상태였음. 사용자 지시로 전면 교체.

| 변경 전 | 변경 후 |
|---------|---------|
| `scaleMode: 'CROP'` + `imageTransform` (fill 단계 크롭) | **`scaleMode: 'FILL'` + transform 없음** |
| 크롭 비율이 fill에 고정 → 위치·배율 재조정 불가 | **원본 비율 RECT를 `clipsContent=true` 프레임 안에 넣고 x·y·size만 조정** |

**imageTransform → 프레임+RECT 환산 공식** (다음 세션에서 재사용 가능)

```
region(px) = { x: tx*W, y: ty*H, w: sx*W, h: sy*H }   // tx,ty,sx,sy = imageTransform
scale      = 표시폭 / region.w
프레임 크기 = 표시폭 × (region.h * scale)
RECT 크기   = (W*scale) × (H*scale)
RECT 위치   = (-region.x*scale, -region.y*scale)
```

## 핵심 설계 결정사항

- **A·B를 "컬러 변주"가 아닌 "구조 변주"로 잡는다**: 1차 시안이 지난 시즌 골격 그대로여서 반려됨. A·B 차이뿐 아니라 **지난 시즌 대비 차이**도 시안 채택 기준에 포함해야 한다. 정렬(중앙↔좌)·컨테이너(카드 유무)·CTA 형태를 축으로 잡으면 한눈에 구분된다.
- **TYPE B는 클라이언트 자체 시안 언어를 계승**: 엑셀 Carousel 7의 매장 정보 목업이 「검정 헤더 밴드 + 흰 본문 + 얇은 테두리 + 아웃라인 박스」 구조. 뒤 페이지와 한 벌로 붙고 클라이언트 설득 논거가 된다.
- **모든 이미지는 fill 크롭 금지, 프레임 clip으로만 크롭**: 로고·누끼처럼 여백 제거가 필요한 자산도 `imageTransform` 대신 tight 프레임 + 원본비율 RECT 위치 조정으로 처리. 이후 사용자가 프레임 안에서 자유롭게 드래그 조정 가능.
- **화이트 로고 = 마스크 반전**: 원본 로고는 검정 워드마크 투명 PNG. 다크 밴드 위에서는 `logo-img.isMask = true` + 그 위에 화이트 RECT를 얹어 반전. 이미지 재가공 없이 처리되며 원본비율 구조도 유지된다.

## Figma MCP 기술 메모

1. **`Apple SD Gothic Neo`는 MCP 환경에서 로드 불가** (`listAvailableFontsAsync` 결과 빈 배열). 지난 시안 B01·B02 텍스트가 이 서체라 **내용 수정조차 막힘** → 신규 텍스트는 Pretendard로 작성했다. 이 파일의 기존 텍스트를 편집해야 하면 폰트 업로드가 선행돼야 한다.
2. **`node.clone()`은 fill의 `imageTransform`까지 그대로 복제**한다. 지난 시안 자산 재사용 시 CROP이 딸려오므로 반드시 `scaleMode`/`imageTransform`을 확인하고 FILL 구조로 재작성할 것.
3. **`upload_assets`는 10MB 제한**. 커버 원본 25MB(6198×9297) → `sips -Z 2400`으로 1600×2400(333KB)로 리사이즈 후 업로드. 380×580 페이지 기준 4배 해상도라 충분.
4. **이미지 natural size는 `figma.getImageByHash(hash).getSizeAsync()`** 로 확인. 원본 비율 오차 검증에 필수.
5. **마스크는 `children` 배열에서 자기보다 뒤(위 z) 형제에 적용**된다. `logo-img`를 index 0 + `isMask=true`, 화이트 RECT를 index 1에 두면 반전 로고가 된다.
6. **섹션(`SECTION`) 자식의 x·y는 섹션 기준 상대 좌표.** `appendChild` 후 x·y를 설정해야 의도한 위치에 놓인다.
7. **`use_figma` 쓰기 전 `get_metadata`로 현재 값 재확인 필수.** 이번 세션에도 작업 중 사용자가 A01 화보를 386.67×580 → 414×622로 조정하고 B02 헤더를 오토레이아웃으로 묶은 것이 확인됐다 (재설계로 흡수, 사용자에게 사전 고지함).
