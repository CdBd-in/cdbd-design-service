## 기술 메모 (트러블슈팅)

1. **auth.py 구버전 주의**: 이 기기(`~/.config/cdbd/auth.py`, 6/9자) 는 cdbd.env 자동 재로그인 없음. refresh 실패 시 **`cdbd-templates/.env`** 계정으로 password grant 직접 수행할 것. anon key는 auth.py 상수 `SUPABASE_ANON` (문자열 3분할 연결이라 단순 정규식으로 못 뽑음 — `from auth import SUPABASE_ANON` 권장)
2. **location 카드 주소 렌더**: 뷰어 표시 텍스트 = `inputValue`, CSS `white-space: pre-wrap`이라 `\n` 그대로 줄바꿈됨. 카드 `wordBreak: break-all`이라 폭 초과 시 단어 중간에서 꺾임 → 긴 영문 주소는 수동 `\n` 분할 필수
3. **에디터 열어둔 채 PATCH 금지** (race condition): 검증용으로 브라우저에서 editor를 연 뒤 추가 PATCH할 땐 **먼저 `about:blank`로 이동해 탭 비우고** PATCH → 재접속 검증
4. **browse CLI**: JS 실행은 `$B js "(()=>{...})()"` (`eval`은 파일 경로 인자임). 로그인 폼은 `#email`/`#password` fill → `press Enter`
5. 작업 후 `$B stop`으로 브라우저 세션 폐기함 — 다음 세션 브라우저 작업 시 재로그인 필요
