## Figma 빌드 기술 메모 (재현·디버그용)

- **`figma:figma-use` 스킬 미등록** → MCP 리소스 `skill://figma/figma-use/SKILL.md` 읽어서 로드. `use_figma` 호출 시 `skillNames:"resource:figma-use"`.
- **`resize()`는 primary/counterAxisSizingMode를 FIXED로 리셋** = 최대 함정. AUTO(hug) 프레임에 resize 쓰면 높이 고정·clip됨 → **resize 후 `primaryAxisSizingMode='AUTO'` 재설정**. (06 표, 17 말풍선에서 발생·수정)
- **wrapping 텍스트** = `textAutoResize='HEIGHT'` 먼저 + 그 다음 `layoutSizingHorizontal='FILL'`. 안 하면 1글자 폭 세로 collapse. (14 콜아웃에서 발생·수정)
- **이미지 업로드** = `upload_assets`(count=N)로 URL 발급 → `curl -F "file=@..."` POST → 응답 `imageHash` 받아 **`rect.fills=[{type:'IMAGE',imageHash,scaleMode}]` 직접 set**. nodeId 지정해도 fill 자동적용 안 되는 케이스 있음. nodeId 없이 올리면 임시 프레임 생성됨 → 삭제 필요. QR은 scaleMode **FIT**(크롭 방지), 사진은 FILL.
- **10MB 초과 사진**(기후위기·물류) = PIL로 max 1400px·q82 리사이즈 후 업로드.
- 폰트 가용: WAGURI Regular / Gmarket Sans Bold·Light / Pretendard 전부 OK.
- 한글 폴더 경로 = Python `pathlib`만 정상(Bash find/grep 실패).
