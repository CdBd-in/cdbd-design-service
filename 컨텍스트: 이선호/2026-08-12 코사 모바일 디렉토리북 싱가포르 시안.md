## 6. 기술 메모 (다음 세션 주의)

1. **표지 AI 이미지 재생성 = OpenAI API 사용**(Flow 세션 만료됨, headless 불가).
   - 키: `~/.config/cdbd/credentials.json` → `openai_api_key`.
   - `POST https://api.openai.com/v1/images/generations`, `model:"gpt-image-1"`, `size:"1024x1536"`(세로, 380×580에 근접), `n:2`, `quality:"high"`. 응답은 `data[].b64_json`(base64) → 디코드 저장.
   - 프롬프트 방향: 추상 3D 네트워크(글로우 노드가 하단 기반→상단으로 상승 = Infra→Industry), 딥네이비 배경, 하단에 싱가포르 마리나베이 실루엣, **텍스트·로고 금지**.
2. **에셋 재생성(로컬)** — PyMuPDF(`import fitz`) + PIL 사용.
   - KOSA 로고: CI `.ai`를 `get_pixmap(dpi=300, alpha=True)` 렌더 → 행 밴드 분리 → 좌측 영문 락업만 크롭(한국어 명칭 제외).
   - Cobaltix 흰 워드마크: 소개덱 p14 좌상단 크롭 → **alpha = luminance 키잉**(흰 텍스트→투명 배경) 하면 다크 배경에 깔끔.
   - 갤러리: 소개덱 p4(Solution)·p5·p6(UseCase)·p8(Impact) `get_pixmap(dpi=200)`.
3. **use_figma 규칙**(figma-use 스킬 항상 로드): 폰트는 사용 전 `loadFontAsync`; 색 0–1 범위; fills 새 배열로 재할당; 페이지 전환 `setCurrentPageAsync`; `figma.notify()` 금지; 텍스트 wrapping은 `textAutoResize='HEIGHT'`+명시 width. 변수 fill 바인딩은 `setBoundVariableForPaint(paint,'color',var)`가 **새 paint 반환** → 재할당.
4. **갤러리 캐러셀 구현** — 가로 auto-layout(itemSpacing 12)에 316×178 카드 4개, strip을 `layoutSizingHorizontal='FIXED'` + `resize(316*4+36,178)`로 폭 초과시켜 프레임 clip으로 peek 연출. 아래 도트 인디케이터(첫 도트=accent 16×4 pill, 나머지 4×4).
5. **인증 헬퍼** — `~/.config/cdbd/auth.py get_credentials()` 로 figma_pat/openai 등 접근 가능.
