## 핵심 설계 결정사항

- **CdBd 블록 = Figma 카드 1:1**: 연속된 배경(크림 지브라 등)도 **같은 색 카드 여러 장이 gap 0으로 타일링**된 것. 한 패널에 다 넣지 않음. → CdBd 등록 시 1:1 매핑.
- **1 텍스트 카드 = 1 텍스트 박스**: 오토레이아웃으로 묶인 여러 텍스트 박스 ❌. 문단·줄은 **줄바꿈(\n)** + 혼합런(setRange*)으로.
- **A=개별 카드 / B=패널 1박스**: A(에디토리얼)는 텍스트 카드를 잘게 분리, B(모던)는 틴트 패널 1장=텍스트 박스 1개(B01 인사말·B03 패널·B02 지원금 동일 패턴).
- **카드 외부여백은 카드별로**: 부모 오토레이아웃 gap 대신 **각 카드가 자기 외부여백을 가짐**. 배경 있는 카드 = 「외부여백 래퍼 + 내부 padding 패널」 2-depth.
- **텍스트 유지 + 디자인만 변경**(원칙) — 단 줄바꿈/카드구조는 CdBd 따름. A/B 내용 불일치(무 면적 A15.8/B15.7, 대파 전망 본문 등)는 사용자가 CdBd에서 별도 관리.

## Figma MCP 기술 메모 (다음 세션 주의)

1. **`use_figma`에 `createImageAsync` 없음** — `createImage(bytes)`/`getImageByHash`만 존재. 외부/로컬 이미지 업로드는 **`mcp__claude_ai_Figma__upload_assets`**(count=1 + nodeId → submitUrl 반환 → `curl -F "file=@..." submitUrl`로 원본 POST, fill 자동 설정). 인라인 base64는 code 50000자 한계라 다운스케일 필요.
2. **폰트 로드 필수** — 텍스트 노드의 `characters`/`layoutSizing`/`textAlign`/`setRange*` 모두 현재+신규 폰트 `loadFontAsync` 선행. `Gmarket Sans` style은 **`Bold`/`Light`**, `WAGURI`는 **`Regular`만**.
3. **구분선 진짜 스펙은 block의 `divider` 객체**(`shape:'dash'|'straight'`, `strokeColor`, `strokeWidth`) — `style.borderColor`(#292929)는 기본값 잔재. Figma 점선은 LINE 노드 + `dashPattern=[4,4]` + `strokeWeight`.
4. **셀렉터 주의**: `findAll(높이≤2 SOLID rect)` 같은 광범위 셀렉터는 **헤더 햄버거 바**까지 잡음 → 폭 등으로 추가 필터.
5. **카드 타일링**: 자식 카드 width는 `layoutSizingHorizontal='FIXED'` + `resize(348, h)`(인셋 16) / 풀폭은 `'FILL'`. 부모 V 오토레이아웃 `counterAxisAlignItems='CENTER'`로 348 카드 중앙 정렬.
6. **CdBd 박스모델**: 검증 공식 `Figma_px = CdBd% × 380/100`(페이지폭 380 기준). 블록 margin "0px 16px"=좌우16 인셋. padding "상 좌우 하" shorthand.
