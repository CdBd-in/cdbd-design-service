## 핵심 룰 리마인더 (다음 세션 진입 시 즉시 적용)

- **`figma:figma-use` 스킬을 `use_figma` 호출 전 반드시 로드** (CLAUDE.md)
- **텍스트 편집 = canonical recipe**: 현재 폰트 로드(`getStyledTextSegments`→`loadFontAsync`) → `await` → 변경 → 변경된 노드 ID 반환
- **WAGURI는 Regular만 존재**, Gmarket Sans는 Bold/Light
- **`use_figma.exportAsync`는 base64 truncation 한계 있음** → 3배 export는 Figma REST API (PAT) 사용
- **구분선 스펙은 block의 `divider` 객체** (shape/strokeColor/strokeWidth) — `style.borderColor` 아님
- **한글파일 스크린샷 폴더 경로 한글 인코딩 주의** — Python `pathlib` 사용
