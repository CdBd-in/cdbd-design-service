## 핵심 설계 결정사항

- **프레임 번호 = 읽는 순서**: 목차가 6항목(주제 단위)이고 실제 페이지는 11장이라 번호가 어긋난다. 목차는 「주제 목차」, 프레임명은 「페이지 순번」으로 역할을 분리하고, 히어로 kicker에서 숫자를 뺐다(`03 DAY 01` → `DAY 01`).
- **안내 vs 일자별 2계열**: 사용자가 *"02와 03·04 히어로가 너무 비슷하다"*고 두 번 지적. 최종 해법은 **투어 요약에서 사진을 완전히 제거**하고 활자 헤더로 전환. 첫 스크롤 대비 = 활자 vs 이미지.
- **아이콘은 나열이 아니라 결속**: 아이콘·품목명·설명·허용여부를 **한 카드**로 묶는다. PPT 원본 패널 구조와 동일하므로 근거도 명확.
- **표 → 카드 전환 기준**: 아이콘을 넣었을 때 헤더 셀이 줄바꿈되는 폭이면 표를 포기하고 카드로 간다(모바일 640px 기준).
- **인포그래픽은 재조판이 원칙**: 항공사 원본 인포그래픽은 640px에서 6~9px로 판독 불가 → 전부 재조판. **예외는 지퍼백 도해뿐**(그림 자체가 정보라 리컬러해서 사용).
- **히어로와 아이템 사진이 겹칠 때**: 같은 원본에서 **다른 구간을 밴드 크롭**해 별개 장면처럼 보이게 한다.
- **불릿도 본문 22px**: 노년층 가독성 우선. 서브 불릿을 20px로 두는 위계보다 통일이 낫다고 판단.

## Figma MCP 기술 메모

1. **`use_figma` 호출 전 `figma:figma-use` 스킬 로드 필수** (CLAUDE.md 규칙).
2. **섹션 리사이즈 시 좌표계 주의** — 섹션 자식의 `x/y`는 **섹션 상대 좌표**다. `maxB - sec.y`가 아니라 **`maxB + 여백`**으로 계산해야 한다. (오늘 한 번 틀려서 높이가 3594로 잘못 잡혔음)
3. **`node.query()`에 한글 선택자 불가** — `Invalid selector: unexpected character (0xec)`. `findAll(predicate)` / `findOne(predicate)` + JS 문자열 비교를 쓸 것.
4. **`appendChild`는 void 반환** — `parent.appendChild(T(...)).layoutSizingHorizontal='FILL'` 하면 null 에러. `add(parent, node)` 헬퍼로 append 후 sizing 설정.
5. **`upload_assets`는 임시 RECT 경유가 안전** — `nodeIds`로 타깃을 지정하고 응답의 `imageHash`를 받아 쓴 뒤 임시 노드 삭제. shell `for` 루프 + `set --` 조합은 curl 출력이 유실된 적 있음 → **python `subprocess`로 업로드**할 것.
6. **`exportAsync` base64 truncation** — 고해상도 원본이 필요하면 **Figma REST `GET /v1/files/{key}/images`** 로 hash→URL 맵을 받아 직접 다운로드. PAT는 `~/.config/cdbd/credentials.json`의 `figma_pat`.
7. **일괄 스타일 변경은 색·자간까지 조건에 넣을 것** — 「19 Bold 자간4」만으로 찾으면 러닝헤드(`#5C564C`)와 카드 라벨(`#9A4A1E`)이 함께 잡힌다. 색으로 분기 필수.
8. **노드 이름은 생성 시점 텍스트로 굳는다** — 사용자가 내용을 바꿔도 이름은 그대로(`02 TOUR SUMMARY` → 실제 `일정 요약`). **이름 말고 `characters`를 읽어 판단할 것.**
9. **삭제 전 반드시 노드 확인** — 오늘 `2117:39`를 「음식물류 카드」로 착각하고 지웠는데 실제로는 「면세품 카드의 주석」이었다(복구 완료). `kill(id)` 전에 `name`·`characters` 확인.
10. **⚠️ 사용자와 동시 편집이 기본 전제** — 턴이 바뀌면 값이 달라져 있다. 쓰기 전 항상 현재 상태를 read-only로 확인하고, 내 설정값과 다르면 사용자 수정으로 간주해 덮어쓰지 말 것.
