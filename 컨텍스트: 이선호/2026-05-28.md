## 2. 핵심 개념 정리

### 시안 / 초안
- **시안**: 동일 콘텐츠·구성요소로 **서로 다른 디자인 2안(A·B)** 제시 → 각 4페이지(시안표지 + 01 + 02 + 03) = 총 8페이지
- **초안**: 시안에서 선택된 안 기반으로 **전체 페이지** 완성

### 파일명 체계
- 시안: `A`/`B`(시안표지), `A01~A03`/`B01~B03`
- 초안: `01`, `02`, `03` …
- OG: `og.jpg` (1배수 JPG)
- 세부 구분: `A02-1`(섹션), `A03-top/bottom`(고정 영역), `A04-btn/insta`(역할)
- swp: `03-BG`, `03-swp1`, `03-swp2` …
- scl: 요소별 `03-1-1`, `03-2-1` … (프레임명과 동일)

### 표지 레이아웃 타입
- `thin frame` (외곽선 있음) / `clean` (외곽선 없음) — 둘 다 화보 위 오버레이
- `thick frame` (화보를 두꺼운 여백 안에 배치, 로고는 여백에)
- `blur BG` (블러·확대·dim 가공 배경)

### 페이지별 정의
- **01** = 각 시안의 표지 (필수: 배경 화보 + 로고)
- **02** = 브랜드·시즌 소개 (필수: 화보 위 #000000 dim 오버레이 + 로고 + 시즌 설명)
- **03** = 내지 (basic / swp / scl 3계열)

## 3. 레이아웃 핵심 원칙

- **01·02 레이아웃 1순위 결정 기준 = 배경 화보의 여백** (모델 얼굴이 상단·양옆에서 떨어진 정도)
- 로고와 텍스트는 **항상 동일 컬러**
- 02는 화보 위 `#000000` dim 오버레이 (기본 40%, 화보 밝기에 따라 조정)
- 정확한 픽셀값보다 **범용 비율·여백**으로 기재 (로고 규격은 브랜드마다 다름)
- **border radius**: 모든 타입 기본 0 / 내부 이미지 프레임 있는 타입(thick frame, blur BG, swp)은 12 기본, 귀여운·젊은·발랄·튀는 느낌 강조 시 20~40

## 4. 03 내지 3계열

| 계열 | 유형 | 특징 |
|------|------|------|
| basic | full / frame | 스크롤 없음. full은 화보 여백 따라 텍스트 정렬, frame은 카테고리(suit, shirt 등) 포함 |
| swp | clean BG / blur BG | 좌우 스와이프 갤러리 카드. BG 고정, swp 페이지만 스와이핑 |
| scl | grid / row | 스크롤 내지. 메인 화보에 번호 마커 + 하단 상품 목록. 요소별 개별 내보내기(3배) |

### swp 그리드 규칙 (요약)
- 누끼컷: 배경 제거 후 여백 없이 상품 사이즈에 딱 맞게 크롭
- 동일 라인 제품: 3개까지 한 행, 4개 이상 2단 그리드
- 색상만 다른 동일 제품: 좌우 간격 좁히고 제품명 1개 중앙정렬
- 전체 프레임 상하/좌우 간격 일정 유지

### scl 마커 규칙 (오늘 상세화)
- 마커: Pretendard Medium 15px · 흰색 · 약 15×15, 하단 목록 번호와 매칭
- **배치 원칙**: 중요 부위(로고·모델) 회피 / 정중앙보다 구분되는 위치 / 작은 제품은 가장자리
- 가려진 상품(아우터 등): 연결선(흰 1px, 약 30) 빼서 표시

## 5. Figma 작업 & 폰트 이슈 (중요)

- **파일 key**: `SI36czRu3lBgkPzyrnPYkB`
- **기본 폰트 = Pretendard** (문서·Figma 모두 통일 완료)
- **로컬 설치 폰트(`~/Library/Fonts`)는 MCP 환경에서 인식 불가** — Figma 화면에 보여도 자동화로 로드 불가
- **MCP에서 로드 가능 = Figma 내장 Google Fonts + 팀 "Your uploaded fonts" 업로드 폰트**
- Pretendard를 팀 폰트에 업로드 → 9개 스타일 인식 → 적용 성공
- ➡️ 사용자가 다른 폰트 요청 시: `listAvailableFontsAsync` 확인 → 없으면 **"팀 'Your uploaded fonts'에 업로드 요청"** 안내
- swp 텍스트를 AktivGrotesk → Pretendard로 변경 (whole-node `fontName` 교체로 missing-font 제약 우회)
