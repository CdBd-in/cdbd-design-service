## A-2. 핵심 개념 정리

### 시안 / 초안
- **시안**: 동일 콘텐츠·구성요소로 **서로 다른 디자인 2안(A·B)** 제시 → 각 4페이지(시안표지 + 01 + 02 + 03) = 총 8페이지
- **초안**: 시안에서 선택된 안 기반으로 **전체 페이지** 완성

### 파일명 체계
- 시안: `A`/`B`(시안표지), `A01~A03`/`B01~B03`
- 초안: `01`, `02`, `03` …
- OG: `og.jpg` (1배수 JPG)
- 세부 구분: `A02-1`(섹션), `A03-top/bottom`(고정 영역), `A04-btn/insta`(역할)
- swp: `03-BG`, `03-swp1`, `03-swp2` …
- scl: 요소별 `03-1-1`, `03-2-1` … (프레임명과 동일)

### 표지 레이아웃 타입
- `thin frame` (외곽선 있음) / `clean` (외곽선 없음) — 둘 다 화보 위 오버레이
- `thick frame` (화보를 두꺼운 여백 안에 배치, 로고는 여백에)
- `blur BG` (블러·확대·dim 가공 배경)

### 페이지별 정의
- **01** = 각 시안의 표지 (필수: 배경 화보 + 로고)
- **02** = 브랜드·시즌 소개 (필수: 화보 위 #000000 dim 오버레이 + 로고 + 시즌 설명)
- **03** = 내지 (basic / swp / scl 3계열)

## A-3. 레이아웃 핵심 원칙

- **⚠️ (가장 중요) 모든 화보 이미지는 절대 크롭하지 않는다** — 원본 비율 유지, clip 프레임 안에서 위치만 조정해 노출 영역 결정(중요 부분=얼굴·착장 상품 비절단). *(B 세션에서 확립 → 규칙 문서 반영)*
- **01·02 레이아웃 1순위 결정 기준 = 배경 화보의 여백** (모델 얼굴이 상단·양옆에서 떨어진 정도)
- 로고와 텍스트는 **항상 동일 컬러**
- 02는 화보 위 `#000000` dim 오버레이 (기본 40%, 화보 밝기에 따라 조정)
- 정확한 픽셀값보다 **범용 비율·여백**으로 기재 (로고 규격은 브랜드마다 다름)
- **border radius**: 모든 타입 기본 0 / 내부 이미지 프레임 있는 타입(thick frame, blur BG, swp)은 12 기본, 강조 시 20~40

## A-4. 03 내지 3계열

| 계열 | 유형 | 특징 |
|------|------|------|
| basic | full / frame | 스크롤 없음. full은 화보 여백 따라 텍스트 정렬, frame은 카테고리(suit, shirt 등) 포함 |

## B-Figma MCP 기술 메모
1. **이미지 원본 픽셀 크기**는 `figma.getImageByHash(hash).getSizeAsync()`로 확인 (이번엔 1080×1920 = 9:16).
2. **화보 비크롭 = 원본 비율 rect + scaleMode FILL**(rect 비율을 이미지 비율과 동일하게 맞추면 내부 크롭 없음) + 프레임 `clipsContent`로 노출 영역 제어. 위치는 rect의 `y`로 조정.
3. **전체 이미지(클립 밖까지) 확대 확인**: 프레임 `clipsContent=false`로 잠시 끄고 rect를 `get_screenshot`/`node.screenshot()` → 작업 후 **반드시 `true`로 복구**.
4. **고배율 검증**: `get_screenshot`는 노드 native 크기 이상으로 디테일이 안 늘 수 있어, 다운로드 후 **PIL로 crop+resize**해 옷 경계 확인이 가장 정확. (Pillow는 `pip install Pillow`)
5. **래스터 로고 검정 반전 = 알파 마스크**: 흰 로고 이미지 rect(`isMask=true, maskType='ALPHA'`)를 먼저, 그 뒤에 검정 rect를 두면 검정 워드마크로 마스킹됨.
6. 텍스트 편집은 canonical recipe(현재 폰트 `getStyledTextSegments(['fontName'])`→`loadFontAsync`→변경) 준수.
