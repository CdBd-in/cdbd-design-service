## ⚠️ 다음 작업 때 주의

- **공개본은 게시 시점 스냅샷이다.** `editor` PATCH만으로는 공개 주소가 안 바뀐다. 공개 반영은 사람이 에디터에서 다시 게시하거나, 지시가 있을 때 `editor_published` PATCH
- **소유자가 다르면 `save_editor_version`이 403**이다. 그래서 16:14 갱신은 CdBd 「버전 히스토리」에 없다. 다음부터 UI로 게시하면 기록된다
- **이미지 라이브러리 삭제 전에 게시본까지 확인할 것.** 오늘 에디터만 보고 지웠다면 공개 페이지 8~11p가 깨질 뻔했다. 안전 확인이 게시본을 발견해 멈췄다. `delete_from_library`는 **저장소 파일까지 지워 복구가 안 된다**
- **PATCH 직전 재조회로 스냅샷과 비교**하고 다르면 멈춘다. 에디터 탭이 열려 있으면 자동저장이 덮어쓸 수 있다. `updated_at`은 내 PATCH로는 안 바뀌고 클라이언트 저장 때 바뀐다 — 값이 바뀌었으면 탭이 열려 있었다는 신호
- **`EuropaNuova`는 자동화에서 로드되지 않는다.** 코드 글자 내용을 못 고친다. 그래서 뺀 줄은 **글자별 투명 처리**로 숨기고 위치만 옮겼다. 화면·이미지에는 안 보이지만 **글자를 직접 편집하면 숨은 줄이 나타난다**. 2p는 글자 상자 2개(9:8 · 24:4), 11p(24:3)는 10p 글자 복제
- **Figma PAT 만료**(`credentials.json`): REST 내보내기 불가. 2배 내보내기 = 프레임 사본 `TMP-` → `rescale(2)` → `get_screenshot`(maxDimension 1236) → 사본 삭제. `get_screenshot`은 원본 크기 이상으로 키워 주지 않는다
- **Vimeo**: 업로드 직후엔 oEmbed 404(변환 중) → 몇 분 뒤 200. 자동화 브라우저는 봇 검사로 막혀 재생 확인이 안 된다(10월호 영상도 동일) → 사람이 확인
- **공식몰 검색**: `https://sisun.com/searchList?brand_nm=&brand_mng_idx=&search=상품명&ithrCd=` — 상품명에 `100%`가 있으면 오류 페이지로 가니 기호를 뺀다. 상품 페이지는 `https://sisun.com/EBM/shop/view?goods_code=…`, 대표 사진은 `og:image`. **대표 사진 색이 페이지 색과 다를 수 있으니** 색상 목록도 볼 것. 상품 페이지·검색은 **UTM을 뗀 주소로** 접속
