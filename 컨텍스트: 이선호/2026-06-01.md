## 3. 디자인 룰 4종 확정 — 자주 놓치는 누락·실수

반복된 피드백을 누적해 **체크리스트·디자인 가이드·CLAUDE.md**에 룰화.

### ① 화보 이미지 = 별도 자식 RECTANGLE 레이어 (프레임 fill 금지)

**Anti-pattern** (지양):
```js
frame.fills = [{ type: 'IMAGE', scaleMode: 'FILL', imageHash: ... }];
// 사이즈/위치 조정 불가, imageTransform/CROP 의존
```

**Correct pattern** (적용):
```js
const rect = figma.createRectangle();
rect.resize(442, 580);  // 원본 비율 442:580 = 1440:1890 그대로
rect.fills = [{ type: 'IMAGE', scaleMode: 'FILL', imageHash: ... }];
frame.insertChild(0, rect);  // z-index 0 (가장 아래)
rect.x = -31; rect.y = 0;  // 모델 중앙으로 위치 조정
// 부모 frame.clipsContent = true (이미 설정됨)
```

→ A01·A02·B02·A03-BG 4개 페이지 모두 마이그레이션 완료. CLAUDE.md 「레이아웃 핵심 원칙」 + [[2-1. 공통]] 「화보 이미지 배치」에 반영.

### ② 03 화보 페이지 — 모델 중앙 + 풀샷 머리·발 모두 표시

- 모델이 좌우·상하 중앙에 위치
- 풀샷 원본은 **머리·발 모두 잘리지 않고 보이도록** child rect 사이즈/위치 조정
- 머리 상단 여백 적절 (지나치게 넓거나 좁지 않게)

### ③ 누끼 그리드 같은 라인 = top→bottom 순서

같은 세트(상하의 매칭)를 한 행에 배치할 때 **좌측=상의(top), 우측=하의(bottom)** 고정.
- ✅ Jacket 좌 + Pants 우
- ✅ Cropped Jkt 좌 + Cotton Short 우
- ✅ Linen Blended Jacket 좌 + Linen Short 우

### ④ swp 2행 그리드 = 카드 내 vertical center

swp 페이지에 2행만 배치되는 경우 (swp3 등), **상하 균등 여백으로 수직 중앙 정렬**.
- B03-swp3 (340×520): row 1 y=106, row 2 y=272 → 상하 여백 106/106
- A03-swp3 (380×580, 상단 로고): row 1 y=136, row 2 y=302 → 카드 중앙 정렬

### 5.4 OG·URL 정보 편집 모달 매핑

상단 「URL 생성하기」 → **「URL 정보 편집하기」** 모달에서:
- **페이지 주소** 슬러그 (`https://cdbd.in/2account/{slug}`)
- **공유 데이터 → 썸네일** = `og.jpg` 업로드 (CdBd 권장 800×400px = 1-1 규격과 정확 일치)
- **공유 데이터 → 제목** = **브랜드 영문명** (예: `PRENDANG`)
- **공유 데이터 → 설명** = **컬렉션명** (예: `26 SS Collection`)

⚠️ OG는 **멀티페이지 전체 1개** (페이지별 X).

### 5.5 CdBd 등록 워크플로우 7단계 신설

사용자 트리거: "(시안/초안) 이미지 CdBd 콘텐츠로 만들어줘" · "CdBd 페이지 만들어줘" · "CdBd에 올려줘" → 자동 워크플로우.

| 단계 | 내용 |
|------|------|
| ① | 시안/초안 구분 + `~/Desktop/{브랜드명}/시안 or 초안/` 폴더 파일 점검 |
| ② | 브랜드 영문명·컬렉션명 — `[문서]`(엑셀·PPT) 우선, 없으면 사용자에게 묻기 |
| ③ | GStack 브라우저 + `cdbd.in` 로그인 |
| ④ | 새 멀티페이지 380×580 + 페이지 테마 위저드 (프리텐다드 기본) |
| ⑤ | 페이지별 카드 등록 (매핑 표 그대로 — `03-BG`는 페이지 케밥 / 03-row 구분선 / `03-logo` 비고정) |
| ⑥ | URL 정보 편집 — **시안 슬러그=`{브랜드영문}-{YYMM}` 자동** · **초안 슬러그=문서 확인 후 없으면 사용자 확인** / OG·제목·설명 입력 |
| ⑦ | **게시 직전 사용자에게 반드시 확인** → 게시 → URL·페이지 수·종류 보고 |

mermaid 도식 포함. **시안·초안 같은 워크플로우** (폴더 경로·파일 패턴·슬러그 규칙만 분기).
