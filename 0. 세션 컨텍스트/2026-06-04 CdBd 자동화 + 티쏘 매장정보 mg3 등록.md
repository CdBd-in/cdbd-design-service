```bash
Header: X-Figma-Token: figd_*
Response: {"images": {"node_id": "https://figma-alpha-api.s3...amazonaws.com/..."}}
```

## 핵심 설계 결정사항

- **Supabase 직접 호출이 UI 자동화보다 우월**: React PointerEvent / dropzone / file picker 우회 시간 누적 매우 큼. 백엔드 직접 호출이 빠르고 안정적.
- **Figma REST API > use_figma.exportAsync**: 후자는 base64 응답이 모델 컨텍스트 통해 전달되며 truncation으로 일부 손실. REST API는 S3 URL만 응답 → curl로 디스크 직접 저장.
- **Slug 언더바 필수**: CdBd UI 검증이 대시 거부. 자동 생성 패턴 `{brand}_{YYMM}` (예: `tissot_2606`).
- **카드 디자인 보드 메뉴만 사용**: 임의 CSS 키 (padding 124px 가짜 가운데 정렬, marginLeft/Right 등) 금지. UI 노출 옵션이 저장하는 JSON 키만 PATCH.
- **그리드 일치 = px margin**: 버튼·multiCard·divider 같은 그리드 요소는 % width 대신 px margin 사용. % 는 디바이스마다 다른 px로 계산되어 그리드 어긋남. 이미지 카드(footer)만 % 사용 가능.
- **margin shorthand는 3-value만**: CdBd가 `"상 좌우 하"` 만 인식. 4-value (`"상 우 하 좌"`)·개별 키 (`marginLeft/Right`) 무시.
- **width<100% + margin LR 0** → CdBd 자동 가운데 정렬. margin LR 설정하면 좌측 부착 (방해).
- **이미지 카드는 minimal keys 우선**: 텍스트 카드용 키(fontSize, lineHeight 등) 추가하면 이미지 사이즈 작아짐.
- **게시 후 수정**: `editor` PATCH만으로 게시 URL에 반영 안 됨. `editor_published` 동기화 PATCH 필요 (또는 사용자가 다시 게시).
