- **로고 = 래스터 검정 반전**(사용자 지정): 검정 벡터 로고가 이미 있었으나, 사용자가 `16008:789` 래스터를 반전해 쓰라고 지정 → **알파 마스크**(흰 로고 alpha로 검정 사각형 마스킹)로 구현. 결과는 검정 FURSAC 워드마크.

## Figma MCP 기술 메모

1. **이미지 원본 픽셀 크기**는 `figma.getImageByHash(hash).getSizeAsync()`로 확인 (이번엔 1080×1920 = 9:16).
2. **화보 비크롭 = 원본 비율 rect + scaleMode FILL**(rect 비율을 이미지 비율과 동일하게 맞추면 내부 크롭 없음) + 프레임 `clipsContent`로 노출 영역 제어. 위치는 rect의 `y`로 조정.
3. **전체 이미지(클립 밖까지) 확대 확인**: 프레임 `clipsContent=false`로 잠시 끄고 rect를 `get_screenshot`/`node.screenshot()` → 작업 후 **반드시 `true`로 복구**.
4. **고배율 검증**: `get_screenshot`는 노드 native 크기 이상으로 디테일이 안 늘 수 있어, 다운로드 후 **PIL로 crop+resize**해 옷 경계를 확인하는 게 가장 정확. (Pillow는 `pip install Pillow`로 설치)
5. **래스터 로고 검정 반전 = 알파 마스크**: 흰 로고 이미지 rect(`isMask=true, maskType='ALPHA'`)를 먼저, 그 뒤에 검정 rect를 두면 검정 워드마크로 마스킹됨.
6. 텍스트 편집은 canonical recipe(현재 폰트 `getStyledTextSegments(['fontName'])`→`loadFontAsync`→변경) 준수.
