## 5. 자동화 실무 노트 (이번에 겪은 것)

### 인증

- `~/.config/cdbd/credentials.json`의 **실제 키 이름은 문서와 다르다**:
  `supabase_url`, `supabase_anon_key`, **`refresh_token`**, `user_id` (문서의 `supabase_refresh_token`/`supabase_anon` 아님)
- `get_credentials()` 반환 키는 `supabase_url`, **`anon_key`**, `access_token`, `user_id`, `figma_pat`
- **`figma_pat`은 현재 비어 있음** → Figma REST export 불가. 대신 MCP `download_assets(defaultScale: 2)` 사용
- refresh_token 만료 시: **Supabase password grant**로 즉시 복구 가능
  ```
  POST {supabase_url}/auth/v1/token?grant_type=password
  headers: apikey
  body: {"email": "account@emka.group", "password": "…"}
  ```
  ⚠️ **비밀번호는 credentials.json에 저장하지 않는다.** 브라우저에 cdbd.in 탭이 열려 있으면
  백그라운드 rotation으로 방금 저장한 refresh_token이 즉시 무효화되니, 탭을 `about:blank`로 보낸 뒤 발급할 것

### 이미지 대량 업로드

- `image_library.upload_to_library()`는 **1장마다 `image_modal` 전체 PATCH** → **병렬 호출 시 서로 덮어씀**
- ✅ 패턴: **storage POST + sign은 병렬(8 workers), `image_modal` PATCH는 마지막에 1회**
  (104장 기준 storage 약 8초)
- `IL._get_modal(creds)`는 **`(modal_id, images)` 튜플**을 반환한다 (dict 아님)
- 등록 실패로 고아 파일이 생기면: storage `list` → `image_modal`에 없는 최근 path만 골라 `DELETE /storage/v1/object/user_image` (`{"prefixes": [...]}`)

### 유니코드

macOS 파일명은 **NFD**, Supabase에 저장된 name은 **NFC**.
→ 이름 매칭 시 반드시 `unicodedata.normalize('NFC', s)` 적용. 안 하면 **0건 매칭**된다.

### Figma query 셀렉터

`node.query('TEXT[name=한글]')`은 **한글 이름에서 파싱 에러**가 난다.
→ 레이어 이름을 영문으로 두거나(`priceOrig`, `priceFinal`) `findAll` 사용.

### 게시 동기화

`editor` PATCH만 하면 게시 URL에 반영 안 됨. 반드시:
```
1. PATCH /rest/v1/editor?id=eq.5876              {pages}
2. PATCH /rest/v1/editor_published?editor_id=eq.5876  {pages, title, multipage_metadata, theme, type:"multi", is_menu:false}
3. POST  /rest/v1/rpc/save_editor_version        {p_editor_id: 5876}
4. POST  /rest/v1/rpc/get_editor_status_v2       {p_editor_id: 5876}  ← 검증
```

### 헤드리스 뷰어 검수

CdBd 뷰어는 방향키·터치 이벤트로 페이지 전환이 안 된다.
→ **가로 스크롤 컨테이너**를 찾아 `scrollLeft`를 조작하면 전환된다.
```js
const c = [...document.querySelectorAll('*')].find(e => e.clientHeight > 500 && e.scrollWidth > e.clientWidth + 50);
c.scrollLeft = c.clientWidth;   // 다음 페이지
```
단 인접 페이지만 프리렌더(가상화)되므로 먼 페이지는 순차 이동 필요.
