## C. ⭐ 초안 템플릿 규격 (사용자 제작 `01`·`02` 실측 → 승계)

### ⚠️ 폰트가 Pretendard가 아니라 **Lato**
| 요소 | 폰트 |
|---|---|
| 카테고리 | **Lato Bold 11** |

| 공통 | 자간 **−2%** · 행간 **160%** · 색 `#141414` |

**⚠️ Lato에는 한글 글리프가 없다** — 09 매장 정보의 한글(매장명·버튼)은 렌더되지 않아 **Pretendard**로 교체했다. 영문 타이틀만 Lato 유지.

### 페이지 공통
| 항목 | 값 |
|---|---|
| 프레임 | 380×580 · fill **`#FDFDFD`** (순백 아님) · clipsContent |
| 로고 | RECT **55.4 × 20** at (163, 20) — 페이지 면적 **0.50%** (가이드 basic-frame 1.2%보다 작음 = 사용자 선택) |
| 화보 clip | x=20 · **y=58** · 폭 **340** · 높이 가변 |
| 화보 rect | **343 × 514** (원본 비율 0.6667 유지) — clip 밖으로 overflow |
| 정보 프레임 | x=20 · 폭 340 · VERTICAL auto-layout `itemSpacing 2` · **하단 기준선 562 고정** |
| 정보 행 | 340×18 · HORIZONTAL `SPACE_BETWEEN` → 좌 `left`(HORIZONTAL, itemSpacing 5: 카테고리+상품명) / 우 가격(RIGHT) |

### ⭐ 화보 높이 = 정보 행 수의 함수
정보 바 하단(562) · 화보 상단(58) · 화보↔정보 간격(26)을 **고정**하고 화보 높이만 조정한다.
```
infoH   = N*20 - 2
infoY   = 562 - infoH
photoH  = (infoY - 26) - 58
```
| 행 수 | infoY | 화보 높이 |
|---|---|---|
| 2 | 524 | **440** |
| 3 | 504 | **420** |
| 4 | 484 | **400** |
| 5 | 464 | **380** |
