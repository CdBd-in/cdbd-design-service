# 미샤 2610 — 모델 위치·선 마커 정리 + CdBd 6899 반영 (2026-10-20)

## 요약

미샤(MICHAA) 10월 룩북에서 **모델 위치(머리 끝·발끝)** 와 **제품을 가리키는 선**의 기준을 정하고, 그 기준으로 Figma 전 페이지를 고친 뒤 CdBd 에디터 6899의 페이지 이미지와 「+」 아이콘 위치를 다시 맞췄다.
기준은 사용자가 직접 다듬은 `02`·`03`·`04` 페이지. 확정된 규칙은 가이드에 반영했다(아래 「반영한 문서」).

## 1. 확정한 규칙 (사용자 지시)

### 모델 위치·사이즈 — 기준 `03`·`04`
- **머리 끝 y≈53**(높이의 8.5%) · **발끝 y≈590~605**.
- 배율 = (목표 발끝 − 목표 머리) ÷ (현재 발끝 − 현재 머리) → 머리 끝을 y≈53에 맞춘다. 화보는 원본 비율 그대로, 크롭 없이 배율·위치만 바꾼다.
- **머리 높이를 모든 페이지에서 같게 맞추는 것이 1순위.** `08`은 원본 아래 여유가 없어 부츠 끝이 프레임 끝에 닿지만 머리 높이를 맞췄다.
- 모델은 좌우 정중앙. 앉은 컷·기댄 컷은 **머리+상체 덩어리**를 가운데에 둔다(`06-B` — 「너무 왼쪽」 피드백 → 화보를 오른쪽으로 77px).
- 버튼이 겹치는 마지막 페이지(`11-B`)도 같은 기준.
- **얼굴이 좌상단 품번 텍스트를 가리면 그 컷은 쓰지 않는다** → `05`는 A안 대신 B안.

### 선 위치 — 기준 `02`·`03`·`04`
- 선의 한쪽 끝은 **제품 외곽(옷 가장자리)** 에 닿고, 나머지는 **모델 몸을 피해 빈 배경으로** 뻗는다.
- 🔴 **틈이 있으면 안 된다** — `07`은 선과 제품 사이가 7~9px 떨어져 「뭘 가리키는지 모르겠다」는 피드백. 시작점을 외곽에 0~1px 겹치게 두고 **4배 확대**로 확인.
- 안에 입은 제품(아우터 안 니트)은 바깥 옷을 가로질러 배경까지 길게 뺀다(`02` 니트 101px).
- 선 색 = 선 끝 배경 명도(밝으면 검정 / 어두우면 흰색).

### CdBd 「+」 아이콘
- size 10(38px) · **선 바깥 끝에서 16px** · **선과 같은 높이** · **선과 같은 색**(흰 gif / 검은 gif).
- 좌표 공식은 [[1-4. CdBd 콘텐츠]] 「「+」 레이어 배치 규칙」.

## 2. Figma 작업 내역

| 프레임 | 한 일 |
|---|---|
| `07` · `09` · `10-B` | 머리 y53 · 발끝 y595 기준으로 배율·위치 조정 |
| `05`(구 `05-B`) | 같은 기준 적용 후 **5페이지 자리로 이동, 이름 `05`**. 기존 A안은 `05-A (미사용)`으로 아랫줄에 보관 |
| `06-B` | 화보 x −457 → −380(모델 가운데) · 선 소매 끝으로 |
| `08` | 머리 y146 → y53(배율 1.198) · 선 소매 끝으로 |
| `11-B` | 사용자가 잡은 구도(1.87배)에서 3%만 확대 → 머리 y58→53 · 발끝 y585→595 · 선 2개 버튼 위로 |
| 선 22개 | 제품 외곽에 닿게 · 빈 배경 방향으로 · 색 재판정. 이후 확대 점검으로 `05` 바지·패딩, `11` 스커트, `10-B` 바지(제품 위로 9px 올라가 있던 것) 추가 보정 |

- 사용자가 이후 직접 손본 것: `10` 선 3개, `05` 선, `06`·`06-B` 선, 윗줄 `11-B`(`13:25`) 새로 만듦.
- 측정은 화보 rect 사본(`TMP-measure-*`)을 클립 없이 캡처해 픽셀로 쟀다. 임시 노드는 모두 삭제함.

## 3. CdBd 6899 반영

### 시안 선택 (사용자 결정)
| 에디터 페이지 | 사용 프레임 |
|---|---|
| 5 | `05` (B안) |
| 6 | `06` (**A안**) |
| 10 | `10` (**A안**) |
| 11 | `11-B` (윗줄 `13:25`) |
| 2·3·4·7·8·9 | `02`·`03`·`04`·`07`·`08`·`09` |

- 1페이지는 Vimeo 코드 카드라 손대지 않음.

### 진행
1. **1차** — 5~11페이지 이미지 교체 + 「+」 16개 재배치.
2. **2차(「선 위치를 다 고쳤으니 거의 다 바꿔야 한다」)** — 2~11 전부 다시 내보내 에디터 이미지와 **픽셀 비교**: 5~11은 이미 최신(차이 0), **2·3·4가 옛 버전**(03·04는 화보 위치까지 다름) → 이 3장만 교체 + 「+」 재배치.
- 이미지 = 2배(760×1232) · 라이브러리 이름 `MICHAA2610-02` ~ `-11`.
- 상품 링크·「+」 크기·11페이지 버튼 3개(공식몰·인스타·카카오)는 그대로.
