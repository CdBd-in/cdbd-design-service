## C. ⚠️ CdBd 구조 제약 (B·C안 설계의 전제)

**CdBd 텍스트 카드는 「전체 정렬(좌/중앙/우)」만 지원 → 「좌 상품명 / 우 가격」 양끝 정렬 2열 재현 불가.**

- 결론: 편집 가능 구조로 가려면 **정보 레이아웃을 좌측 정렬 1행형으로 재설계**해야 한다
  → `OUTER  울 이중직 셔켓  ₩ 1,990,000` (카테고리만 Bold = lexical format bit 1)

| | A안 | B·C안 |

## E. 배경 늘림 요청 (blocking)

**보드**: `배경 늘림 필요 이미지` = `4:5` (900, 5060) · 카드 `BG-EXT-p3-상단` = `4:7` · extend-source rect = `4:10`

| 항목 | 내용 |
|---|---|
| 방향 | **상단** (+10~12%) |
| 사유 | 모델이 원본 **3%~97%**를 채우는 타이트한 프레이밍 → 상·하 여백 각 3%뿐 |
| 결과 | 380×580 고정(A·B안)에서 **상단:하단 = 1:1**, 모델 키 **94%** → 「3:2 / 90%」 규칙 만족 불가 |
| 난이도 | 배경이 **균일한 베이지 그라데이션** → Figma AI 배경 늘림 성공률 높음 |
| 범위 | ⚠️ **초안 진행 시 `p3`~`p21` 19컷 전체 동일 사안** → 미리 일괄 가공 권장 |

Figma AI는 에디터 전용이라 자동화 API로 호출 불가 ([[CLAUDE.md]] 「배경 늘림 보드」). 가공 완료 신호 → 새 hash로 fill 교체 → 「위치·사이즈 결정 트리」 재적용.
