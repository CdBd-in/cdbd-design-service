## D. ⭐⭐ 상품 링크 연결 (`텍스트+이미지` 카드) — 이번 최대 수확

### 핵심: multiCard에는 **카드 단위 링크 메뉴가 없다**
`카드 디자인` = 배경/테두리/모서리/내부여백/외부여백 뿐. `block.linkButton`을 넣어도 **UI에 안 보이고 렌더도 안 됨** → 금지.
링크는 **`디자인` 탭 → `구성요소` 선택 → `링크 연결`** 로, **구성요소별로** 걸린다.

### ① 이미지(chevron `›`) 구성요소 → `multiCard.items[1].linkButton`
```json
{"type":"url","link":{"href":"<상품 URL>","openNewTab":true}}
```
UI: 디자인 → 구성요소 `이미지` → 링크 연결 → URL 열기 (**placeholder가 `URL을 입력해주세요`**)

### ② 텍스트 구성요소 → lexical **`link` 노드** (`items[0].content` 안)
UI에서 텍스트를 드래그 선택 후 링크를 걸면 **밑줄(format bit 8)이 자동으로 붙는다** → 사용자는 이어서 **`U` 토글로 밑줄 해제**(영상 `쁘렝땅 텍스트 url 걸기.mov`).
자동화에서는 **품번 텍스트 노드만 link 노드로 감싸고 format에서 8비트를 빼면** 동일 결과:
```json
{"children":[{...품번 text node, "format": 원본format & ~8 ...}],
 "direction":"ltr","format":"","indent":0,"type":"link","version":1,
 "textStyle":"<품번 노드 style 그대로>","rel":"noreferrer","target":"_blank","title":null,
 "url":"<상품 URL>"}
```
- 링크 대상 = **품번 부분만** (카테고리·마커는 제외) — 사용자 작업분과 동일
- 텍스트 링크 URL과 chevron 링크 URL은 **동일**하게 유지 → 행 어디를 눌러도 같은 상품

### ⚠️ UI 자동화로 링크를 넣으려다 생긴 사고
`$B fill` 로 URL을 넣고 submit → **입력이 카드 텍스트 본문에 타이핑돼 3P 첫 행 텍스트가 손상**됐다.
원인: 텍스트 구성요소 링크 입력창 placeholder(`URL을 입력하세요`)와 이미지 쪽(`URL을 입력해주세요`)이 달라 **잘못된 입력창/에디터에 포커스**.
→ 백업(`pages_prelink.json`)에서 복구 완료. **교훈: 링크 주입은 UI 대신 REST PATCH로, 키 검증만 UI diff로 할 것.**

### 상품 URL 파싱 (pptx)
`unzip` → `ppt/slides/slideN.xml` 의 `a:p` 텍스트를 순서대로 읽어 `CATEGORY → 품번 → URL:` 3줄 패턴으로 묶음. 슬라이드 N = 룩 N.

## E. ⭐ 인증 복구 (refresh_token 전부 만료 시)

`auth.py get_credentials()`·`accounts` 항목·기존 browse state의 refresh_token이 **모두 400 Bad Request**였다.
Supabase는 refresh token을 **회전**시키므로, 사용자가 브라우저에서 로그인/갱신하면 저장본은 죽는다.

**크롬 쿠키에서 세션 복구 (성공한 경로)**
```bash
cp "$HOME/Library/Application Support/Google/Chrome/Default/Cookies" /tmp/ck.db
security find-generic-password -w -s "Chrome Safe Storage" -a "Chrome"   # 최초 1회 키체인 허용 필요
# key = PBKDF2-HMAC-SHA1(pw, b'saltysalt', 1003, 16)
# openssl enc -d -aes-128-cbc -K <hex> -iv 20*16 -nopad  (값 앞 3바이트 'v10' 제거, 끝 PKCS7 패딩 제거)
# 최신 크롬은 평문 앞 32바이트가 도메인 SHA256 → 'base64-' 로 시작 안 하면 [32:] 슬라이스
# sb-<ref>-auth-token.0 + .1 이어붙이기 → base64 디코드 → 세션 JSON
```
- **access_token을 그대로 쓰면 회전이 없어 사용자 크롬 세션이 안 죽는다** (refresh 호출은 회전시킴 → 사용자 로그아웃 유발 가능)
- 헤드리스 브라우저에는 세션 JSON을 다시 `base64-` + 3180자 청크로 나눠 `cookie-import` (도메인 먼저 1회 방문 후 import)
- access_token 수명 1시간 → 장시간 작업 시 중간에 401/`JWT expired` 발생, 재추출 필요

- **`텍스트+이미지`(multiCard) 카드의 링크는 구성요소별**: 이미지 → `items[i].linkButton`, 텍스트 → lexical `link` 노드. **카드(block) 레벨 `linkButton`은 이 카드 타입에선 무효** → CLAUDE.md 「링크 연결 = linkButton」 규칙에 카드 타입별 예외를 추가해야 함.
- **CdBd 텍스트 링크는 밑줄이 기본** → 디자인 유지하려면 format 8비트 제거(=UI의 `U` 토글).
- **UI 자동화로 값 주입 금지** — 입력창 placeholder가 유사해 오입력 위험. 키 검증(diff)만 UI로, 쓰기는 REST.
- **화보 크롭은 승인된 결과물 1건을 역산해 공식화**하면 나머지에 일괄 적용 가능(모델 키 89% / 상단 여백 28 / 좌우 중앙).
- **흰색 마커는 명도 검사 필수** — 그림자 효과가 없어 밝은 옷 위에서 소실된다.
- **PPT→PDF 목업은 이미지가 누적 잔존** → 마지막 draw만 실제 노출. `get_image_rects()` 순서로 판별.
- **이미지 라이브러리 이름 중복**이 심하므로 `upload_if_missing(name)`은 룩북 재작업에만 쓰고, 신규 시즌은 항상 새 업로드.
